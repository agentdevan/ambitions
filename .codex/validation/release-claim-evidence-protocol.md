# Release Claim Evidence Protocol

Status: Active validation protocol.

Claim types: implementation, test, simulator, physical device, TestFlight, App Store, release readiness, privacy/legal, accessibility, market. Allowed evidence must match the claim. Forbidden claims include production ready, TestFlight ready, App Store ready, privacy certified, accessibility compliant, physical device passed, legal signoff, market proven, fully autonomous, guaranteed, remembers everything, or understands everything unless exact proof exists. Human/platform proof boundaries must be explicit.
