# Release Claim Firewall

Forbidden without matching evidence:

- production-ready
- release-ready
- fully tested
- fully accessible
- App Store ready
- TestFlight ready
- device verified
- privacy compliant
- legally approved
- performance safe

Claim downgrade language:

- planned
- canonized
- scaffolded
- implemented in source
- focused test passed
- build attempted
- build passed for command X
- device proof required
- human review required
- not claimed
