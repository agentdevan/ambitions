# Ambitionsos Template Catalog

Status: Consolidated AmbitionsOS operating asset catalog

Template catalog. Owns kernel spec, graph delta, event, golden scenario, performance budget, source claim, path portfolio, batch report, maintainability extraction report, compatibility retirement report, migration impact, rollback plan, future train manifest, human-made audit, validation log ledger, prompt quality review, evidence ledger, traceability matrix, test impact matrix, risk-to-test map, and source-truth claim ledger templates.

## Standard Fields For Every Split-Out Asset

- purpose
- required source docs
- checks
- allowed files
- forbidden files
- Green/Yellow/Red gates
- validation commands
- report requirements
- stop conditions

## Split Rule

Create a separate file only when a future train names it as required for execution, evidence, or repair. Until then, this catalog prevents one-file-per-idea sprawl.
