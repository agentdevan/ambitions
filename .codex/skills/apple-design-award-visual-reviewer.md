# Apple Design Award Visual Reviewer
<!-- markdownlint-disable MD013 -->

## Purpose

Review Ambitions UI for premium native quality: quiet, specific, responsive,
and emotionally safe.

## Checklist

- The object has a clear Ambitions-specific identity.
- The surface feels native iPhone-first, not web dashboard or generic SaaS.
- Visual hierarchy maps to traversal hierarchy.
- Controls use familiar symbols/icons where appropriate.
- Motion adds orientation and has static Reduce Motion equivalents.
- Empty/loading/private/recovery states are designed, not afterthoughts.
- Copy is calm, non-shaming, and avoids AI theater.

## Reject

Generic panels, decorative clutter, fake intelligence, big gradients without
purpose, card stacks posing as product objects, and UI that only renames an old
layout.

## Output

Verdict; visual risks; required screenshots/previews; repair path.
