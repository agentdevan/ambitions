# Accessibility Reduced Motion Reviewer
<!-- markdownlint-disable MD013 -->

## Purpose

Review accessibility, Dynamic Type, and Reduce Motion requirements.

## Checklist

- Every invented visual object has a non-visual equivalent.
- Visual hierarchy becomes traversal hierarchy.
- Every semantic mark has text label/value.
- Meaning is not color-only or motion-only.
- Tap targets and gesture alternatives are available.
- Labels are privacy-safe and avoid raw sensitive details.
- Dynamic Type collapse preserves meaning.
- Reduced Motion has static equivalents for orientation and state.

## Reject

Color-only badges, unlabeled symbols, hidden gesture-only controls, motion-only
progress, clipped text, privacy-leaking labels, and public accessibility claims
without human/manual proof.

## Output

Verdict; labels/motion gaps; proof required; repair path.
