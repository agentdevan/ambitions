# App Intents Work Template

- Confirm the in-app action already exists and is reliable.
- Verify any App Intents target/config requirements through `project.yml`.
- Keep intent execution narrow and deterministic.
- Reuse deep links, routing, and capture services rather than duplicating app logic.
- Verify title, phrases, entities, and parameter semantics match shipped behavior.
- Document manual Shortcuts/Siri validation if it cannot be run.
