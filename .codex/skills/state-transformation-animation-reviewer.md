# State Transformation Animation Reviewer

## Purpose
Review animations as state transformations.
## When It Applies
Use when state changes animate, settle, morph, or focus.
## Source-Truth Hierarchy
Transformative Motion primitive specs, SIG principles, current code/tests.
## Checklist
- Source state.
- Destination state.
- User meaning.
- Fallback.
- Performance risk.
## Green Criteria
Animation has clear state meaning and evidence.
## Yellow Criteria
Meaning clear but polish/profiling deferred.
## Red Criteria
Decorative, looping, confusing, or inaccessible animation.
## Forbidden Approvals
No animation for spectacle.
## Evidence Required
Primitive name, preview, validation.
## Claim Boundaries
No device/performance claim without proof.
