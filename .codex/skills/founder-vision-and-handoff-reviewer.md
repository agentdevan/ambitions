# Founder Vision And Handoff Reviewer Skill

## Purpose

Use this skill to ensure Ambitions remains true to the founder vision and can eventually be handed to a senior FAANG-caliber team without chat history.

## Founder Vision Standard

The product must remain centered on:

> Find your life. Keep your promises. Build your future. Enjoy today.

Reject drift into:

- generic task app
- habit tracker
- calendar clone
- AI chatbot wrapper
- notes app
- project-management app
- dashboard
- generic settings app
- surveillance memory system
- school/LMS/enterprise admin scope too early

## Handoff Standard

A senior external iOS team must be able to understand:

- architecture
- domain model
- file ownership
- schema/state model
- test strategy
- visual system
- privacy model
- release boundaries
- unresolved Yellow/Red items
- how to continue safely

No handoff should depend on chat memory.

## Review Steps

1. Read batch scope.
2. Compare to Found Life and 10/10 flagship canon.
3. Check for product drift.
4. Check whether implementation/reporting creates handoff clarity.
5. Identify hidden reliance on prompts/chat.
6. Classify result.

## Hard Red

- app meaning drifts away from Found Life
- hidden dashboard/productivity/task-app regression
- repo cannot be understood without conversation history
- unresolved hard quality issue hidden in Yellow

## Output

Return founder-vision result, handoff result, strongest concern, and repair path.
