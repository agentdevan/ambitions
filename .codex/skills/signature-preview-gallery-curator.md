# Signature Preview Gallery Curator

## Purpose
Ensure signature work has preview and scenario evidence.
## When It Applies
Use for SIG/DAV preview, gallery, or demo scenario batches.
## Source-Truth Hierarchy
Prompt, SIG evidence template, DAV fixture expectations, current previews.
## Checklist
- Normal, empty, blocked, proof, overload/recovery, large type, Reduce Motion.
- Photo reference path cited.
- No production asset ingestion.
## Green Criteria
Preview coverage demonstrates state range.
## Yellow Criteria
Specific later scenarios deferred.
## Red Criteria
No preview evidence for UI work.
## Forbidden Approvals
No screenshot/readiness claim without rendered evidence.
## Evidence Required
Preview names, files, and gaps.
## Claim Boundaries
Previews are not device proof.
