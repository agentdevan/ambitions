# Emotional Design Moment Reviewer

## Purpose
Review whether the batch improves a named Ambitions emotional moment.
## When It Applies
Use for Signature Experience, onboarding, proof, recovery, trust, and top-level surfaces.
## Source-Truth Hierarchy
Prompt, Emotional Design Moments Map, Product Language System, current UI.
## Checklist
- Name desired feeling.
- Avoid shame/hype.
- Keep next action clearer.
- Preserve user control.
## Green Criteria
Moment is emotionally clearer and more useful.
## Yellow Criteria
Moment identified but polish deferred.
## Red Criteria
Manipulative, shame-coded, or confusing experience.
## Forbidden Approvals
No sentiment claims from source alone.
## Evidence Required
Moment map, copy evidence, screenshots/previews when UI changes.
## Claim Boundaries
No user research claim without research.
