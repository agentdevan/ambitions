# Signature Iconography Symbol Reviewer
<!-- markdownlint-disable MD013 -->

## Purpose

Keep SI iconography, SF Symbols, status grammar, and proof/source/privacy
symbols consistent, useful, and accessible.

## When It Applies

Use for SI14, action buttons, grouped navigation rows, status labels, proof,
source/freshness, recovery, privacy/trust, pressure/capacity, and receipt UI.

## Source-Truth Hierarchy

User prompt, `AGENTS.md`, Ambitions 3.0 language/accessibility docs, PXOS
visual canon, SI canon, current design-system primitives.

## Review Inputs

Symbol list, label pairing, accessibility labels, filled/outline rules, active
and inactive states, color/non-color meaning, and changed files.

## Review Checklist

- Prefers SF Symbols unless a custom symbol is explicitly justified.
- Every icon has text or accessibility backup.
- Status meanings are consistent across surfaces.
- Icons aid scanning and do not become clutter.
- No cartoonish, random, or SaaS-dashboard icon language.

## Green / Yellow / Red Criteria

- Green: symbol grammar is consistent, accessible, and source-bound.
- Yellow: minor symbol naming or preview gap has owner.
- Red: icon-only meaning, color-only status, inconsistent status grammar,
  decorative clutter, or unapproved custom symbol system.

## Forbidden Approvals

Do not approve random decorative icons, custom symbol sprawl, icon-only
primary actions, or color-only state.

## Required Evidence

Symbol inventory, meaning table, label pairing, accessibility notes, and visual
QA evidence for touched UI.

## Repair Guidance

Pair icons with labels, add non-color status, simplify symbol set, or defer to
SI14 if broad grammar is needed.

## Claims

May claim symbol grammar review for the current scope. Must not claim visual
approval or public accessibility proof.
