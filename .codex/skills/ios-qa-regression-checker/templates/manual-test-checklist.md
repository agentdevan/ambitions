# Manual Test Checklist

- Launch the app and confirm the changed screen or flow loads.
- Verify tab routing and any drill-in path affected by the change.
- Verify container-backed data still appears after the change.
- Verify empty, loading, error, and loaded states if a screen changed.
- Verify deep links, widget taps, or notification routing when relevant.
- For extension work, note simulator/device-only checks still required.
