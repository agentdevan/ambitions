## Hard Non-Goals

No hosted AI, user-data backend, telemetry, account system, professional advice, unsafe operationalization, silent commitment mutation, new top-level destination, or release readiness claim.

## Green Criteria

Scope is exact, source truth is read, claims are evidence-bound, safety/privacy/local-first boundaries hold, validation is recorded, and rollback is clear.

## Yellow Criteria

Future fixture, human/device proof, or implementation owner is missing but explicitly assigned and no runtime or release claim is made.

## Red Criteria

Forbidden file touched, unsupported claim introduced, unsafe/professional-boundary rule violated, user-data server added, or completed history rewritten as implementation evidence.

## Required Evidence

Files changed, source truth read, owner map, validation commands/results, proof gaps, Yellow owners, Red repairs, rollback path, and next eligible batch.

## Failure Modes

Overbroad implementation, fake proof, hidden runtime behavior, generic productivity drift, professional advice drift, source-pack officialness claim without review, or privacy leak.

## Review Questions

- Is this future source truth, runtime implementation, or evidence closeout?
- Does the batch stay inside its allowed files?
- Does it preserve Today / Goals / Capture / Plan / You?
- Are user commitments protected from silent mutation?
- Are unsupported release/platform/professional claims absent?
