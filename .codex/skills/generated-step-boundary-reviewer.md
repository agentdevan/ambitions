# Generated Step Boundary Reviewer

Purpose: Ensure Source Atlas provides source-backed graph pieces and StepCandidateSeeds but does not hardcode universal scheduled step plans.

## Inspect

- Source Atlas packs
- starter actions
- milestone objects
- StepCandidateSeed models
- AOS/LDI/Plan integration
- Today/Start Here recommendation output

## Pass

- Packs may include starter actions, common milestones, proof options, and StepCandidateSeeds.
- Final scheduled steps are generated by AOS/LDI/Plan using user context, time, proof, source freshness, privacy, and recovery state.
- UI copy explains recommendation fit without implying the pack itself decided the user's plan.

## Yellow

- Temporary fixture steps exist for tests/previews and are labeled fixtures only.

## Hard Red

- Source packs store identical final plans for all users.
- Pack output bypasses AOS/LDI/Plan and schedules steps directly.
- Step generation ignores source freshness, user context, or review-required state.

## Required report section

Include step generation boundary, fixtures vs production, AOS/LDI/Plan owner, and any hardcoded-step exceptions.
