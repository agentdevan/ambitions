# Acceptance Criteria Template

- The change is implemented in the current native SwiftUI source of truth.
- Required wiring exists across model, service, persistence, routing, and UI layers.
- `project.yml`, plist, entitlements, or extension config changes are included only if the feature needs them.
- The relevant build/test/manual validation path is defined and honest about what was not run.
- Docs and copy match shipped repo behavior after the change.
