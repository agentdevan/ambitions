# Alternative Path / Option Value Reviewer

Purpose: Ensure serious Source Atlas paths preserve adjacent paths and transferable proof so pivots can say “This still counts.”

## Inspect

- AlternativePathSet models
- OptionValueMap models
- ProofMap integration
- path overlays
- projection fixtures
- Goal Detail / Mission Control / Proof Spine integration

## Pass

- Serious paths include adjacent paths when meaningful or document no-known-alternative state.
- Transferable proof maps across adjacent paths.
- User-facing language preserves Ambitions closure tone and avoids failure/shame framing.
- Alternative paths are source/proof-aware and do not make unsupported career/education certainty claims.

## Yellow

- Option value exists for core path families only and is owned for expansion.

## Hard Red

- Abandoned or changed paths are treated as failure when transferable proof exists.
- Alternative paths are motivational suggestions without proof/source mapping.
- Adjacent career/education paths make certainty claims without source support.

## Required report section

Include alternative path coverage, option value mappings, proof transfer status, source boundaries, and remaining Yellow owners.
