# No Sprawl Guard

Use this wrapper when the change could accidentally create a second OS, a second canon tree, or a duplicate implementation path.

## Route to existing skills

- `pack-duplication-reviewer`
- `orphan-doc-resolver`
- `changed-file-boundary-reviewer`
- `source-truth-librarian`

## Minimum check

1. Do not create a second root.
2. Do not duplicate active authority.
3. Keep install docs subordinate to the truth files.
4. Treat `.codex/runs/` as scratch, not product documentation.
