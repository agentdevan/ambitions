# SwiftUI Flagship UI Reviewer

Use this wrapper for premium UI review of flagship iPhone surfaces.

## Route to existing skills

- `premium-ios-visual-reviewer`
- `flagship-quality-reviewer`
- `ios-native-believability-reviewer`
- `visual-qa-preview-fixture-reviewer`

## Minimum check

1. One primary object.
2. One primary action.
3. No dashboard or card-stack fallback.
4. Dynamic Type and Reduce Motion considerations present.
