# Accessibility Native iOS Reviewer

Use this wrapper when a UI change touches accessibility or claims accessibility quality.

## Route to existing skills

- `accessibility-conformance-tester`
- `accessibility-cognitive-load-reviewer`
- `accessibility-evidence-reviewer`
- `accessibility-reduced-motion-reviewer`

## Minimum check

1. Dynamic Type still works.
2. VoiceOver order makes sense.
3. Reduce Motion has a meaningful fallback.
4. Touch targets remain usable.
