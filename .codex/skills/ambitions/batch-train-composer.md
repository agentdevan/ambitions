# Batch Train Composer

Use this wrapper when a request should become a bounded batch instead of a single sprawling train.

## Route to existing skills

- `autonomous-train-conductor`

## Minimum check

1. Separate installer work from implementation work.
2. Record dependencies and stop conditions.
3. Prefer Green or honest Yellow.
4. Defer senior-only gates rather than guessing through them.
