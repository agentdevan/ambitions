# Release Believability Reviewer

Use this wrapper when a batch needs a skeptical release-feel review rather than a technical implementation pass.

## Route to existing skills

- `ios-native-believability-reviewer`
- `release-claim-safety-auditor`
- `app-store-truth-packet-reviewer`
- `product-maturity-onboarding-reviewer`

## Minimum check

1. Does it feel flagship?
2. Does it feel local-first and trustworthy?
3. Is the claim set conservative?
4. Are release claims still blocked by missing proof?
