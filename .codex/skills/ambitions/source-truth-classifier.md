# Source Truth Classifier

Use this wrapper when a file or doc needs a current-state classification before edits or cleanup.

## Route to existing skills

## Minimum check

1. Prefer live source and current proof.
2. Demote old plans and prompts unless promoted by truth files.
3. Mark unknown rather than guessing.
