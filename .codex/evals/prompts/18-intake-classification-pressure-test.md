# Eval 18: Intake And Classification Pressure Test

## Prompt

`Support a new capture source for Ambitions, keep the change local-first, tell me whether this should be plan-only, plan-plus-implement, or blocked investigation, and explain which skill path you chose before editing anything.`

## Expected Likely Skill(s)

- `phase-executor`
- `capture-flow-implementer`

## Files Likely Touched

- planning or template files if this is only a review exercise
- capture-domain files only if the seam is already clear

## Files That Should Not Be Touched

- unrelated planner files
- release docs

## Expected Stop Condition If Blocked

- stop at blocked investigation if the requested source implies a missing runtime seam

## Success Criteria

- clear task class
- clear execution mode
- clear primary and follow-on skill choice
- no premature broad implementation

## Common Failure Patterns

- skipping classification
- choosing implementation before deciding whether the seam exists
