## Product Facts

- Ambitions is a premium native iOS life execution system.
- Canonical top-level destinations remain `Today / Goals / Capture / Plan / You`.
- Ambitions is not a generic task app, calendar clone, habit tracker, productivity score app, chatbot, dashboard, or AI wrapper.
- Core loop: `Capture -> Place -> Plan -> Do Today -> Close / Recover -> Save Proof`.
- User-facing Today language prefers `Start here` and `Recommended step`.
- Avoid `next best move` / `Your best next move` as user-facing copy.
- Action Closure is not binary overdue/failure; closure states include `Completed`, `Still Counts`, `Moved`, `Skipped/Not Needed`, `Blocked`, `Waiting`, `Needs Recovery`, and `Needs Review`.
- Capture is composer-first, not an inbox/feed/notes top-level surface.
- Plan is capacity/LifeShape/reflow/protected-time oriented, not a generic calendar clone.
- Goals should support multiple equally weighted goal categories, not a forced single primary goal.
- You owns personal system, planning setup, trust, memory, receipts, and appearance surfaces; compatibility code may still use Profile naming internally.
