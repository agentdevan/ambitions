# Visual Performance And Accessibility Board

## Purpose
Review premium visuals for readability, performance, and accessibility risk.
## Review Roles
Visual performance reviewer, accessibility reviewer, Dynamic Type reviewer, Reduce Motion reviewer.
## Required Evidence
Build/test status, previews, accessibility notes, performance risk notes.
## Source-Truth Hierarchy
Accessibility canon, SIG scorecard, DAV/PXEQ, current source.
## Green Criteria
Readable, performant, accessible evidence is complete.
## Yellow Criteria
Human/device proof or profiling deferred with owner.
## Red Criteria
Clipping, motion-only meaning, heavy unmanaged visual cost.
## Stop Conditions
Public accessibility or performance claims without proof.
## Claim Boundaries
Internal evidence only.
## Relation
Required for DAV/SIG premium surfaces.
