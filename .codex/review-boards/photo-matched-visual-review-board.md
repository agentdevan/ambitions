# Photo-Matched Visual Review Board

## Purpose
Ensure visual work follows uploaded photo-matched references.
## Review Roles
Photo-matched visual director, material-depth reviewer, surface owner.
## Required Evidence
Reference paths inspected, reference script result, visual alignment report.
## Source-Truth Hierarchy
Photo reference README, Signature Experience Layer, DAV/PXEQ docs.
## Green Criteria
Fidelity is clear and reference handling is safe.
## Yellow Criteria
Partial visual alignment with named future owner.
## Red Criteria
Missing assets, asset catalog ingestion, old filename, identity split.
## Stop Conditions
Unsupported readiness/award claims from images.
## Claim Boundaries
References are not shipped app assets.
## Relation
North star for DAV/SIG/Transformative Motion.
