# Roadmap To Code Traceability Protocol

Use for implementation batches, batch closeout, and handoff reports.

## Steps

1. Name batch, primitive, and surface.
2. Link source canon and roadmap/status docs.
3. List touched code/docs/tests.
4. Map validation evidence.
5. Mark claim state.
6. Update registry/status only after evidence supports it.

## Output

Use the mapping fields in `docs/canon/Ambitions_3_0_Roadmap_To_Code_Traceability_Rules.md`.
