# Risk Register Protocol

Use when a risk is durable, repeated, release-relevant, or likely to be rediscovered.

## Steps

1. Classify severity and owner.
2. Add or update `docs/audits/ambitions-3-0-risk-register.md`.
3. Link evidence.
4. Name mitigation and next review.
5. Include release impact in closeout.

## Stop Conditions

Stop if a high-severity risk would be hidden by a PASS result.
