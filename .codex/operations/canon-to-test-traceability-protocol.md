# Canon To Test Traceability Protocol

Use when adding tests, modernizing UI tests, or changing canon promises.

## Steps

1. Extract user promise from canon.
2. Choose test class.
3. Identify fixture and stable accessibility identifiers.
4. Add or update tests only for the protected promise.
5. Record validation command and release impact.

## Stop Conditions

Stop if canon and implementation reality conflict and no owner decision exists.
