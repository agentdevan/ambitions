# Postmortem Learning Loop Protocol

Use after bad runs, repeated validation failures, source-truth mistakes, or process gaps.

## Steps

1. Write the smallest useful postmortem.
2. Identify the failed protocol or missing gate.
3. Update one durable artifact: protocol, checklist, template, validation pack, or prompt.
4. Record follow-up proof.

## Stop Conditions

Do not create process artifacts without changing a future decision or validation behavior.
