# Test Ownership Protocol

Use when adding, changing, deleting, quarantining, or interpreting tests.

## Required Inputs

- `docs/canon/Ambitions_3_0_Test_Ownership_Matrix.md`
- `docs/canon/Ambitions_3_0_UI_Test_Contract.md`
- Target canon/primitive doc.
- Failing command or proposed test change.

## Steps

1. Identify surface, primitive, and test class.
2. Name owner and fixture owner.
3. Decide whether the test should survive redesign.
4. Classify failures before code or test edits.
5. For deletion, document replacement or retirement reason.
6. Record evidence in the closeout.

## Stop Conditions

Stop if the test protects a release, privacy, shell, or persistence claim and no replacement guard exists.
