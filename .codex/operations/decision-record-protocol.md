# Decision Record Protocol

## When To Use

Use when a change meets ADR triggers in the Ambitions 3.0 Decision Record
Protocol.

## Exact Steps

1. Open a new ADR from `docs/adr/ADR_TEMPLATE.md`.
2. Name context, decision, alternatives, consequences, validation, reversal.
3. Link owning canon, code seams, and tests.
4. Do not implement architecture-sensitive changes until the ADR is coherent.

## Stop Conditions

- No clear reversal path.
- Privacy/persistence/release implications are unresolved.
