# Architecture Review Board Protocol

## When To Use

Use for L/XL architecture-sensitive Ambitions work.

## Exact Steps

1. Identify architecture trigger.
2. Select board roles.
3. Read owning canon and current code seams.
4. Decide whether ADR is required.
5. Approve, caveat, or block.
6. Record validation and reversal path.

## Stop Conditions

- Board block remains unresolved.
- Human approval is required.
- Change would create a parallel architecture.
