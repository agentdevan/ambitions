# Ambitionsos Checklist Catalog

Status: Consolidated AmbitionsOS operating asset catalog

Checklist catalog. Owns kernel readiness, runtime contract, source truth, starting position, alternate path, commitment time, reality drift, performance, privacy, edge cases, deep-not-wide, no-sycophant copy, release truth, maintainability, compatibility, migration, rollback, external route, future train, log preservation, human-made maintainability, prompt quality, and performance budget checks.

## Standard Fields For Every Split-Out Asset

- purpose
- required source docs
- checks
- allowed files
- forbidden files
- Green/Yellow/Red gates
- validation commands
- report requirements
- stop conditions

## Split Rule

Create a separate file only when a future train names it as required for execution, evidence, or repair. Until then, this catalog prevents one-file-per-idea sprawl.
