# Task Width Checklist

- [ ] Task size is XS, S, M, L, XL, or split from XXL.
- [ ] Owning primitive is named.
- [ ] Owning surface is named.
- [ ] Allowed files are named.
- [ ] Forbidden files are named.
- [ ] Role passes are named.
- [ ] Validation pack is named.
- [ ] Hard split rules are checked.
- [ ] Multi-primitive combination is allowed or split.
- [ ] Human approval triggers are checked.
