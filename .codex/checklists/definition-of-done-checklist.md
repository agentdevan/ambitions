# Definition Of Done Checklist

- [ ] Matches active Ambitions 3.0 canon.
- [ ] Tests run or reason documented.
- [ ] Copy guard run where relevant.
- [ ] Accessibility evidence where UI changed.
- [ ] Privacy/trust evidence where sensitive data changed.

- [ ] No active stale-doc guidance introduced.
- [ ] Status docs updated when status changed.
- [ ] Closeout report written.
- [ ] Next exact prompt provided.
- [ ] Release claims remain evidence-gated.
