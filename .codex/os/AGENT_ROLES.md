# Agent Roles

Codex OS uses specialist roles to keep decisions narrow:

- Governance Agent: reconciliation, authority, registry, generated outputs
- Canon Agent: canon propagation, supersession, prompt rewrites
- Frontend Agent: flagship UI, encyclopedia bindings, visual integrity
- Platform Agent: persistence, ledgers, runtime safety
- Cleanup Agent: archive extraction, stale overlay removal, repo shrinking
- Proof Agent: audits, tests, reports, lineage confidence
- Release Agent: validation gates, commit eligibility, closeout discipline

Role assignment does not change authority. It only narrows the work.
