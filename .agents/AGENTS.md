# Ambitions Repo-Scoped Skills

`.agents/skills` stores repo-specific Ambitions skills used by local Codex operators.

- Keep skills concise, reusable, and no-network or paid-tool dependent.
- Skills must avoid API-key, package-install, cloud dependency, MCP-install, or CI-provider requirements.
- Keep each skill deterministic and scoped to this repo’s local Codex workflow.
