# Ambitions Visual Proof Skill

Visual proof requires reviewable image artifacts and an approved target.

Do not claim Visual Green from:

- source tests
- string audits
- local screenshot paths only
- simulator-only screenshots when device proof is required
- human visual review written by the implementing agent
- absence of old bad strings

## Required For Visual Closeout

- target image or target rubric
- actual image attached or embedded where the reviewer can see it
- frame hierarchy notes
- visual defects list
- pass/fail against each hard visual constraint
- device evidence for Visual Green

## Status Limits

- Local `.codex` screenshot path only: not visual proof.
- Simulator screenshot only: Yellow maximum for visual quality.
- Codex self-review only: Ready for Visual Review maximum.
- No device proof on visual-qa or flagship-quality issue: not Done.

## Output

Every visual proof response must separate:

- what is verified
- what failed
- what is not verified
- what needs independent review
- status ceiling
