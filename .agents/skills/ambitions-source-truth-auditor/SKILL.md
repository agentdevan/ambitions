## Inputs
- `docs/truth/*`
- Current task scope and file list.

## Steps
1. Read ordered truth files.
2. Confirm active/compatible language (especially IA and release posture).
3. Flag stale or conflicting material and keep historical material classified.
4. Record ambiguity before edits.

## Output
- A short list of active sources used and unresolved uncertainties.
