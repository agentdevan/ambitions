## Requirements
- Distinguish verified claims vs assumptions.
- Use `docs/status/release-evidence-packet.md` for validated release claims.
- Never claim App Store/TestFlight/device readiness without logs and exact source proof.

## Failure handling
- Mark Yellow on missing evidence, then request explicit verification.
