## Red Classes

- Private user data in R2/public material.
- Missing source binding.
- Missing freshness or stale behavior.
- Missing revocation.
- Missing release receipt.
- Missing rollback.
- Runtime eligibility without proof.
- Duplicate architecture or bypassed existing tooling.
- Unproven release/privacy/legal claim.
