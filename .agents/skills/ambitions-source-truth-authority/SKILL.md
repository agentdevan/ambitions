# Ambitions Source Truth Authority

This skill is operating support only. It is not product truth, implementation proof, validation proof, release proof, accessibility proof, privacy approval, App Store proof, or permission to widen scope.

## Canon

- Persistent surfaces: Today / Goals / Time / You
- Global composer: Capture
- Behavior layer: Motion
- Trust layer: Proof / Source / Privacy / History / Receipts

Motion is not a tab or destination. Capture is not a tab.

## Workflow

1. Read `docs/truth/README.md`, product/design truth, moat truth, implementation truth, release truth, Codex process truth, retention truth, then `AGENTS.md`.
2. Treat live source/project/test/script evidence as implementation truth.
3. Treat current logs and proof packets as release truth.
4. Classify non-source material as active, supporting, stale, or delete-worthy before using it.
5. Do not revive deleted prompts, trains, artifacts, old skills, old control-plane files, or five-surface IA.

## Output

- Truth files inspected
- Current evidence used
- Conflicts found
- Claims allowed and forbidden
- Smallest safe next action
