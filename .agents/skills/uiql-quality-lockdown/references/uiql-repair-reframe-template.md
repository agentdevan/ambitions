# uiql-repair-reframe-template

Use this reference during UIQL closeout. It reinforces no product Yellow, screenshot path is not proof, read-only reviewers, exact proof paths, rollback, Linear closeout, and no release/owner approval claims.

Repair/reframe must stay inside the active AMB issue. If a repair maps to a later AMB issue than the one currently active, stop and record it as dependency drift rather than continuing under the synthetic `UIQL-*` label.
