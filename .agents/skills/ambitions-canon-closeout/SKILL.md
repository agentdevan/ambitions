# Ambitions Canon Closeout Skill

Use scoped statuses:

- Source Green
- Runtime Green
- Interaction Green
- Ready for Visual Review
- Visual Green
- Release Green
- Yellow
- Red

Never write unqualified `Green`.

If any required proof category is missing, status is Yellow or Red.

If the issue is visual/product-surface work, Codex may only claim Ready for Visual Review unless independent visual acceptance and required device proof already exist.

If the umbrella proof issue is not complete, do not say project complete.

## Closeout Template

```text
Status:
Scope completed:
Files changed:
Rendered target:
Rendered actual:
Target-vs-actual critique:
Product object proof:
Validation run:
Validation not run:
Accessibility proof:
Device proof:
Known risks:
Follow-up required:
Rollback plan:
Independent visual reviewer:
```

`Independent visual reviewer` is required for Visual Green.
