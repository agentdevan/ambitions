# PLOS Golden Slice Standard

The Golden Slice is the first end-to-end proof that the Private Life Runtime moat works in live Ambitions source. It is not a design concept or docs claim.

## Required Proof

The slice must demonstrate:

- Goal or intent input.
- Local context and constraints.
- Source authority and freshness.
- A `Recommended step` that is specific, capacity-aware, and source-backed.
- Trust receipt explaining why the step was recommended.
- Execution launch with `Start now` or `Open step` as appropriate.
- Closure and recovery path.
- Reflow or replay proof after changed reality.
- No hidden mutation and no cloud LLM/core server dependency.

## Required Evidence

- Live source ownership map.
- Focused tests or deterministic scripts.
- Visual/accessibility proof for user-facing surfaces.
- Privacy/source boundary proof.
- Reviewer pass for phase-order, architecture, privacy, and closeout.
- Linear closeout using `AMB-*` identifiers.

## Blockers

- Generic task fallback without explanation.
- Missing source receipt.
- Missing local replay proof.
- Hidden schedule or recommendation mutation.
- Source Atlas pack without runtime eligibility proof.
- Release/readiness claim beyond evidence.
