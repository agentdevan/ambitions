# Ambitions Visual Red Team Skill

Given the screenshot, ignore the closeout and answer:

1. What is visually dominant?
2. What feels prototype?
3. What violates canon?
4. Which file likely caused it?
5. Would this ship in a flagship native iPhone app?
6. Red / Yellow / Green.

This review must happen after implementation and before closeout for visual/product-surface work.

Codex may perform this as a defect-finding pass, but Codex may not use its own review to certify Visual Green.

## Required Output

- Verdict: Red, Yellow, or Ready for Visual Review
- Dominant object
- Prototype signals
- Canon violations
- Likely source files
- Required repair before Visual Green
