# Ambitions iOS quality routing adapter

This is a non-authoritative procedural adapter. It cannot replace canon, Apple
source verification, rendered evidence, independent review, or release proof.

Registry entry: `docs/canon/references/skill-dependencies.json`
Allowed purpose: route native iPhone implementation through canonical platform
and accessibility obligations.
Canonical requirement IDs: `SPEC-APP-SHELL-ROOT-NAVIGATION-001`,
`ACCESSIBILITY-SEMANTIC-EQUIVALENCE-001`.

Procedure:

1. Generate the bounded pack and read its native/platform/accessibility requirements.
2. Inspect current source ownership, deployment target, APIs, tests, and proof.
3. Verify platform availability and required fallbacks before adopting an API.
4. Run the focused native and accessibility checks routed for the exact scope.
5. Report current evidence, not-run checks, unsupported claims, and rollback.

Use the exact dependency paths and SHA-256 values in the registry; stale bytes
fail `skill-conformance --check`.
