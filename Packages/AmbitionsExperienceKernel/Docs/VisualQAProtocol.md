# Visual QA Protocol

The app must prove each top-level surface across normal, constrained, protected, recovery, stale proof, privacy boundary, Dynamic Type XXL, and Reduce Motion states.

Required checks:
- object hierarchy remains intact
- semantic field changes match runtime inputs
- proof and replay remain inspectable
- commands remain native-feeling and custom to Ambitions
- VoiceOver summaries describe object purpose and state
- Reduce Motion keeps meaning while removing nonessential movement
- protected time and away time are never presented as free time
