# Converted SWOT To Release Strengths

## Former weakness: accumulated release strata
Strength: the package is now one canonical `AmbitionsExperienceKernel` with no legacy release ladder in its source layout.

## Former weakness: Today hierarchy conflict
Strength: Today has exactly one primary object: Reality Meridian. Start here is explicitly a decision layer attached to it.

## Former weakness: shallow validation
Strength: release gates now check surface contracts, token range, raw Swift literals, legacy UI language, runtime calibration, Codex batch count, invention count, and install scripts.

## Former weakness: token sprawl
Strength: color tokens are tiered and capped. Core, surface, object, field, and state tiers are defined in `tokens.json` and enforced by lint.

## Former weakness: magic constants in visual state
Strength: compiler constants moved into `AmbitionsCompilerCalibration` and `compiler_calibration.json`, aligned to hard context, availability, cognitive context, and recommendation layer.

## Former weakness: default command styling
Strength: primary and secondary commands now use `AmbitionsCommandStyle` instead of default system command treatments.

## Former weakness: install script only copied files
Strength: the installer creates a repo integration report, detects repo shape, installs the package, and points Codex to exact validation and wiring batches.

## Former opportunity: experience kernel
Strength: the package now owns tokens, object contracts, visual state compilation, proof/replay, accessibility grammar, motion/haptics, diagnostics, scripts, and Codex execution.

## Former opportunity: visual-state pipeline
Strength: `AmbitionsRuntimeSnapshotInput` compiles into `AmbitionsVisualFieldState` through `AmbitionsExperienceCompiler`, with a private runtime bridge contract.

## Former opportunity: screenshot proof
Strength: `preview_matrix.json` defines required surface/state screenshot fixtures for release proof.

## Former risk: over-abstraction
Strength: every invention spec requires a shipped surface binding, runtime input, preview fixture, and validation gate.

## Former risk: living visuals becoming gimmick
Strength: visuals are only allowed when caused by semantic field state: capacity, pressure, closure residue, source freshness, proof intensity, goal pull, recovery, or privacy boundary.

## Former risk: performance debt
Strength: `AmbitionsPerformanceBudget` and quality gates cap animated layers, blur surfaces, inline receipts, and motion behavior.

## Former risk: Codex drifting from repo truth
Strength: Codex must run repo truth audit first, then execute sixteen sequenced batches with proof artifacts and rollback notes.
