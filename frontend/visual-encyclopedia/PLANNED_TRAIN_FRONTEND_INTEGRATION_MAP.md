# Planned Train Frontend Integration Map

Status: Active all-train source-family integration map

MRI and HBI are preserved as entries within the broader planned train/source-family system. They are not the only overlay inputs and they do not override `docs/truth/*` or live source.

## What This Map Does

- Groups the train/source families that shape intended final-state frontend direction.
- Keeps MRI/HBI as supported entries instead of privileged special cases.
- Distinguishes direct visual influence from validation-only and control-plane families.
- Connects the family layer to the surface, object, primitive, and gap matrices.

## Core Families

- PK, MRI, HBI, LID, AOS, REC, SI, PD, Moat Runtime, Runtime, Visual Canon, Planning, Capture, Time, Today, Goals, You, Accessibility, Privacy, QA / validation, and Onboarding / First Run.

## Supporting Programs

- AFI, FCP, PFC, FL, CQS, FET, FVQ, MEG, AIR, SA, EFC, PXOS, GQ, RHC, CS, and ME.

## Primary Use

Use this map to decide which planned-train direction belongs on a surface or object. Use the matrix docs for specific surface/object/primitive placement, and use `docs/truth/*` whenever a family conflicts with active repo truth.
