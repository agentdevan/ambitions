# Accessibility And ADHD Laws

Status: Active behavior canon

This file restates the intended requirement set in plain terms so it can be used in review and validation.

1. One dominant action at rest.
2. Maximum three visible choices after capture.
3. One unresolved attention object at most per top-level surface.
4. Metadata collapses before actions collapse.
5. "Why this?" starts small.
6. Recovery mode reduces density.
7. "Needs a Place" is success.
8. No categorization before saving.
9. No shame copy.
10. Every state has a next safe action.
11. No color-only meaning.
12. No motion-only meaning.
13. No glow-only meaning.
14. No tiny-only freshness indicators.
15. Primary actions stay reachable at large Dynamic Type.
16. VoiceOver reads object summary before child controls.
17. Reduce Motion replaces morphs with static before/after state.
18. Reduce Transparency replaces glass with opaque graphite layers.
19. Increase Contrast adds seams and boundaries.
20. Differentiate Without Color adds shape, icon, and text markers.
21. Hit targets stay native-believable.
22. Context switching is minimized after capture.
23. Destructive actions require preview.
24. Automation changes require consequence explanation.
25. Recovery flows keep the exit path visible.

## Proof Boundary

These are intended requirements, not accessibility conformance proof.
