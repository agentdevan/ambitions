# Cross-Surface State Grammar

Status: Active behavior canon

## Canonical State Families

- active
- empty
- loading
- stale source
- local-only
- waiting
- blocked
- recovery
- disabled
- unresolved direction

## Grammar Rules

- State should be readable in words and structure.
- State should preserve source and receipt continuity.
- State should survive Dynamic Type and Reduce Motion.
- State should not rely on color alone.

## Surface Expectations

- Today: current-state, closure, recovery
- Goals: proof, blocker, pivot
- Capture: route reveal, hold, receipt
- Time: pressure, protected time, fit, reflow
- You: runtime, trust, privacy, reset

## Error Handling

Errors are state, not a generic fallback page.
