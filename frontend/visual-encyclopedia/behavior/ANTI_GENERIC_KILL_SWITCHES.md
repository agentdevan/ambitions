# Anti-Generic Kill Switches

Status: Active behavior canon

## Kill Switches

### Fancy To-Do List

Fails if Today can be described as a list of tasks with a recommended item on top.

### Calendar Clone

Fails if Time can be described as a calendar with better visuals.

### Chatbot

Fails if Capture can be described as a chat box where the app replies.

### Goals Dashboard

Fails if Goals can be described as a dashboard of goals and progress.

### Settings App

Fails if You can be described as a profile/settings page.

### Futuristic UI

Fails if the interface depends on decorative stars, neon glow, sci-fi HUD lines, fake glass everywhere, unreadable transparency, or dashboard metrics.

## Required Alternatives

- Today -> current-state meridian
- Time -> capacity field
- Capture -> local composer with route reveal
- Goals -> relational atlas
- You -> visible local runtime profile
