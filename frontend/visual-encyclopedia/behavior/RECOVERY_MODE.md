# Recovery Mode

Status: Active behavior canon

## Triggers

- interrupted flow
- multiple unclosed steps
- repeated moves
- protected-time conflict
- stale source conflict
- high-pressure week
- missed planning review
- manual overload selection
- large schedule disruption

## Required Behavior

- Today narrows to one closure or one step.
- Time shows pressure source and one relief option.
- Goals dims non-active ambitions.
- Capture defaults to hold-first after saving.
- You exposes temporary automation controls.
- Copy remains calm and direct.
- Use `CLOSURE_RECOVERY_INTERACTION_GRAMMAR.md` for interrupted, blocked, stale, and recoverable labels.

## Forbidden Behavior

- shame language
- score or streak pressure
- hidden exit path
- false certainty

## Recovery Goal

Make the next safe action obvious while reducing visible density.
