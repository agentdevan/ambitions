# No False Momentum

Status: Active behavior canon

## Rules

- Completed requires completion.
- Still Counts requires evidence.
- Moved is not progress.
- Skipped is not failure.
- Blocked is not user fault.
- Waiting is not procrastination.
- Reflow is not automatic unless automation permits it.
- Proof cannot be manufactured from intention alone.
- Captured but unplaced is safe, not clutter.
- A recommendation without source must disclose uncertainty.

## Failure Language

The product must not turn ordinary reality into shame.
