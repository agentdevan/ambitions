# Reality Meridian Anatomy

Status: Active primary-object canon
Destination: Today

## User-Facing Role

Reality Meridian is the Today object that shows what fits now, what needs closure, and what source or proof explains the current state.

## Current-State Spine

```text
Reality Meridian
  ├─ Start Here region
  ├─ Now / Next / Later sequence
  ├─ closure prompt seam
  ├─ source / proof seam
  └─ recovery / undo path
```

## What It Must Hold

- one dominant current-state object
- a visible Start Here region
- a source/proof seam that is not decorative
- a recovery path that never hides the state that produced the problem

## Read When Labels Are Off

- The current-day band should still read as the primary object.
- The Start Here region should be obvious without a settings-clone layout.
- The proof seam should explain itself as trust, not chrome.
- The closure path should still be reachable when text is reduced.

## Interaction Grammar

- Start now.
- Open a step.
- Close the loop.
- Review the source if the recommendation feels stale.

## Failure Modes

- too many competing actions
- hidden source
- stale recommendation treated as fact
- no obvious recovery path
- dashboard tiles or card stacks replacing the current-state spine

## Trust Rule

The object may explain why it knows what it knows, but it must stay inspectable and user-controlled.

## Accessibility Notes

- VoiceOver sequence starts with object, then state, source, action, and recovery.
- Dynamic Type must not hide the dominant current-state object or its action.
- Reduce Motion should preserve meaning through before/after summaries.
- Reduce Transparency should fall back to opaque graphite layers without losing the seam.

## Native Believability

- Reads like a current-state iPhone surface, with restraint, thumb reach, and no spectacle.
- Keeps actions thumb-reachable.
- Never drifts into a dashboard or card stack.

## Why It Exists

Reality Meridian exists so the user can see what fits now, what can close, and what must recover without the app becoming a generic task list.
