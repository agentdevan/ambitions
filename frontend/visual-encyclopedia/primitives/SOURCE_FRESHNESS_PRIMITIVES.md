# Source Freshness Primitives

Status: Active primitive contract

## Purpose

Show whether the source is fresh, stale, local-only, or unresolved.

## Canonical Anatomy

- freshness badge
- stale mark
- local-only mark
- unresolved mark

## Allowed Use

- trust seams
- source / proof rows
- runtime explanations

## Forbidden Use

- decorative status light
- model-confidence proxy

## Allowed Surfaces

- Today
- Goals
- Capture
- Time
- You

## Forbidden Surfaces

- generic dashboards
- scoreboards

## Visual Ingredients

- label
- state marker
- compact disclosure

## State Variants

- fresh
- stale
- local-only
- unresolved

## Source / Proof / Receipt Behavior

Freshness must be inspectable and never implied by color alone.

## Accessibility Fallback

The badge must remain understandable in VoiceOver and under reduced transparency.

## ADHD Safety Note

Freshness should lower uncertainty, not create another task.

## Misuse Examples

- glowing badge with no explanation
- hidden freshness cue

## Recipe Examples

- today source freshness indicator
- local runtime trust panel

## Validator Hooks

- source truth
- local-first trust
- vocabulary boundary
