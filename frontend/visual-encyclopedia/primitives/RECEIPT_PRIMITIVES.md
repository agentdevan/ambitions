# Receipt Primitives

Status: Active primitive contract

## Purpose

Make change, confirmation, and recovery legible.

## Canonical Anatomy

- receipt chip
- receipt row
- receipt trail
- receipt preview

## Allowed Use

- confirm a transaction
- preserve proof
- show reversible history

## Forbidden Use

- toast spam
- gamified reward badge

## Allowed Surfaces

- Today
- Capture
- Goals
- Time
- You

## Forbidden Surfaces

- generic notification feed
- achievement wall

## Visual Ingredients

- label
- compact evidence text
- source / proof tie-in

## State Variants

- pending
- confirmed
- failed
- reversed

## Source / Proof / Receipt Behavior

Receipts must stay attached to the transaction they came from.

## Accessibility Fallback

Receipts must be understandable as text, not decoration.

## ADHD Safety Note

Receipts should close loops, not create clutter.

## Misuse Examples

- reward confetti
- floating checkmark spam

## Recipe Examples

- closure sheet
- receipt detail
- local data reset / forget

## Validator Hooks

- proof source receipt
- transaction
- no false momentum
