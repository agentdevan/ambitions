        # Local First Runtime Trust Gate

        Status: Active frontend contract scaffold

        ## Definition

        This gate enforces local-first runtime trust: no external/cloud LLM core dependency, inspectable learning, reset/forget preview, source authority ladder, and no hidden automation.

        ## Allowed Use

        - Use to review local runtime behavior and user-set truth priorities.
- Use as a trust contract for You and the control-plane layers.

        ## Forbidden Use

        - Do not use to justify hosted AI or hidden automation.
- Do not use to claim device validation.

        ## Required Tokens

        - youTrust
- sourceFreshness
- proofReceipt

        ## Accessibility Requirements

        - The gate requires inspectable learning and visible reset/forget preview.
- The gate requires user-set truth to outrank suggestion.

        ## State Variants

        - local-only
- inspectable
- reset preview
- forget preview
- no hidden automation

        ## Proof And Receipt

        No external/cloud LLM core dependency is introduced by this batch.
