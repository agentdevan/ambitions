        # Primary Cta Contract

        Status: Active frontend contract scaffold

        ## Definition

        The primary CTA is one clear action per surface and no more.

        ## Allowed Use

        - Use for the dominant action on each object surface.
- Use when the user has one obvious next step.

        ## Forbidden Use

        - Do not stack competing primary actions.
- Do not hide secondary actions as the primary action.

        ## Required Tokens

        - ctaPrimary
- panelHero

        ## Accessibility Requirements

        - Label must make the action obvious.
- Disabled state must be explicit.

        ## State Variants

        - enabled
- disabled
- loading
- correction

        ## Proof And Receipt

        If the primary action is ambiguous, the surface is not yet contract-complete.
