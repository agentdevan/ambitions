        # Differentiate Without Color Contract

        Status: Active frontend contract scaffold

        ## Definition

        Meaning must survive when color is unavailable.

        ## Allowed Use

        - Use icon + label + structure for state meaning.
- Use for state, source, and proof surfaces.

        ## Forbidden Use

        - Do not use color alone to distinguish states.
- Do not assume users can infer meaning from hue.

        ## Required Tokens

        - differentiationFallback
- sourceFreshness

        ## Accessibility Requirements

        - Each state must have a non-color cue.
- Meaningful labels must be present.

        ## State Variants

        - same color different meaning
- icon plus label
- pattern plus label

        ## Proof And Receipt

        Color-independent meaning remains a contract until observed in source or device evidence.
