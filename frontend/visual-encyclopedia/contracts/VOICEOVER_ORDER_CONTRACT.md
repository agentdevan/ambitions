        # Voiceover Order Contract

        Status: Active frontend contract scaffold

        ## Definition

        VoiceOver order must be logical, local, and source-first.

        ## Allowed Use

        - Use for every object surface that includes control, source, or proof.
- Use to define reading order and labels.

        ## Forbidden Use

        - Do not depend on visual ordering alone.
- Do not suppress correction paths from VoiceOver.

        ## Required Tokens

        - voiceOverOrder
- sourceFreshness

        ## Accessibility Requirements

        - The order must lead with object, then state, then source, then proof, then action.

        ## State Variants

        - surface first
- source first
- proof first
- correction first

        ## Proof And Receipt

        This is a contract, not a verified VoiceOver audit.
