        # Reduce Transparency Contract

        Status: Active frontend contract scaffold

        ## Definition

        Reduce Transparency must preserve separation, depth, and contrast without depending on blur.

        ## Allowed Use

        - Use for panels, overlays, and shell chrome.
- Use explicit contrast and outline fallback.

        ## Forbidden Use

        - Do not rely on blur for meaning.
- Do not hide state behind glass alone.

        ## Required Tokens

        - contrastFallback
- quietGlass

        ## Accessibility Requirements

        - The fallback must remain readable and distinct.
- Boundaries must remain visible.

        ## State Variants

        - glass
- reduced transparency
- solid fallback

        ## Proof And Receipt

        This is a requirement contract, not a live accessibility report.
