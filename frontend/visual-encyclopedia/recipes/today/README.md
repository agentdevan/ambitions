Locked requirements:

- Today is a living temporal surface, not a productivity dashboard.
- Reality Meridian is the primary object.
- The Reality Meridian is a scrollable vertical day spine; one screen is only one viewport state.
- Scheduled step nodes and the live current-time cursor are separate visual objects.
- The live current-time cursor uses an exact left-side label, for example `12:15 PM`.
- Start Here is sparse and integrated into the temporal field.
- Start Here is a reality-recognition aperture, not a generic recommendation card.
- `Recommended step` is only valid when Ambitions selects from unscheduled possible work.
- `Active step` is required when a scheduled step is currently inside its scheduled time window.
- `In progress` is reserved for a user-started step/session.
- `Up next` is used for an upcoming scheduled item.
- `best next step`, `next best move`, and `optimal move` are forbidden.
- Receipt source must match authority: scheduled-current work uses `Scheduled step`, not `Local recommendation`.
- `Start now →` is one-handable, right-side, and at or below vertical center when the resolved state supports execution.
- The top-right local-first lockup is `Local · Ambitions`.
- Future moments are lightweight time/title pairs, not boxed rows.
- Receipt/recovery is compact, authority-aware, and calm.
- Bottom IA is exactly `Today / Goals / Capture / Time / You`.

## Start Here Reality Recognition Rule

If a lower-level Today recipe says or implies that Start Here is always a recommendation, treat that as superseded. Start Here is a stateful aperture whose label is resolver-derived:

| State | Correct label |
| --- | --- |
| User explicitly started the step/session | `In progress` |
| Scheduled step is active now | `Active step` |
| Scheduled item starts soon | `Up next` |
| Ambitions selected unscheduled work for open time | `Recommended step` |
| Prior step needs a landing place | `Needs closure` |
| Plan drift requires repair | `Recovery` |
| Protected block is active | `Protected time` |
| Vacation/away is active | `Away mode` |
| Hard event/commitment is active | `Current commitment` |
| Multiple scheduled/hard items compete | `Schedule conflict` |
| Not enough context exists | `Set up today` |

The Reality Meridian must visually prove the resolved state. For `Active step`, the scheduled block remains at its actual scheduled time and the live current-time cursor remains exact; the Start Here Aperture attaches to the scheduled-current reality, not to generic AI recommendation language.

## Supersession Rule

If an older Today recipe suggests dense dashboards, stacked productivity cards, top-left primary CTAs, a top hero panel full of chips, a standalone `On-device` badge, a finite task-list rail, a generic recommendation card, or `best next step` copy, treat that reading as superseded for the default Today viewport.

Lower-level recipes still supply object, accessibility, proof, and state details, but the flagship composition is owned by `today_reality_meridian_flagship_surface.md`, and Start Here state/copy is owned by `../../START_HERE_REALITY_RECOGNITION_DOCTRINE.md`.
