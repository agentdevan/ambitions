# Today Visual Encyclopedia Recipes

Status: Active Today recipe portal
Authority: subordinate to `docs/truth/*` and `frontend/visual-encyclopedia/FRONTEND_AUTHORITY_INDEX.md`

Use this directory for Today-specific final-state visual canon. Today is the flagship daily execution surface and is governed by the Reality Meridian instrument.

## Active Flagship Viewport

Start here:

- [`today_reality_meridian_flagship_surface.md`](today_reality_meridian_flagship_surface.md)

This file owns the default Today viewport composition and hierarchy when lower-level Today recipes or older language conflict.

Locked requirements:

- Today is a living temporal surface, not a productivity dashboard.
- Reality Meridian is the primary object.
- The Reality Meridian is a scrollable vertical day spine; one screen is only one viewport state.
- Scheduled step nodes and the live current-time cursor are separate visual objects.
- The live current-time cursor uses an exact left-side label, for example `12:15 PM`.
- Start Here is sparse and integrated into the temporal field.
- `Start now →` is one-handable, right-side, and at or below vertical center.
- The top-right local-first lockup is `Local · Ambitions`.
- Future moments are lightweight time/title pairs, not boxed rows.
- Receipt/recovery is compact and calm.
- Bottom IA is exactly `Today / Goals / Capture / Time / You`.

## Supersession Rule

If an older Today recipe suggests dense dashboards, stacked productivity cards, top-left primary CTAs, a top hero panel full of chips, a standalone `On-device` badge, or a finite task-list rail, treat that reading as superseded for the default Today viewport.

Lower-level recipes still supply object, accessibility, proof, and state details, but the flagship composition is owned by `today_reality_meridian_flagship_surface.md`.

## Proof Boundary

This directory is visual canon. It does not prove SwiftUI implementation, simulator/device behavior, screenshot parity, accessibility conformance, release readiness, or hosted-CI validation.
