# Ambitions Visual Proof MCP

MCP03 is currently a scaffold for Ambitions-aware visual proof.

It is not generic screenshot tooling, and it does not automate Simulator capture until XcodeBuildMCP or an equivalent local workflow is verified for this repo.

## Planned Tools

- `list_visual_surfaces`
- `required_visual_states`
- `plan_surface_capture`
- `generate_fvq_packet_stub`
- `validate_visual_proof_folder_shape`

## Surfaces

- Today
- Goals
- Capture
- Time
- You
- Step Detail
- Step Session
- Goal Detail
- Receipt / Trust
- Recovery / Closure
- Onboarding

## Required States

- empty
- first useful object
- normal
- overloaded
- degraded
- recovery
- reduced motion
- large Dynamic Type
- VoiceOver-shadow equivalent
- privacy redacted external surface
