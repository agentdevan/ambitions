# Ambitions Twin Fixture MCP

MCP05 is currently a scaffold for Ambitions Twin fixtures.

Fixtures live under `fixtures/ambitions-twins/` and are not wired into production app runtime.

Planned MCP work:

- list fixture names
- validate fixture shape
- generate cross-surface proof fixture summaries
- route fixtures into future visual, accessibility, source, and release proof packets

No production app runtime dependency is created by this scaffold.
