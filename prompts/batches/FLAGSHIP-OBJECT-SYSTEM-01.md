## Required Work

### Phase 1 — Authority Alignment

Confirm the installed doctrine and architecture are discoverable from the Frontend Authority Index and Visual Encyclopedia master.

If missing, update those files.

### Phase 2 — Object Graph Core Contracts

Create or map Swift contract files for:

- `AmbitionObjectID`
- `AmbitionObjectNode`
- `AmbitionObjectState`
- `AmbitionObjectAction`
- `AmbitionObjectProof`
- `AmbitionObjectMotionContract`
- `AmbitionObjectAccessibilityContract`
- `AmbitionObjectPreviewContract`

These must be generic enough to support all flagship objects and strict enough to prevent shallow view-only objects.

### Phase 3 — Object Kernel Stubs

Create strongly typed kernel stubs for:

- `RealityMeridianObjectKernel`
- `StartHereObjectKernel`
- `ConstellationAtlasObjectKernel`
- `AtmosphereComposerObjectKernel`
- `LifeShapeFieldObjectKernel`
- `UserSystemProfileObjectKernel`
- `ReceiptObjectKernel`
- `ClosureRecoveryObjectKernel`

Each kernel must expose identity, destination, surface ID, current state, source/proof/receipt behavior, actions, motion contract, accessibility summary, preview scenario IDs, and known gaps.

### Phase 4 — Preview Scenario Contracts

Create preview-scenario scaffolding that defines required scenario sets for FO-P0 and FO-P1 objects.

At minimum define scenario names for:

- normal
- empty
- active
- blocked
- waiting
- needs recovery
- stale source
- proof missing
- receipt available
- high pressure / overloaded
- protected / away where relevant
- Dynamic Type XL/AX
- Reduce Motion
- Increase Contrast / Differentiate Without Color

### Phase 5 — Validation Gates

Add validation scripts that can fail when:

- FO-P0 object kernel is missing
- FO-P0 state machine or state list is missing
- FO-P0 preview matrix is missing
- FO-P0 accessibility contract is missing
- FO-P0 motion contract is missing
- forbidden shallow object pattern appears
- release/award readiness is claimed without proof

The scripts may be conservative and report YELLOW if static source discovery cannot be exact, but they must be useful and honest.

### Phase 6 — Reports And Next Batch

Create:

- `docs/audits/FLAGSHIP_OBJECT_SYSTEM_01.md`
- `build/reports/flagship-object-system-01.json`
