# AMB-526 / AOR-002 - Deterministic Screenshot Harness

Work directly on `main`. Do not create a branch. Do not open a PR.

## Mission

After AOR-001 proves the active root path, add Debug-only launch routing and establish a repeatable simulator screenshot path. This is proof infrastructure only, not a product UI redesign.

## Required Root Proof Before Edits

AOR-001 report exists at `artifacts/ambitions-ui-reconstruction/reports/AOR-001-report.md` and proves:

```text
AmbitionsApp -> LaunchGateView -> AmbitionsRootView -> SwiftUI TabView
```

`AmbitionsRootView.shellTabView(theme:)` owns tab selection and surface routing. `AppMeridianShell.swift` is support/preview only.

## Discover Before Use

```bash
xcodebuild -list
xcrun simctl list devices available
xcrun simctl list runtimes
```

Do not invent scheme names, workspace names, project names, simulator names, iPhone 17e, or iOS 26.3 unless present locally.

## Required Debug-Only Launch Args

Wire only under `#if DEBUG` and only through `ProcessInfo.processInfo.arguments`:

```text
-AmbitionsInitialSurface today
-AmbitionsInitialSurface goals
-AmbitionsInitialSurface time
-AmbitionsInitialSurface motion
-AmbitionsInitialSurface you
-AmbitionsScreenshotMode YES
```

## Expected Implementation Boundary

Preferred source owner: `Native/Ambitions/App/AppBootstrapper.swift`, because it already resolves Debug launch configuration from `ProcessInfo.processInfo.arguments` and creates the `AppContainer` before `LaunchGateView` presents `AmbitionsRootView`.

Allowed companion tests: focused app-shell/navigation tests under `Native/AmbitionsTests/App/`.

Do not change product UI surfaces, root IA, product copy, project/package files, runtime dependencies, privacy manifests, entitlements, or release/signing behavior.

- App builds or launches through discovered tooling.
- Today opens deterministically from launch args.
- At least one non-Today surface opens deterministically or navigation is documented.
- At least one screenshot file is saved under `artifacts/ambitions-ui-reconstruction/screenshots/`.
- Implementation is Debug-only.

## Yellow Gate

- Automation cannot run locally, but exact blocker and manual fallback are documented.

## Red Gate

- Production routing changes without proof.
- Hardcoded unavailable scheme/device.
- Visual success claimed without screenshots.
- TestFlight/App Store/release readiness claimed.
