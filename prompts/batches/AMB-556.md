# AMB-556 - AOR-CAPTURE-01 - Atmosphere Composer Activation

## Mission

Implement and prove the activated global Capture Atmosphere Composer states without making Capture a tab, persistent floating button, non-canonical intake surface, task board, category grid, prompt wall, or cloud-classification surface.

## Active Truth

- Read and follow `docs/truth/README.md`.
- Product/design truth: `docs/truth/PRODUCT_DESIGN_TRUTH.md`.
- Implementation/source truth: `docs/truth/IMPLEMENTATION_TRUTH.md`.
- Release/proof truth: `docs/truth/RELEASE_TRUTH.md`.
- Codex process truth: `docs/truth/CODEX_PROCESS_TRUTH.md`.
- Historical policy: `docs/truth/HISTORICAL_POLICY.md`.
- `AGENTS.md`.

Active IA stays exactly `Today / Goals / Time / Motion / You`.

`Capture` is the global action layer. Capture is not a top-level tab.

Activated Capture is `RuntimeRootShell + PlacementField + AtmosphereComposerLayer + OpenField + HeldObjectRouteTransformation`.

## Scope

Extend the existing app-shell activated Capture seam rather than creating a new Capture implementation.

Preferred source owner:

- `Native/Ambitions/App/AppShellView.swift`
- focused UI coverage in `Native/AmbitionsUITests/AmbitionsUITests.swift`

Allowed only if proven necessary:

- `Native/Ambitions/App/ShellCommandModels.swift`
- `Native/Ambitions/App/AmbitionsRootView.swift`
- AMB-556 proof report under `artifacts/ambitions-ui-reconstruction/reports/`

Avoid ordinary changes in locked Capture feature-owner source unless the parallel guard explicitly authorizes a Champion Merge or accepted-Yellow owner boundary.

Do not add app runtime dependencies, hosted services, external/cloud LLMs, analytics, telemetry, or new backend paths.

## Required States

The activated composer must honestly expose or prove:

- hidden before activation
- activated after contextual/toolbar Capture entry
- typing
- dictating, through the system keyboard/dictation affordance only; do not record audio
- keyboard visible/focused
- captured locally
- classifying locally, expressed as deterministic local placement review rather than synthetic confidence theater
- high-confidence route reveal
- low-confidence `Needs a Place`
- `Ready to Place`
- `Grow into Goal`
- `Held for Review`
- save error
- source/trust explanation
- large text usability
- Reduce Motion static meaning

## Runtime Trust Boundary

Do not create a new runtime, parser, placement engine, proof ledger, or receipt system.

Any runtime-affecting copy or affordance must preserve the existing SourceRecord, Receipt, ReplayTrace, and You / What Ambitions knows inspection path.

Local save/classification language must be honest: no cloud AI, no percentage confidence, no fake model certainty, no silent mutation.
