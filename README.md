# Ambitions

Ambitions is a native iPhone-first, local-first Personal Life OS.

The sole normative repository authority is [docs/canon/](docs/canon/). Start
with the generated [Codex router](docs/canon/generated/CODEX_START_HERE.md),
then use the bounded canon pack and tracked-change authorization flow it names.
