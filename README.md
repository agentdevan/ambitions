The repo authority starts at [docs/truth/README.md](docs/truth/README.md). Truth files define current canon and claim boundaries; live source, project files, tests, scripts, and current logs provide implementation and validation evidence.

- Supreme mission lens: Private Life Orchestration, defined in [docs/truth/PRIVATE_LIFE_ORCHESTRATION_TRUTH.md](docs/truth/PRIVATE_LIFE_ORCHESTRATION_TRUTH.md)

Motion is not a root destination. Capture is not a tab.
