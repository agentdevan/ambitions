# Ambitions 3.0 Demo Script

Status: Drafted from current repo evidence; use for internal/investor demo with limitations
Owner: Product Marketing / Demo Lead
Last updated: 2026-05-01

## Demo Boundary

This script demonstrates the Golden Launch Loop from current Ambitions 3.0 canon and repo evidence. It must not be presented as App Store submission approval, TestFlight distribution proof, physical-device proof, public accessibility proof, or final release approval.

Use privacy-safe fixture data only.

## Core One-Liner

Ambitions makes life feel organized by turning what is on your mind into a clear place, a believable plan, one step to start, and proof of what counted.

## Demo Fixture

Goal:

```text
Release 3 songs by August 1
```

Why this fixture:

- It is specific enough to show planning and proof.
- It avoids sensitive personal data.
- It demonstrates creative work without promising expert advice.
- It maps cleanly to Capture, Goals, Plan, Today, Reviews, and You.

## Demo Flow

### 1. Capture

Show `What needs a place?`

Narration:

Real life starts as a loose thought. Ambitions gives it a place before it becomes a scattered list.

Evidence:

- Capture is a canonical top-level destination.
- Smart placement and Needs a Place behavior are current repo seams.

### 2. Place

Show `Grow into Goal`.

Narration:

The app does not treat every thought as a generic task. It helps decide whether this belongs as a goal, a step, or something to revisit.

Evidence:

- Placement Resolver and Goals evidence are active canon/test surfaces.

### 3. Plan

Show `Does this hold together?`

Narration:

Ambitions checks whether the week can hold the work without pretending it can control the user's calendar.

Evidence:

- Plan tests cover believability, denied-calendar fallback, overloaded days, waiting/blocked posture, and suggestion-only recovery.

### 4. Today

Show `Start here`.

Narration:

Today is not a task dump. It gives the user one clear Step and enough context to understand why it matters.

Evidence:

- Today and Reality Rail tests protect Start here, Step Detail, privacy projection, and forbidden-copy rules.

### 5. Step Detail

Show `Why this?`

Narration:

The recommendation is explainable through visible context and user-owned controls, without model jargon or fake certainty.

Evidence:

- Recommendation and Today tests cover deterministic explanation labels and privacy-safe detail projection.

### 6. Close The Loop

Show `Close the loop` and `Still Counts`.

Narration:

When the day changes, Ambitions does not punish the user. It helps close the loop truthfully and save what still counted.

Evidence:

- Action Closure and Today tests cover Still Counts and proof-preview boundaries without unsupported persistence claims.

### 7. Proof Saved

Show `Proof saved`.

Narration:

Progress becomes evidence the user can return to, not a score.

Evidence:

- Proof/receipt contracts and release reports keep receipt visibility and privacy boundaries explicit.

### 8. You / What Ambitions Knows

Show `You are in control`.

Narration:

Ambitions shows what it knows, where it came from, and what the user can correct before it shapes future suggestions.

Evidence:

- F24 privacy/trust QA covers What Ambitions Knows, memory consent, receipt/proof visibility, and privacy-safe external projections.

## Investor Script

Ambitions starts where real life starts: with something important in your head.

You capture it. Ambitions gives it a place.

That place becomes a believable plan.

Today does not show a task dump. It shows where to start.

When the day changes, Ambitions does not mark failure. It helps you close the loop.

If progress still happened, Still Counts saves proof.

Every recommendation, change, and memory stays visible, correctable, and under the user's control.

## Demo Do Not Say

- This is approved for public release.
- This has been verified on physical devices.
- This has passed public accessibility verification.
- This is ready for App Store submission.
- This is ready for TestFlight distribution.
- This treats ADHD or any medical condition.
- This writes to the calendar automatically.
- This syncs to an Ambitions account.
- This uses cloud memory.
- This includes a subscription, trial, or paid unlock.
- This scores productivity.

## Demo Stop Conditions

Stop and record a follow-up if:

- visible copy implies unsupported readiness
- private data appears in a public/demo surface
- navigation requires old tab or old product knowledge
- a screenshot would imply unbuilt behavior
- visual overlap, clipping, or inaccessible reading order appears
- a demo operator cannot explain the evidence boundary
