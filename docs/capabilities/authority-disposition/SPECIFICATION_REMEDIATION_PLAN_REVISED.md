## Fragmented integrations—not independent gaps

- **Relevant Resource Resurfacing:** reconcile Planning, Source Atlas, Search, object relationships, and Local Learning; define why-now rationale, source/freshness, expiry, suppression, no-repeat behavior, owning placement, quiet fallback, and no private feedback egress.
- **Recovery Choice Preferences:** retain only non-destructive option influence. Do not personalize or preauthorize backup restore, repair, reset, continuity conflict resolution, source replacement, or destructive recovery.
- **Personalized Review and Closure Rhythm:** reconcile You review cadence, Notifications, Closure, and Local Learning; keep optional, object-scoped, quiet, non-gamified, suppressible, and separate from completion/Proof.
- **Alternate Career Path Simulation:** use existing Life Branch authority; add a career policy/profile only when roadmap work requires domain assumptions, public-source rules, sensitivity constraints, and no-prediction language.

## Explicitly avoided architecture

- No new Capability Atlas authority.
- No generic personalized-operational-rules system.
- No new capability/resource graph.
- No user-facing knowledge/influence dossier.
- No separate career simulation engine.
- No parallel sharing graph.
- No appearance authority outside You and design/accessibility standards.

## Required proof

Every accepted target requires exact state/command contracts, one canonical owner, privacy abuse tests, confirmation and semantic recovery, offline/no-account behavior, accessibility parity, deterministic behavior where durable, and rendered/device evidence before any shipping claim.
