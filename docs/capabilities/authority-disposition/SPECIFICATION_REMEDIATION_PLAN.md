## Additional specification alignment

### Global Search Ask

Current Search canon permits optional on-device conversational Ask but keeps it future-gated. Align the specification with the current owner decision by preserving deterministic bounded Understand and removing or narrowing conversational product language. This is not counted as a missing capability because evidence-backed Search understanding is already authoritative.

### Domain scenario profiles

Alternate Career Path Simulation should not become a separate simulation engine. Preserve the approved identity as a domain-specific policy/profile over Life Branch, Branch Viability Certificate, Source Atlas public references, privacy, and existing review/promotion law.

## Required proof for every accepted gap

- exact state and command contracts;
- owner and mutation boundary;
- privacy classification and egress abuse tests;
- current-revision confirmation and semantic Undo/recovery;
- offline/no-account behavior;
- VoiceOver, Dynamic Type, reduced-effects, focus, and nonvisual parity;
- deterministic replay or projection behavior where durable state changes;
- rendered and device evidence before any shipping claim.
