        # ADR-009 Accessibility Contracts Before Claims

        Status: Active architecture decision record

        ## Context

        This ADR is dated 2026-05-14 and applies only to the control-plane install batch.

        ## Decision

        Accessibility requires contract docs and proof gaps before any conformance claim.

        ## Consequences

        - Prevents false accessibility claims.
- Preserves honest validation posture.

        ## Status

        Accepted
