        # ADR-006 State Machine Over Generic MVVM

        Status: Active architecture decision record

        ## Context

        This ADR is dated 2026-05-14 and applies only to the control-plane install batch.

        ## Decision

        Critical flows are documented as object state machines rather than left as generic view-model assumptions.

        ## Consequences

        - Improves explicitness.
- Keeps recovery and correction visible.

        ## Status

        Accepted
