        # ADR-007 Source Proof Receipt Ledger

        Status: Active architecture decision record

        ## Context

        This ADR is dated 2026-05-14 and applies only to the control-plane install batch.

        ## Decision

        Source, proof, and receipt are distinct contracts and must stay inspectable.

        ## Consequences

        - Keeps correction paths explicit.
- Prevents false release claims.

        ## Status

        Accepted
