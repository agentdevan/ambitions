        # ADR-005 No Core Cloud LLM

        Status: Active architecture decision record

        ## Context

        This ADR is dated 2026-05-14 and applies only to the control-plane install batch.

        ## Decision

        The product core must not require a hosted/cloud LLM dependency.

        ## Consequences

        - Preserves privacy and local control.
- Avoids chatbot-driven architecture drift.

        ## Status

        Accepted
