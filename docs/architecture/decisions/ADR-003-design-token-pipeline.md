        # ADR-003 Design Token Pipeline

        Status: Active architecture decision record

        ## Context

        This ADR is dated 2026-05-14 and applies only to the control-plane install batch.

        ## Decision

        Design tokens are formalized as a source tree plus generated Swift contracts.

        ## Consequences

        - Creates deterministic token generation.
- Keeps generated code reproducible from token source.

        ## Status

        Accepted
