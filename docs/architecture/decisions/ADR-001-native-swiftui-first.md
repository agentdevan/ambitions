        # ADR-001 Native SwiftUI First

        Status: Active architecture decision record

        ## Context

        This ADR is dated 2026-05-14 and applies only to the control-plane install batch.

        ## Decision

        Ambitions is a native SwiftUI-first product system and should remain so for the foreground surface layer.

        ## Consequences

        - Preserves app quality and package compatibility.
- Keeps the control-plane install aligned with current source.

        ## Status

        Accepted
