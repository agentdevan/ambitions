        # ADR-008 Generated Token Contracts

        Status: Active architecture decision record

        ## Context

        This ADR is dated 2026-05-14 and applies only to the control-plane install batch.

        ## Decision

        Generated Swift token contracts are source-derived and must stay reproducible.

        ## Consequences

        - Enables drift checking.
- Keeps source of truth in DesignTokens.

        ## Status

        Accepted
