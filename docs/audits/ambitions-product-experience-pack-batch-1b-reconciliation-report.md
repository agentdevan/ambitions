## 11. Accent Reconciliation Summary

Severity: Yellow.

The Pack locks Gold as the default accent and launch accents as Gold,
Platinum, Rose, Cyan, Violet. Current repo evidence shows
`AmbitionAccentFamily` cases `sage`, `blueGray`, `mutedGold`, `copper`, and
`sand`, with `.sage` defaults in theme, persistence, and You editor state.

This is classified as a naming/token migration conflict with product
implications. It is not safe to fix silently in Batch 1B because token/default
changes can affect Appearance Studio, saved preferences, and shared UI
semantics.

Future treatment options recorded:

- Rename/map existing accent tokens to Pack taxonomy.
- Introduce compatibility mapping while preserving old internal values.
- Create a docs-only alias plan first.
- Stop for design-token implementation approval.

Recommended future treatment: docs-only alias plan first, then explicit
design-token approval before implementation.
