## Installed Chrome Standard

The installed chrome model is:

`Persistent Reality Context + One Privileged Action + Local Proof + Contextual Overlays`

This means Ambitions chrome should consistently preserve:

- compact contextual top edge
- bottom-reachable primary controls
- exact five-tab IA: `Today / Goals / Capture / Time / You`
- one dominant object per destination
- Reality Meridian and Start Here as Today flagship chrome
- local proof through receipt/proof/source affordances
- contextual sheets for closure, recovery, reflow, conflict, and proof
- conditional continuity strip for active execution or adaptation state
- accessibility-preserving state beyond color, glow, or motion
