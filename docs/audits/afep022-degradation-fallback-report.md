# AFEP-022 Degradation And Fallback Report

Issue: AMB-416 / AFEP-022
Date: 2026-06-01

## Summary

AFEP-022 adds degradation plans that keep elevated visuals, expensive render paths, and background work optional or deferable before the surface feels degraded.

## Deferable Vectors

- Elevated visuals
- Expensive render paths
- Background work

## Protected Vectors

- Query budget
- Launch budget
- Scroll budget
- Memory budget
- Wakeup budget
- Energy impact

## Boundary

This is a fallback scaffold, not a runtime policy change and not a measured performance claim.
