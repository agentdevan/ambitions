# Ambitions Multi-Agent Specialization

Status: ACTIVE

## Specialized Agent Roles

| Agent | Responsibility |
|---|---|
| Governance Agent | reconciliation, manifests, registry, authority |
| Canon Agent | canon propagation, supersession, ontology |
| Frontend Agent | flagship UI, encyclopedia bindings, visual integrity |
| Platform Agent | persistence, ledgers, runtime safety |
| Cleanup Agent | archive extraction, repo shrinking, stale overlay removal |
| Proof Agent | audits, tests, reports, lineage confidence |
| Release Agent | CI, branch orchestration, segmentation |

## Rule

Large autonomous operations should be segmented conceptually even if executed by one Codex runtime.

## Goal

Prevent:
- mixed authority decisions
- giant unfocused patches
- architecture drift
- canon inconsistency
- governance blind spots
