## Seven Step Loop

1. New direction is shaped with ChatGPT.
2. ChatGPT returns a runner-compatible prompt or installs a repo plan.
3. Repo governance propagates the change across canon, specs, prompts, manifests, generated governance outputs, frontend authority, encyclopedia authority, and archive candidates.
4. Global batch ordering updates by dependency, implementation readiness, and governance state instead of train origin.
5. Codex runs the global batch train through the Ambitions runner.
6. Codex implements with flagship quality, governance, cleanup, validation, and rollback discipline.
7. Completed app behavior must match active canon, generated specs, implementation expectations, and completed batch evidence.
