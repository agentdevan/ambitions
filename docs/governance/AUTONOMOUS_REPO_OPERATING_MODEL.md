# Ambitions Autonomous Repo Operating Model

Status: ACTIVE

## Purpose

Defines the intended long-term operating model for Ambitions.

Ambitions is no longer treated as:
- a passive source repository
- a manually curated documentation set
- a loosely governed AI-assisted codebase

Ambitions is now treated as:
- a continuously self-normalizing repo operating system
- a canon-propagating governance system
- a proof-aware execution control plane
- a continuously hygienic autonomous development environment

## Core Operating Loop

1. Canon changes.
2. Repo doctor runs.
3. Canon impact maps regenerate.
4. Governance reconciliation regenerates.
5. Prompt rewrite plans regenerate.
6. Supersession plans regenerate.
7. Cleanup plans regenerate.
8. Encyclopedia/frontend authority validates.
9. Governance Reds block expansion.
10. Codex repairs until governance passes.

## Long-Term Goal

Eventually:
- generated governance becomes primary operational truth
- stale overlays disappear automatically
- historical extraction becomes deterministic
- canon propagation becomes semantic and symbol-aware
- implementation ownership becomes exact
- prompt rewriting becomes autonomous
- governance drift becomes difficult to introduce
- repo size trends downward operationally over time

## Anti-Sprawl Principle

Every new addition must:
- justify its existence
- identify its owner
- identify its authority tier
- identify its retirement path
- integrate into governance outputs

Anything that cannot do this is operational debt.
