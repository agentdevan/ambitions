# Ambitions Sprawl Budget

Status: ACTIVE

## Purpose

Defines hard governance limits to prevent uncontrolled operational growth.

## Budgets

| Category | Limit |
|---|---|
| Active top-level governance docs per subsystem | 15 |
| Active prompts per train family without supersession | 50 |
| Unresolved orphan prompts | 0 in strict mode |
| Duplicate active operational states | 0 |
| Simultaneous active canon overlays for same concern | 1 |
| Active unresolved governance Reds | 0 |
| Accepted Yellow advisories per subsystem | Must trend downward |
| Generated artifacts committed without source generator | 0 |
| Unknown ownership files in active governance areas | 0 |

## Hard Rules

If budgets are exceeded:
- governance remediation outranks feature expansion
- new overlays are blocked
- new canon layering is blocked

## Goal

The repo should become:
- smaller operationally
- clearer structurally
- more deterministic over time

—not more sprawling.
