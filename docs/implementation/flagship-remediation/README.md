# Ambitions Flagship Remediation

Repo-side package for the Linear project `Ambitions Flagship Remediation Program`.

Installed files:
- `.linear/projects/AMB-FLAGSHIP-REMEDIATION/project.md`
- `.linear/projects/AMB-FLAGSHIP-REMEDIATION/linear_issues.csv`
- `.linear/projects/AMB-FLAGSHIP-REMEDIATION/linear_issues.json`
- `prompts/projects/AMB-FLAGSHIP-REMEDIATION.md`
- `prompts/batches/AMB-FLAGSHIP-REMEDIATION/`
- `.codex/manifests/ambitions-flagship-remediation.json`
- `scripts/validate_flagship_remediation.sh`

Operating model: Linear owns issue tracking. Codex owns scoped implementation. The repo owns source truth, validation, and proof artifacts.
