# 13 — Cognitive Ergonomics and Copy Compression

## Core law

Low cognitive load is the effort required to find and interpret meaning, not the amount of meaning visible. Ambitions should maximize **information value per required read**, not minimize content.

## Operating measures

- **Meaningful facts at rest:** typical first viewport should expose approximately 5–8 useful facts through text, structure, position, state, and relationship.
- **Required reading:** roughly 35–55 words at rest for complex root/focused-object viewports; exact count is subordinate to comprehension.
- **Hierarchy recognition:** identity, current truth, material condition, and primary action should be locatable within a brief glance.
- **Repeated explanation:** zero repeated semantic sentence in one viewport.
- **Action explanation:** consequence copy appears only when the action is material, uncertain, destructive, or cross-owner.
- **Progressive disclosure:** moves detail/provenance/history deeper, never identity, current truth, consequence, owner route, or return.

## Copy roles

| Role | Budget/behavior |
| --- | --- |
| Identity | 1 concise line; may wrap once |
| Direction/current truth | 1 short sentence or structured phrase |
| Material qualification | 1 phrase; no stacked badges |
| Consequence | 1 humane sentence only when needed |
| Evidence/Proof | compact summary; details deeper |
| Primary action | verb-led, plain, one line |
| Secondary context | labels/values or aligned compact rows |
| Help/explanation | disclosure, not first-viewport paragraph |

## Recognition over recall

- Preserve surrounding Life Areas/Goals when focusing one pursuit.
- Use stable ordering, identity, and owner symbols.
- Keep accepted/current/adaptable distinctions spatially stable.
- Make return and next action explicit; do not require remembering the previous screen.

## Paired quality checks

Every simplification must show:

- reading burden decreased **and** informational richness preserved;
- visual noise decreased **and** adult sophistication preserved;
- number of actions reduced **and** context required to choose preserved;
- copy removed **and** its meaning encoded elsewhere.

Goals R01 fails reading burden. Goals R02 fails informational richness. R03 must pass both axes.
