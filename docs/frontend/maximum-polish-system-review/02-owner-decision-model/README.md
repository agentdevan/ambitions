# 02 — Owner Decision Model and Review Engine

## Demonstrated owner preferences

| Dimension | Demonstrated preference | Hard-fail signal |
| --- | --- | --- |
| Product maturity | Adult, premium, composed, clearly authored | Juvenile scale, toy-like symbols, giant simplistic controls |
| Perceived intelligence | Rich context is visible without explanatory essays | Empty surfaces that imply the system knows very little |
| Reading burden | Rapid scan, short copy, visual encoding first | Serial paragraphs, repeated explanations, specification prose |
| Spatial composition | One dominant composition with meaningful relationships | Generic vertical card stacks or disconnected floating objects |
| Native credibility | Native navigation/controls/material behavior with Ambitions-specific composition | Custom mechanics that compete with Back, safe areas, focus, or system convention |
| Density | Information-rich but legible; depth should reward attention | Either cluttered “everything at once” or extreme subtraction |
| Distinctiveness | Recognizably Ambitions, not a template | Generic Apple imitation, dashboard, task manager, or children’s habit tracker |
| Action hierarchy | One unmistakable next action earned by context | Command card/button that visually outranks identity and truth |
| Emotional character | Calm, alive, consequential | Sterile prototype or decorative atmosphere detached from meaning |
| Evidence | Strong proof after concept validity | Gate-passing used to defend an undesirable concept |

## Confidence classes

- **Demonstrated:** repeated owner decisions or direct rejection language.
- **Probable:** consistent inference from approved comparisons but not explicitly stated.
- **One-off:** local wording that should not be generalized without another example.

## Review engine

Score each dimension 0–4. A candidate is not numerically “approved”; the score routes judgment.

- **Automatic REJECT:** any hard fail in maturity, perceived intelligence, native credibility, or core product meaning.
- **REJECT:** owner-fit score below 26/40, or the candidate solves feedback by destroying another protected quality.
- **REVISE:** 26–33/40 with no hard fail and a coherent architecture worth preserving.
- **APPROVE recommendation:** 34–40/40, no hard fail, current canon preserved, and no unresolved contradiction that changes the first viewport.

Owner approval remains explicit and cannot be inferred from this engine.

## Mandatory review questions

1. Does the screen look appropriate for an intelligent adult managing a complex life?
2. Can the first viewport communicate more than one useful fact without requiring a paragraph?
3. Is the dominant action visibly earned by identity, truth, trajectory, or consequence?
4. Would the composition still feel premium if all decorative effects were removed?
5. Does it look and behave native without becoming generic?
6. Did the revision preserve the valuable qualities of the rejected predecessor while fixing the actual problem?
7. Is the candidate being advanced because it is good, or because an expensive proof package already exists?
