# 11 — Golden-Master Visual Regression System

## Catalog posture

Shell and Time can serve as provisional visual baselines. Today is blocked from pixel-level cataloging because its complete final package is absent from this archive. Goals and Global Object Language are explicitly excluded.

## Delta classes

- **Intentional evolution:** owner-approved change with a new stable ID and preserved semantic contract.
- **Acceptable variability:** content length, locale, state density, accessibility recomposition, supported device geometry.
- **Suspicious drift:** typography amplitude, spacing rhythm, material role, action hierarchy, or object ordering changes without a decision record.
- **Forbidden regression:** root/global ownership change; identity/truth/action inversion; reappearance of rejected anti-pattern; meaning that depends only on color/effect; native Back/safe-area/focus break.

## Review protocol

1. Identify canonical frame ID and environment.
2. Compare geometry, hierarchy, typography relationships, material boundaries, and semantic ordering.
3. Classify every material delta; unclassified deltas fail review.
4. Run owner-fit review for novel direction; golden-master match alone is not proof of quality.
5. Do not promote Simulator frames to physical-device baselines.

See `GOLDEN_MASTERS.json` for the catalog.
