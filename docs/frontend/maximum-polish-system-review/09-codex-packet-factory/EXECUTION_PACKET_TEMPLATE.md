# Maximum Polish Bounded Execution Packet

## Objective
One sentence describing the exact deliverable.

## Entry gate
Facts that must already be true. If false, stop.

## Authority
Ordered source list: current owner decisions → current canon → approved evidence → candidate/negative evidence.

## Protect
Qualities and decisions that must survive.

## Correct
The specific failure or unresolved question.

## Forbidden reopenings
Decisions outside scope.

## Evidence to inspect
Exact files/boards/logs; no corpus-wide rescan.

## Likely implementation surface
Exact files/targets if implementation is authorized.

## Deliverable boundary
What is produced in this packet.

## Acceptance criteria
Observable and traceable conditions.

## Proof order
Cheapest decisive proof first; expensive proof last.

## Stop conditions
Architecture hard fails, repeated repair limit, missing authority, or invalid baseline.

## Rollback
How to abandon the candidate without changing production/canon.

## Explicit non-goals
Production integration, canon change, broad reconstruction, unrelated refactor, invented owner approval.

## Final response
Decision point, evidence locations, exact ceiling, and one next action.
