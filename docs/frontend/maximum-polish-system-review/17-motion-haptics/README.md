# 17 — Motion, Continuity, and Haptic Choreography

## Motion law

Motion communicates causality, ownership transfer, temporal movement, and return. It is sparse, interruptible, and never used as ambient decoration.

| Event | Motion intent | Reduce Motion equivalent | Haptic intent |
| --- | --- | --- | --- |
| Root switch | brief spatial/context transition while independent path persists | immediate content replacement + focus/heading update | none |
| Dock hide/reveal | follows deliberate scroll with hysteresis; no target jump | instant bounded state change | none |
| Object focus | source object expands/transfers into owned depth | direct push/fade preserving identity | none |
| Time scale change | preserve anchor date/object while scale transforms | direct scale replacement with persistent anchor label | light selection only if useful |
| Proposed → accepted | proposal separates, commit settles into accepted structure | labelled pending then accepted replacement | success only after durable settlement |
| Failure/recovery | failed operation returns to retained truth and repair action | explicit state replacement | warning/error only for material failure |
| Completion/closure | restrained settlement into Proof/history continuity | static completion state | success if user-triggered and settled |
| Search/Capture present | temporary global passage from initiating origin | full-screen presentation without travel effect | none |
| Search/Capture return | exact origin/focus restored or explained fallback | immediate return + focus announcement | none |
| Keyboard | native coordinated avoidance; no custom competing animation | native behavior | none |

## Proof gaps

The corpus includes motion recordings and timing contracts, but not production-wide motion, actual haptic calibration, device ProMotion/performance, interactive Back arbitration, or full Reduce Motion manual proof. These remain implementation/device gates.
