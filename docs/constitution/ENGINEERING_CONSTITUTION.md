## First-Class Green

A launch-required opportunity is First-Class Green only when every applicable dimension is Green:

```text
constitutional / product / architecture / domain / runtime / persistence /
concurrency / frontend / accessibility / privacy-security / performance /
reliability / integration / QA / visual / release
```

Source presence, documentation, one passing test, or one screenshot cannot substitute for integrated acceptance.

This annex is constitutional direction, not implementation proof.
