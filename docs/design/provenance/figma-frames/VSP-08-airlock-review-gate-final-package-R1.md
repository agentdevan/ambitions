- Today / Goals / Time / You remain the only persistent surfaces.
- Capture remains global composer, not a tab/root surface.
- Motion remains behavior, not a root destination.
- Proof / Source / Privacy / History / Receipts remain inspection details.
- VSP-08 is an external-boundary inspection/content layer only.
- Offline no-account core value remains usable.
- Ambitions Account remains optional identity, entitlement, recovery, and support only.
- R2 / Source Atlas remains public/reference/freshness infrastructure only.
- Private life graph egress remains forbidden.
- Goals, captures, schedule, proof, receipts, behavior, inferred priorities, personalization, and private user context may not be sent to R2, Source Atlas, external tools, or hosted AI.
- External/cloud LLMs are not core runtime architecture.
