## Production Gate Review

- Shell contamination: pass for exploration. No VSP-04 frame invents VSP-01 shell chrome.
- Product law: pass for exploration. Today / Goals / Time / You remain the only root surfaces; Capture is not a tab; Motion remains behavior; trust details remain inspection-only.
- Calendar-grade target: pass for exploration. All options begin from a native month calendar grammar instead of an anti-calendar or abstract day/week field.
- Dashboard/KPI drift: Yellow. Options A, B, D, and E must keep semantic overlays inside the month object instead of spawning side metrics.
- Today boundary: Yellow. Option C's aperture behavior must not pull Time back into Today-owned day timeline/current-step territory.
- Typography/spatial gate: repaired after export inspection. SF Pro text did not render into PNG proof, so all proof text was switched to Inter with a recorded boundary that SwiftUI remains system-font/SF aligned. The option-label/boundary-panel collision and cramped protected/recovery chips were repaired before final PNG export.
- SwiftUI plausibility: Yellow. Major objects are plausible as SwiftUI month grid, LazyVGrid/custom Layout, Canvas/GraphicsContext semantic overlays, event chips, and static reflow markers, but no source implementation or parity proof exists.
- Accessibility: Yellow. Required acceptance includes current date, current zoom level, fixed points, open capacity, protected windows, pressure seams, Today anchor, VoiceOver month summary, Dynamic Type stress, Reduce Motion static equivalent, Reduce Transparency, and Increase Contrast proof. None of that is proven yet.

## Current Recommendation

F is the strongest candidate if the floor is replacing the user's month calendar plus reminders. It preserves the familiar native month calendar first, then adds Ambitions-native meaning at native density.

C should be treated as a behavior candidate, not the root visual direction by itself. B, D, and E are strong semantic overlays, but they should stay subordinate unless the owner intentionally chooses one as the primary Time philosophy.

Do not synthesize yet. Select one primary direction, then build the complete VSP-04 candidate package around that direction.
