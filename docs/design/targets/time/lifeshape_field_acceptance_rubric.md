# LifeShape Field Acceptance Rubric

Status: Active rubric  
Applies to: Time root LifeShape Field visual review and shell integration

Pass requires every hard gate below.

## Frame And Hierarchy

- Primary object starts in the first viewport.
- Primary object occupies at least 45 percent of first viewport height.
- No more than one top-level material container appears before the primary object.
- One primary CTA maximum in the first viewport.
- Detail, correction, inspection, proof, and receipt UI are not root siblings before user intent.
- Time reads as one full-bleed stage, not header plus boxed content plus dock.

## Single Ownership

- Exactly one visible context crown.
- Exactly one Capture access point.
- Exactly one Search access point.
- Dock ownership remains shell-owned.
- Product object does not duplicate shell context.
- Shell crown and dock are integrated into the surface atmosphere.

## Shell Integration

- No hard header slab.
- No visible shell/content divider.
- No pasted dock pill.
- No duplicate bottom shelf.
- Dock is visually subordinate to the primary object.
- Crown controls are functional and quiet, not utility blobs.
- Content remains safe under status bar, crown, dock, keyboard, and Dynamic Type.

## Visual Object

- Field shape carries meaning visually before text.
- Primary object is a horizontal / Weather-discipline LifeShape Field Band, not a radial dial.
- Open/protected/pressure/buffer are visible as layers or bands inside one object.
- Fixed points are visible as marks inside the object.
- Now/current marker is integrated into the field.
- Selected layer state is visually connected to the field.
- Selected bucket includes time range, fit, and one action.

## Copy And Language

- No root explanatory paragraph before the field.
- No root semantic jargon generated from architecture names.
- No root `ridge`, `contour`, `basin`, `bridge`, `lane`, `seam`, `trace`, or `pocket` unless explicitly approved for that visible state.
- No fabricated minimum-count capacity claims.
- Copy outside labels and controls remains secondary to the field.
- Copy uses human reality language such as open now, next fixed point, selected window, protected, tight, or needs buffer.

## Accessibility And Device

- Dynamic Type variant remains coherent and unclipped.
- VoiceOver semantics mirror the visual field.
- Reduce Motion preserves comprehension.
- Reduce Transparency preserves legibility.
- High Contrast preserves object hierarchy.
- Physical iPhone proof is required for Visual Green.

## Status Ceiling

- Simulator screenshot only: Yellow maximum.
- Local `.codex` screenshot path only: not visual proof.
- Codex self-review only: Ready for Visual Review maximum.
- Independent review plus attached target/actual comparison plus device proof: eligible for Visual Green.

## Global Shell Completion Note

This rubric can make Time Visual Review Ready, but it cannot make global shell work complete. Global shell completion also requires all root surfaces, major drilldowns, Capture, Search, Closure, and Inspection routes to pass the global shell manifest evidence table.
