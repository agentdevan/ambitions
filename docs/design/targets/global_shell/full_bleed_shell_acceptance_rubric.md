# Full-Bleed Global Shell Acceptance Rubric

Shell Green requires an integrated crown, integrated dock, safe full-bleed atmosphere, one dominant product object, correct route-depth chrome, accessibility safety, and reviewable screenshots.

## Blockers

- hard header slab
- duplicate crown ownership
- pasted dock
- dock over content
- root dock on detail routes
- boxed page body
- decorative wallpaper atmosphere
- source-only proof
- local screenshot paths as acceptance evidence

## Required proof

- route screenshot
- target-vs-actual critique
- accessibility variant proof
- independent visual review for Visual Accepted
