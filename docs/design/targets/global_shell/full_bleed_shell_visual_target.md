# Full-Bleed Global Shell Visual Target

Status: Active target for AMB-1180 and future global shell work.

## Target statement

Ambitions should feel like one full-bleed native object stage. The shell is not a frame. The Context Crown, active surface object, horizon/detail rows, overlays, and Continuity Dock all sit inside one continuous graphite/North-Star atmosphere.

## Visual family

- full-bleed graphite/OLED stage
- quiet glass controls where they have a job
- luminous trace only for selected state, proof, route, or boundary
- surface-specific atmosphere that remains Ambitions-native
- no bordered header slab
- no pasted dock pill
- no carded page body inside app chrome

## Required anatomy

Root surface:

- integrated Context Crown
- active product object as first-viewport hero
- surface-specific controls absorbed into object or crown
- integrated Continuity Dock, visually subordinate
- atmosphere visible behind status bar, crown, object, rows, and dock

Detail route:

- reduced crown with native back
- no root dock
- focused object content
- safe full-bleed atmosphere continues

Composer route:

- composer owns stage
- root dock hidden
- keyboard choreography safe
- controls belong to composer, not duplicated shell

## Visual red fixtures this target rejects

- hard header bar above content
- dock floating as a pasted pill
- duplicate crown inside surface content
- boxed dashboard page body
- large content card containing the entire surface
- nested material panels in the first viewport
- scenic wallpaper or decorative stars
- neon HUD
- selected state as giant white slab

## North Star phrasing

A functional, modern shell that blends into every active surface and never looks bordered off.
