# LifeShape Open Ring Gauge Failure

Status: Red fixture

This fixture preserves the failure where Time becomes a radial gauge instead of a truthful LifeShape Field Band.

Must not recur:

- radial dial as the primary root Time object
- decorative arcs without direct Time semantics
- giant center state replacing time range, next fixed point, selected window, and protected boundary
- layer selector visually disconnected from the field
- selected bucket pasted on as a card instead of integrated into the field

Required replacement: horizontal Weather-discipline field band with now marker, selected time window, fixed-point ticks, protected boundaries, horizon rows, and one action.
