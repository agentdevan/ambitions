## Purpose

The Signature Experience Layer defines the premium experiential bar for future
DAV, SIG, Transformative Motion, and UI-heavy External Brain work.

It does not create a second visual identity. It extends the existing
DAV/PXEQ/photo-matched system so Ambitions feels emotionally desirable before
the user understands the intelligence underneath.

## Principles

- Love before logic: the first impression should feel calm, premium, and
  personally useful before the system explains itself.
- Motion as meaning: movement exists only to show state, ownership, continuity,
  receipt, recovery, or focus.
- Beauty as clarity: visual polish must make the next action easier to see.
- Minimalism with utility: fewer visible objects, richer meaning per object.
- Living but not busy: state may feel alive, but never noisy or decorative.
- Conservative futurism: dark graphite, refined material, soft edge light, and
  native iPhone believability over spectacle.
- Trust before intelligence: proof, receipts, source, correction, and control
  are more important than looking smart.
- Accessibility as design: Dynamic Type, VoiceOver, Reduce Motion, non-color
  meaning, and motor alternatives are part of the visual system.
- No gimmicks: no neon, fake AI glow, dopamine loops, or animation without
  product meaning.
- Product-still fidelity: visual objects should read like premium studio
  product photography, not dashboard widgets.
- No visual identity split: SIG extends DAV/PXEQ/photo-matched references.

## Required Evidence For UI Work

Every future DAV/SIG UI batch must record:

- photo-matched reference paths inspected;
- primary visual object;
- before/after product-experience impact;
- preview evidence;
- Reduce Motion equivalent;
- Dynamic Type and VoiceOver evidence;
- performance/battery risk review;
- no generic dashboard/task-list/SaaS drift;
- claim boundaries.

## Claim Boundaries

This layer is an execution and review standard. It does not claim shipped
feature behavior, production readiness, App Store readiness, TestFlight
readiness, public accessibility conformance, physical-device proof, or Apple
award status.
