# HBI Source Family

Status: Active frontend source-family map
Kind: source_family
Destination: Cross-surface

## What It Is

HBI is a source family and overlay input, not a frontend object or visual object family. It exists to capture historical-baseline direction from `docs/codex/HISTORICAL_BASELINE_*`, then map that direction onto real Ambitions surfaces, states, receipts, and recovery comparisons.

## What It Is Not

HBI is not a visual object family, not implementation proof, and not release proof.

## Where It Appears

HBI contributes cross-surface source meaning through Goals, Time, Today, and You wherever historical comparison, recovery context, or proof continuity matters.

## Source-Family Role

- Source truth flows from `docs/truth/*` first.
- HBI adds source-direction input only when it is compatible with active truth.
- Any HBI-derived visual direction must be remapped to a real surface, object, or state before it is treated as canon.

## Visual Direction Extracted

- Historical comparison must remain inspectable.
- Recovery and proof continuity must be visible instead of implied.
- Stale/fresh comparison must map onto actual surface states.
- Baseline comparison must not become a score, streak, or ranking mechanic.
- Source freshness and archive context must stay attached to the real object they explain.

## Accessibility

Dynamic Type keeps the object summary and primary action visible. VoiceOver exposes object summary, state, source, and available actions. Reduce Motion uses static state and before/after equivalents. ADHD usability requires one primary next action and no urgency mechanics.

## Must Never Be

Not a card-stack dashboard, chatbot, decorative space effect, score/streak/ring, sportsbook interaction, generic task row, or uninspectable recommendation.
