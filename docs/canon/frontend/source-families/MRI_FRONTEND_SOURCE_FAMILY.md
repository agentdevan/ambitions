# MRI Source Family

Status: Active frontend source-family map
Kind: source_family
Destination: Cross-surface

## What It Is

MRI is a source family and overlay input, not a frontend object. It exists to collect Moat Runtime Integration direction from `docs/codex/MOAT_RUNTIME_*`, then map that direction onto real Ambitions surfaces, states, receipts, and trust affordances.

## What It Is Not

MRI is not an object bible, not a visual object family, not implementation proof, and not release proof.

## Where It Appears

MRI contributes cross-surface source meaning through Today, Capture, You, and other trust-adjacent surfaces where local runtime, recommendation source, correction, or proof visibility matters.

## Source-Family Role

- Source truth flows from `docs/truth/*` first.
- MRI adds source-direction input only when it is compatible with active truth.
- Any MRI-derived visual direction must be remapped to a real surface, object, or state before it is treated as canon.

## Visual Direction Extracted

- Local runtime meaning must be inspectable.
- Recommendation source must be visible without model jargon.
- Correction and preview states must preserve a clear return path.
- Receipt and proof meaning must stay attached to the affected surface.
- Source freshness and recovery must be explicit rather than implied.

## Accessibility

Dynamic Type keeps the object summary and primary action visible. VoiceOver exposes object summary, state, source, and available actions. Reduce Motion uses static state and before/after equivalents. ADHD usability requires one primary next action and no urgency mechanics.

## Must Never Be

Not a card-stack dashboard, chatbot, decorative space effect, score/streak/ring, sportsbook interaction, generic task row, or uninspectable recommendation.
