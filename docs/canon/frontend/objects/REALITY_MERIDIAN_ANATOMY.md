# Reality Meridian Anatomy

Status: Active primary-object canon
Destination: Today

## User-Facing Role

Reality Meridian is the Today object that shows what fits now, what needs closure, and what source or proof explains the current state.

## Product Meaning

- Current-state orientation.
- Start Here visibility.
- Closure without shame.
- Proof-preserving action.

## Label-Off Visual Signature

- One dominant current-state band.
- A visible Start Here region.
- A closure or recovery seam.
- A source/proof line that is not decorative.

## Canonical Structure

- top orientation
- dominant now band
- Start Here region
- now/next/later rail
- step detail or session seam
- proof/receipt seam

## Visible Zones

- current context
- primary step
- supporting commitments
- source freshness
- receipt or proof

## Allowed States

- active
- empty
- recovery
- blocked
- waiting
- stale source

## Forbidden States

- dashboard
- task list
- chatbot
- calendar clone
- score/streak/ring

## Primary Actions

- Start now
- Open step
- Close loop
- Review source

## Secondary Correction Paths

- adjust recommendation
- open source sheet
- hold for later
- recover blocked step

## Proof Behavior

Proof stays attached to the state that produced it and is visible as a receipt or evidence line.

## Receipt Behavior

Receipts must be compact and recoverable, not noisy toasts.

## Source / Trust Behavior

The source should say why this step fits now and how to correct it if the recommendation is stale.

## Local-Runtime Behavior

Local runtime may explain why the app knows what it knows, but it must stay inspectable and user-controlled.

## Evolution Over Time

Reality Meridian may refine the way it groups current state, but it must never stop being a current-state object.

## Failure States

- too many competing actions
- hidden source
- stale recommendation treated as fact
- no obvious recovery path

## Recovery Behavior

- reduce density
- keep one dominant action
- expose the source
- preserve proof

## ADHD Density Law

One dominant action at rest. No more than one unresolved attention object above the fold.

## VoiceOver Summary / Order

Object -> state -> source -> action -> recovery.

## Dynamic Type Behavior

Text can grow without hiding the dominant current-state object or its primary action.

## Reduce Motion Behavior

Meaning survives without animation; before/after summaries replace movement.

## Reduce Transparency Behavior

Glass becomes opaque graphite layers if needed.

## Increase Contrast Behavior

State boundaries and recovery affordances get stronger.

## Differentiate Without Color Behavior

Shape, icon, label, and spacing must still encode state.

## Native iPhone Believability Requirements

- feels like a native iPhone current-state surface
- uses restraint, not spectacle
- keeps actions thumb-reachable

## Anti-Generic Red Flags

- task list
- dashboard
- calendar clone
- assistant persona

## Recipe Dependencies

- Today root
- Start Here region
- reality rail
- recommendation source sheet
- closure sheet
- receipt detail

## Source-Link Status

Linked through the live Today source candidates in `VISUAL_SOURCE_LINKS.yaml`.

## Good vs Bad Interpretation

- Good: "what fits now, why, and how to close or recover it."
- Bad: "a prettier task list with a recommended item."
