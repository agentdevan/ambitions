# Material Primitive Roles

Status: Active material-role canon

## GraphiteRecess

- role: grounded plane
- allowed: base layer, stable support, calm depth
- forbidden: generic card background, cheap dark tile

## QuietGlass

- role: elevated inspectable layer
- allowed: sheet, tray, transient explanation plane
- forbidden: frosted card stack everywhere, unreadable blur

## LuminousTrace

- role: state/source/proof continuity
- allowed: connection, freshness, motion path
- forbidden: neon stripe, decorative glow, HUD line

## CelestialField

- role: semantic background orientation
- allowed: relationship, continuity, meaning field
- forbidden: stars, particles, fantasy skybox

## Accessibility Concern

Material must never be the only carrier of meaning.
