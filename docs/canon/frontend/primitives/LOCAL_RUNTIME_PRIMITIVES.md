# Local Runtime Primitives

Status: Active primitive role set

## Local Runtime Mark

- marks on-device behavior and local knowledge

## User-Set Mark

- marks explicit user choice

## Stale Source Mark

- marks a source that needs refresh or correction

## Source Freshness Badge

- marks how recent or authoritative a source is

## Runtime Status Panel

- shows runtime posture, trust, and local control

## Accessibility Concern

The user must be able to inspect runtime meaning without relying on small icons or color alone.
