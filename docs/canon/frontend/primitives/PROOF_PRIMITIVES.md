# Proof Primitives

Status: Active primitive role set

## Proof Chip

- compact evidence token
- allowed: receipts, attachments, confirmations
- forbidden: generic badge decoration

## Purpose

Represent evidence in a way that keeps proof attached to the state that created it.

## Allowed Use

- receipts
- attachments
- confirmations

## Forbidden Use

- generic badge decoration
- ranking ladder
- score theatrics

## Canonical Anatomy

- chip
- ladder
- transfer thread
- gap marker

## Allowed Surfaces

- the active five destinations only
- shared shell proof seams
- bounded drill-down surfaces that preserve origin

## Forbidden Surfaces

- scoreboards
- streak widgets
- leaderboard chrome
- decorative badges with no evidence role

## State Variants

- attached
- transferred
- missing
- weak
- strong

## Source / Proof / Receipt Behavior

Proof must read as evidence, not gamification.

## Accessibility Fallback

Proof must be readable as text and structure, not color alone.

## ADHD Safety Note

Proof should reassure or correct, not shame.

## Proof Ladder

- stepwise proof chain
- allowed: progression of evidence
- forbidden: score or ranking ladder

## Proof Transfer Thread

- moves proof across surfaces while preserving origin
- allowed: pivots, capture promotion, closure
- forbidden: silent mutation

## Proof Weight

- shows how much evidence supports the state
- allowed: light / medium / strong support
- forbidden: numeric scoring theatrics

## Proof Gap

- shows missing evidence
- allowed: recovery prompts
- forbidden: shame language

## Misuse Examples

- badge farm
- score ladder
- opaque progress icon

## Recipe Examples

- receipt detail
- proof trail
- closure sheet

## Validator Hooks

- proof behavior
- receipt behavior
- transaction behavior
