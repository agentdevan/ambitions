# Proof Primitives

Status: Active primitive role set

## Proof Chip

- compact evidence token
- allowed: receipts, attachments, confirmations
- forbidden: generic badge decoration

## Proof Ladder

- stepwise proof chain
- allowed: progression of evidence
- forbidden: score or ranking ladder

## Proof Transfer Thread

- moves proof across surfaces while preserving origin
- allowed: pivots, capture promotion, closure
- forbidden: silent mutation

## Proof Weight

- shows how much evidence supports the state
- allowed: light / medium / strong support
- forbidden: numeric scoring theatrics

## Proof Gap

- shows missing evidence
- allowed: recovery prompts
- forbidden: shame language

## Accessibility Concern

Proof must be readable as text and structure, not color alone.
