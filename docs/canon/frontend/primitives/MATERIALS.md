# Materials

Status: Active frontend primitive bible

## Definition

GraphiteRecess, QuietGlass, LuminousTrace, and CelestialField only when semantic.

## Allowed Use

Use this primitive when it clarifies object hierarchy, state, source, proof, receipt behavior, or a native iPhone control path.

## Forbidden Use

Do not use this primitive as generic decoration, fake intelligence chrome, hidden-only affordance, or color-only state.

## Accessibility Requirements

Dynamic Type, VoiceOver, Reduce Motion, contrast, motor alternatives, and ADHD usability must be specified before implementation is considered complete.

## Source Truth And Proof

Source truth: `docs/truth/PRODUCT_DESIGN_TRUTH.md`, `Sources/Theme/AmbitionTheme.swift`, `Sources/Accessibility/AccessibilityNutrition.swift`, and matching SwiftUI source when present. Proof required: screenshot/state matrix and accessibility notes for any implementation change.
