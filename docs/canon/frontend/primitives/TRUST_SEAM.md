# Trust Seam

Status: Active primitive role

## Role

The trust seam is the visible handoff between state, source, proof, and user control.

## Allowed Use

- source freshness
- correction path
- receipt confirmation
- privacy and trust disclosure

## Forbidden Use

- decorative divider
- generic card border
- hidden model-confidence cue

## Visual Ingredients

- clear label
- compact disclosure
- source/proof line
- recovery action

## Accessibility Concern

The seam must remain understandable without color or motion.

## Source Linkage

The seam is source-present across Today, Goals, Capture, Time, and You.
