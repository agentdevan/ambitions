# Ambitions 3.0 Risk Register Protocol

Status: Active program governance

## Purpose

Risks that recur, block validation, or threaten product truth must be tracked instead of rediscovered by each Codex run.

## Use For

- Failed batches.
- Repeated test failures.
- Bad Codex runs.
- Dependency rollbacks.
- Release blockers.
- Product/canon contradictions.
- Recurring stale-doc drift.

## Required Fields

- Risk id.
- Area.
- Trigger.
- Severity.
- Owner role.
- Current evidence.
- Mitigation.
- Next review.
- Release impact.

## Rules

Do not hide risks in final prose only. Durable risks belong in `docs/audits/ambitions-3-0-risk-register.md` or the relevant audit report.
