when a real native view rendered in a SwiftUI preview host or running native
application. A loaded preview page, source-only build, design document, or
Figma frame is not native render proof.

The first bounded proving slice is one production-intended, fixture-driven
Today composition with:

- a mineral-neutral Light or deep-graphite Dark matte semantic plane;
- a compact semantic Today crown and present/date relationship;

- one primary native action;

- the Crowned Edge Dock in ordinary Peek posture.

Accessibility Dynamic Type Dark. Fixture copy is evaluation content, not

## 8. Native visual law retained

The bootstrap inherits all closed Wave 1–3 laws. In particular:

- primary content remains matte and opaque;
- system typography and natural scrolling remain native;
- identity precedes state, chronology, and action;
- routine content does not become a card grid;
- native controls keep native behavior and interaction targets;
- Liquid Glass is limited to functional crown or dock chrome and always has an
  authored opaque equivalent;
- Search and Capture do not enter the crown;
- bottom tabs, glow, glass content cards, decorative category color, tiny type,
  progress scores, completion circles, status-pill collections, generic
  dashboards, AI-assistant presentation, and fake runtime controls remain
  rejected; and
- unsupported capability remains absent or explicitly fixture-only.

## 9. Architecture boundary

Production-intended views may consume a small value snapshot supplied by a
synthetic fixture adapter. The boundary must allow a later runtime adapter to
construct the same snapshot without changing the view’s semantic contract.
The bootstrap does not connect that adapter, change the live app entry, import
legacy visual code, or make a fixture an authority owner.

Navigation, dock behavior, Search or Capture presentation, keyboard/safe-area
behavior, focus/restoration, sheets or consequential review, runtime data, and
any viewport proposed for owner closure require full-app verification in
addition to preview proof.
