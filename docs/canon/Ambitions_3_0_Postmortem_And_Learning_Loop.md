# Ambitions 3.0 Postmortem And Learning Loop

Status: Active operating governance

## Purpose

Ambitions Codex runs should get better after failures. Postmortems convert mistakes into protocol, validation, prompt, skill, or checklist improvements.

## Triggers

- Repeated failed validation.
- Wrong source truth used.
- Over-broad edit.
- Lost context after compaction.
- Bad dependency decision.
- Release claim overstated.
- User correction that reveals a systemic protocol gap.

## Postmortem Shape

1. What happened.
2. Expected behavior.
3. Root cause.
4. Detection gap.
5. Protocol or validation change.
6. Owner.
7. Follow-up proof.

## Rules

Keep postmortems practical. The goal is fewer repeated errors, not ceremonial process.
