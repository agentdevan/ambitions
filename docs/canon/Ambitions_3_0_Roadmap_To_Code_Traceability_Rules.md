# Ambitions 3.0 Roadmap To Code Traceability Rules

Status: Historical supporting canon; subordinate to `docs/truth/*`

## Purpose

Every F-series implementation batch must connect roadmap intent to concrete code, tests, and evidence without pretending that future canon is already shipped.

## Required Mapping

For each batch, record:

- Roadmap/batch identifier.
- Owning primitive.
- Owning surface.
- Canon docs used.
- Code files touched.
- Tests/previews added or updated.
- Validation pack used.
- Evidence artifact.
- Release claim state.

## Rules

- `docs/codex/BATCH_REGISTRY.md` is status truth only.
- Historical batches remain evidence, not active product direction.
- Multi-primitive batches must pass the batch combining gate.
- If implementation diverges from canon, resolve or record the gap before claiming completion.
