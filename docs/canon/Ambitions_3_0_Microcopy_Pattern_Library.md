## Purpose

This library defines reusable Ambitions 3.0 microcopy patterns for common product states.

Copy should be clear, useful, human, and short.

---

## Empty States

### Today

```text
Nothing needs you yet.
```

Actions:

- Capture something
- Open Plan

### Capture

```text
What needs a place?
```

### Goals

```text
No active goals yet.
Start with something you want to move forward.
```

### Plan

```text
Nothing planned here yet.
Start with one thing that should hold.
```

### You

```text
You are in control.
Set up Ambitions at your pace.
```

---

## Save Failed

Pattern:

```text
This did not save. Your text is still here.
```

Action:

- Try again
- Copy text

---

## Placement Preview

Pattern:

```text
Save as [Object]
[Destination] · [consequence]
```

Actions:

- Place it
- Change
- Decide later

---

## Recommendation Explanation

Pattern:

```text
Recommended because:
• [source fact]
• [fit fact]
• [goal/context fact]
```

Keep to three bullets max.

---

## Closure Prompt

Pattern:

```text
Close the loop
What happened with this step?
```

Outcome copy:

- Completed
- Still Counts
- Rescheduled
- Not needed
- Waiting
- Blocked
- Needs Review

---

## Still Counts

Pattern:

```text
Still Counts
Save what moved forward.
```

Receipt:

```text
Still Counts · Saved as proof
```

---

## Proof Saved

Pattern:

```text
Proof saved
Attached to [Goal].
```

---

## Receipt

Pattern:

```text
[Result] · [Object] · [Destination or consequence]
```

Examples:

```text
Saved as Step · Today
Rescheduled · Friday
Plan adjusted · You approved this
```

---

## Memory Confirmation

Pattern:

```text
Remember this?
[Memory summary]
This shapes [recommendation area].
```

Actions:

- Keep
- Change
- Not now

---

## Privacy/Sensitive State

Pattern:

```text
Details hidden here.
Open Ambitions to review.
```

---

## Permission Unavailable

Pattern:

```text
[Permission] is unavailable.
Ambitions still works manually.
```

---

## Reflow Preview

Pattern:

```text
Review what changes.
```

Sections:

- Moves
- Stays
- Needs closure
- Creates receipt

Actions:

- Apply changes
- Keep current plan

---

## Recovery

Pattern:

```text
The day changed. Nothing is broken.
```

Actions:

- Make this lighter
- Close the loop
- Review later

---

## Low Energy

Pattern:

```text
Low energy today.
Ambitions will keep things smaller.
```

---

## Acceptance Criteria

A microcopy pattern is acceptable when:

- it is plain
- it is human
- it avoids shame
- it states what happened or what to do next
- it preserves trust
- it does not sound like AI output
