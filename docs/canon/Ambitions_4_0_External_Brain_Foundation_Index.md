## Product Goal

Make Ambitions reliably capture, remember, organize, explain, and recover the user's life context without becoming noisy, creepy, or overwhelming.

Ambitions 4.0 External Brain Foundation makes Ambitions feel like a private external brain, a calm life operating system, a trusted executive assistant, a personal context engine, a capture-to-clarity machine, an accessible low-cognitive-load planning partner, and a source-grounded user-controlled intelligence layer.

It must not make Ambitions a chatbot wrapper, generic notes app, generic to-do app, CRM clone, widget dashboard, creepy memory system, shaming productivity app, AI feature dump, uncontrolled automation system, privacy liability, noisy recommendation feed, or unrelated feature collection.
