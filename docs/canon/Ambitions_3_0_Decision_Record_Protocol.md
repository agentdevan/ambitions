# Ambitions 3.0 — Decision Record Protocol

Status: Active architecture governance

Create ADRs for architectural changes, persistence changes, shell/routing
changes, dependency additions, external surface changes, privacy/trust model
changes, and major design-system primitives.

ADRs must state context, decision, alternatives considered, consequences,
validation, reversal path, and links to canon/tests.

Do not use ADRs for tiny implementation details, routine docs edits, or
temporary debugging notes.
