## Decision

C4 — Quiet Field is the visual-language substrate for Ambitions:

- pale stone, midnight navy, and muted sage/clay palette posture;
- SF Pro typography;
- calm spacing and object-led hierarchy;
- native icon treatment;
- status meaning carried by label plus shape, never color alone;
- restrained opaque native materials;
- visual anatomy that does not invent commands or state transitions.

The direction supplies visual language, not product behavior. Canonical state,
route, action, mutation, recovery, focus, Search/Capture placement, shell,
accessibility, and privacy behavior come from the owning specifications.

The raw directions contained product-law and implementation-plausibility
conflicts. C4 consolidated the strongest C-based spatial language, removed the
conflicting command implications, and corrected copy and mounting so the
visual layer could remain subordinate to explicit product state and command
contracts.

## Implementation use

Use C4 for foundations, materials, hierarchy, typography, rhythm, icon posture,
and state legibility. Do not infer product behavior from a frame. Before
implementation, resolve the exact screen/state/command requirement with the
canon compiler, then validate the rendered result for native layout,
accessibility, appearance variants, and the applicable behavioral contract.
