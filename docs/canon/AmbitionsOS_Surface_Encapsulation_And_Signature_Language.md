# AmbitionsOS Surface Encapsulation And Signature Language

## Status

This is active planned canon after PK06 Green evidence and AIR fold-in integration. It does not implement UI/runtime behavior by itself.

## Purpose

This document makes every AmbitionsOS / AIR / PK / AOS / LDI capability product-visible through Today, Goals, Capture, Time, and You without widening the app.

It closes the gap between local backend/runtime scope and the flagship frontend by requiring every intelligence capability to have a surface home, review path, correction path, receipt path, trust/source/privacy path, degraded state, and signature language.

## Deep-Not-Wide Law

Ambitions becomes more powerful by deepening the five surfaces, not by adding destinations.

Depth comes from folds, seams, receipts, holds, previews, drill-downs, correction paths, review states, trust states, source states, and personal runtime controls.

Depth must not come from new tabs, dashboards, chatbots, AI consoles, admin panels, generic insights pages, feed/inbox sprawl, calendar clones, habit trackers, or scoreboards.

## Surface Encapsulation Law

Every capability must define:

- where the user sees it
- where the user reviews it
- where the user corrects it
- where the receipt lives
- where source/privacy/trust state appears
- what happens when Ambitions is uncertain
- what happens when the user rejects it
- what happens when the data is sensitive
- what prevents chatbot/dashboard/hidden-learning drift

No AmbitionsOS intelligence capability may remain invisible magic, and no capability may require a new top-level destination.

## Proprietary Surface Objects

### Personal Runtime Signature

Surface:

You, with reflections in Today, Capture, and Time.

Meaning:

Visible local profile of how this Ambitions instance is shaped around the user.

Includes:

- name/greeting preference
- day rhythm
- step-size preference
- recovery preference
- language preference
- density preference
- protected-time sensitivity
- correction history
- trusted assumptions
- rejected assumptions
- sensitive area rules
- reset/forget controls

User-facing name:

Personal Runtime

Forbidden simplification:

Do not reduce to theme settings, greeting, or AI profile.

### Assumption Ledger

Surface:

You, with contextual links from all surfaces.

Meaning:

Reviewable ledger of assumptions Ambitions uses.

Required controls:

- Correct
- Use less
- Stop using this
- Forget
- Approve
- Reject
- Review later

Forbidden simplification:

Do not turn assumptions into hidden preferences.

### Held Items Shelf

Surface:

Capture, You, and contextual object surfaces.

Meaning:

User-facing form of intelligence quarantine.

User-facing states:

- Needs a Place
- Needs Review
- Source Needed
- Private Only
- Not Enough Context
- Waiting for Confirmation
- Not Ready to Recommend

User-facing verb:

Hold

Forbidden simplification:

Do not use Quarantine as ordinary user-facing language.

### Correction Fold

Surface:

All surfaces.

Meaning:

Universal correction primitive.

Controls:

- Wrong place
- Wrong time
- Wrong size
- Wrong goal
- Too personal
- Stop using this
- Forget this

Forbidden simplification:

Do not hide correction inside generic edit menus only.

### Start Here Receipt

Surface:

Today.

Meaning:

A small trust object attached to Start Here.

Shows:

- why this
- why now
- what changed
- time-fit proof
- assumption used
- alternatives rejected
- correction path
- what receipt will be created

Forbidden simplification:

Do not reduce to generic explanation text.

### LifeShape Consequence Preview

Surface:

Time.

Meaning:

A preview before reflow.

Shows:

- what gets lighter
- what gets heavier
- what remains protected
- what pressure changes
- what needs review
- what still counts
- what receives a receipt

Forbidden simplification:

Do not turn into reschedule confirmation or calendar move UI.

### Proof Transfer Fold

Surface:

Goals.

Meaning:

Path/pivot proof continuity surface.

Shows:

- what proof transfers
- what still counts
- what does not transfer
- what source is stale
- what needs new proof
- what path remains open

Forbidden simplification:

Do not treat pivots as failure or generic archive.

### Source Needed Mode

Surface:

Capture / Goals / Time / Today / You.

Meaning:

Consistent state for facts Ambitions cannot safely use yet.

User-facing examples:

- Source needed before this can guide a recommendation.
- Saved safely, but not used as requirement truth.
- This can be reviewed later.

Forbidden simplification:

Do not hallucinate or promote source-needed facts into recommendations.

### Day Close

Surface:

Today.

Meaning:

A small evening closure ritual.

Shows:

- what closed
- what still counts
- what moved
- what is held
- what tomorrow inherits

User-facing phrase:

Close Today

Forbidden simplification:

Do not turn into daily review dashboard.

### Personal System Changes

Surface:

You / Receipts & History.

Meaning:

Receipt category for personalization changes.

Example:

Ambitions stopped favoring long evening steps because you moved them four times. Review assumption?

Controls:

- Keep
- Correct
- Use less
- Stop using this

Forbidden simplification:

Do not hide learning or adaptation.
