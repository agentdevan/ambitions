# AmbitionsOS Core Architecture

Status: Future canon under Ambitions Beyond 3.0; not current app implementation truth

AmbitionsOS = event-sourced local Life Graph + typed kernels + source-bound claims + starting-position awareness + alternate path intelligence + commitment/time reasoning + bounded reflow + proof/receipts + privacy-safe projections + performance-energy governance + optional on-device language interface.

## Operating Principles

1. Typed objects are truth. Prose is presentation. No kernel returns vague prose as product truth.
2. Event log before mutation. Consequential changes become events.
3. Graph delta before commit. Intelligence outputs proposed graph deltas. It does not silently mutate truth.
4. Deterministic first. Rules, typed models, local domain packs, state machines, and tests own critical reasoning.
5. Language assisted, not language owned. Language models may parse, summarize, and propose. They do not certify requirements or write directly to the Life Graph.
6. Source-bound claims. Fresh/current facts require source state.
7. Starting position matters. The same dream cannot produce the same path for every user.
8. Alternate paths are first-class. Ambitions preserves the North Star even when one route changes, becomes blocked, or stops fitting.
9. Performance is a product feature. No local brain should make the app slow, battery-heavy, or bloated.
10. Privacy projections are mandatory. External surfaces never receive raw sensitive state.
11. Deep, not wide. AmbitionsOS deepens existing Ambitions primitives before creating new surfaces.
12. Maintainability before maturity. Future implementation must not add major behavior into known large-file risk areas without extraction or ownership review.
13. Compatibility before cleanup. Internal seams are retired only after route, schema, widget, App Intent, import/export, persistence, and tests prove replacement.
14. Evidence before claim. No release, accessibility, platform, device, or App Store claim is made without matching evidence.

## Runtime Pipeline

Raw Input -> Control Plane -> Work Classifier -> Relevant Kernels -> ProposedGraphDelta / Projection / Recommendation / Question / Receipt / ReviewRequest / SourceRequest / ImpactReport / PrivacyProjection -> Trust Gate -> Performance Energy Gate -> Privacy Gate -> Compatibility Gate -> Maintainability Gate -> User Approval if needed -> Event Log -> Life Graph -> UI Projection

## Current Non-Implementation Boundary

No app behavior is implemented by this document. No production Swift file, persistence model, dependency, workflow, or platform integration is changed by the AmbitionsOS canon batch.
