# Ambitions 3.0 — Design QA Protocol

Status: Active QA protocol

## Triggers

Run for UI, IA, visual hierarchy, design-system primitive, motion, density, or
surface-state changes.

## Required Docs

- `Ambitions_3_0_Front_End_Redesign_Index.md`
- `Ambitions_3_0_Primitive_Architecture.md`
- target surface/primitive docs
- `Ambitions_3_0_Ambitions_Operating_Shell.md` when shell-adjacent

## Checks

- Surface has one clear job.
- Primary action is visible and not crowded.
- Visual states are meaningful, not color-only.
- Design-system primitives are reused before new components.
- Motion is supportive and respects Reduce Motion.

## Evidence

List inspected screens/components, screenshots/previews if available, and
PASS/PARTIAL/FAIL with risks.

## Stop Conditions

Stop when design changes imply new product behavior, a new destination, or a
missing primitive contract.
