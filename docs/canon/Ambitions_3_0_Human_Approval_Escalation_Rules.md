# Ambitions 3.0 Human Approval Escalation Rules

Status: Historical supporting canon; subordinate to `docs/truth/*`

## Human Approval Required

Codex must stop and request human approval before:

- Runtime dependency addition.
- Persistence migration.
- Privacy model change.
- Sync, auth, account, or backend architecture.
- App shell replacement.
- Major navigation architecture change.
- Signed release, TestFlight, App Store, or final RC work.
- Deleting large historical docs.
- Failing validation after two informed repair attempts.
- Ambiguity between product vision and implementation reality.

## Human Evidence Required

Human/device/platform proof is required before claiming:

- TestFlight readiness.
- App Store readiness.
- Public accessibility verification.
- Real-device readiness.
- Final release candidate lock.

## Escalation Output

Include the decision needed, options, risk of proceeding, evidence already gathered, and the safest next command or prompt.
