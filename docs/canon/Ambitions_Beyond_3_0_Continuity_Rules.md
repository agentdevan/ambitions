# Ambitions Beyond 3.0 Continuity Rules

Status: Future-canon continuity governance

## Purpose

Ambitions 3.0 operating discipline must survive 3.1, 4.0, and later canon without stale-doc drift or product identity loss.

## Introducing Future Canon

Future canon must include:

- Source-of-truth override.
- Documentation index.
- Supersession map from 3.0.
- Migration plan.
- Release claim state.
- Archive/update plan for old docs.

## Supersession Rules

Newer canon replaces older canon only when it explicitly says so. Historical implementation evidence remains useful but cannot override the active source hierarchy.

## Product Identity

Preserve the Ambitions promise: life feels organized, concrete steps become visible, and the product remains an intelligent life organization system rather than an AI wrapper.

## Skill System Evolution

Skills, validation packs, templates, and operations should be versioned by source truth. Do not silently reuse 3.0-specific prompts as 4.0 direction without a context refresh.

## Archive Rules

Archive superseded docs only after active indexes link replacements. Do not delete historical evidence unless human approval is explicit.

## Compatibility

Future migrations should preserve working behavior until replacements are implemented, tested, and traceable.
