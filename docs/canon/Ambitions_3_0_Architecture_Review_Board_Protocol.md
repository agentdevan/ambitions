# Ambitions 3.0 — Architecture Review Board Protocol

Status: Historical supporting canon; subordinate to `docs/truth/*`

## Purpose

L/XL architecture-sensitive work requires review before implementation.

## Trigger Changes

- Shell/routing architecture.
- Persistence model or migration.
- Dependency addition or promotion.
- External surfaces.
- Sync/auth/account architecture.
- Privacy/trust model.
- Major design-system primitive.
- Cross-primitive state-machine changes.

## Required Review

The board includes Product Manager, iOS Engineer, Backend/Data Engineer,
AI/Personalization Engineer where relevant, Privacy/Security Reviewer, QA, and
Technical Program Manager.

## Output

- ADR required or not.
- Approved scope.
- Rejected alternatives.
- Validation plan.
- Reversal path.

Any unresolved board block stops implementation.
