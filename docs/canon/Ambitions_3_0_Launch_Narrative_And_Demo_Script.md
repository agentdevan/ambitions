## Purpose

This document defines the canonical Ambitions 3.0 demo story for implementation, screenshots, investor materials, App Store assets, and QA fixtures.

---

## Core Narrative

Ambitions is a life execution system.

It helps the user:

```text
capture real intent
place it safely
plan what can hold
start one clear step
close the loop when reality changes
save proof of what counted
stay in control
```

---

## Canonical Demo Goal

```text
Release 3 songs by August 1
```

This fixture should appear across previews, screenshots, onboarding samples, QA flows, and demo scripts unless a batch explicitly chooses another fixture.

---

## Demo Story Arc

1. User captures: `Release 3 songs by August 1`.
2. Ambitions suggests: `Grow into Goal` under Creative.
3. Goal Detail creates a believable path.
4. Plan shows whether the week can hold.
5. Today shows one recommended step.
6. User opens Step Detail.
7. User starts Step Session.
8. The day changes.
9. User chooses Still Counts.
10. Ambitions saves proof.
11. Receipt shows what changed.
12. Review shows what counted and what carries forward.
13. What Ambitions Knows asks before remembering a pattern.

## Demo Must Not Show

- fake AI assistant chat
- fake sync/cloud behavior
- fake calendar write unless implemented
- fake accessibility claim
- fake memory use without consent
- productivity score
- streak
- generic task list
- generic calendar clone
- private real user data

## Investor Script

```text
Ambitions starts where real life starts: with something important in your head.

You capture it. Ambitions gives it a place.

That place becomes a believable plan.

Today does not show a task dump. It shows where to start.

When the day changes, Ambitions does not mark failure. It helps you close the loop.

If progress still happened, Still Counts saves proof.

Every recommendation, change, and memory remains explainable and correctable.
```

## Acceptance Criteria

The launch narrative is mature when:

- screenshots tell the same story
- previews use the same fixture
- demo flow maps to the Golden Launch Loop
- no screenshot implies unimplemented capability is shipped
- proof/recovery/trust are visible
- Ambitions sounds unlike a task manager, calendar, or AI scheduler
