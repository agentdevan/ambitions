Status: Active invariant ledger. LDI01 is Green as source-truth/governance
evidence; no runtime implementation is claimed.

- Every dream is classified, protected, routed, and handled honestly.
- Not every dream becomes a complete plan.
- Every capture/dream has exactly one primary canonical handling lane from: `parked_thought`, `clarification_needed`, `quick_step`, `project_plan`, `dream_scaffold`, `source_backed_plan`, `regulated_plan`, `professional_boundary_scaffold`, `north_star_extraction`, `unsafe_blocked`, `crisis_support`, `source_stale_review`, `source_conflict_review`, `impossible_timeline_review`, `conflict_review`, `privacy_sensitive_plan`, `sync_recovery`, `unsupported_domain_exploration`, `source_check_first`, `user_review_required`, `local_only_private_plan`.
- Unsupported dreams become scaffolds or exploration paths.
- Impossible or symbolic dreams become North Stars.
- Regulated dreams use professional-boundary scaffolds, source states, and verification boundaries.
- Unsafe dreams are blocked and redirected; crisis-coded inputs receive support and no harmful steps.
- Source-backed plans depend on claim IDs.
- Generated packs remain draft until source/schema/review evidence exists.
- Packs contain no executable logic.
- User data remains local-first and private by default.
- Ambitions-owned infrastructure never stores user dreams, goals, plans, receipts, source dependency index, memory, schedule, identity, or user analytics by default.
- Commitments never move without user review.
- Privacy settings use most-restrictive merge behavior.
- Sensitive goals may be local-only and excluded from sync.
- LDI does not create a sixth top-level destination.
- LDI does not make Ambitions a chatbot or generic productivity surface.
- Early LDI insertion before AOS24 is source-truth/governance only unless a
  later batch explicitly owns implementation, tests, rendered proof, and
  claim boundaries.
