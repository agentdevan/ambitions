# Codex Skills Kit

Status: Active skills routing index.  
Date: 2026-05-07  
Scope: How agents should use `.codex/skills/` with the efficiency layer.

## Principle

Use an existing skill before inventing a new role. Add a skill only when a repeated task needs reusable behavior.

## High-Value Skill Families

| Skill family | Use |
| --- | --- |
| Canon Steward | Source truth, supersession, conflict reconciliation. |
| UI Primitive Steward | Ambitions-native object composition and anti-generic UI. |
| Build Sheriff | Compile/test/log extraction and repair loops. |
| Accessibility Reviewer | VoiceOver, Dynamic Type, Reduce Motion, non-color meaning. |
| Visual QA Reviewer | Rendered proof, primary-object discipline, premium object identity. |
| Batch Conductor | Continue global train until hard Red. |
| Repo Hygienist | Stale docs, orphan files, duplicated concepts, prompt residue. |
| Release Claim Auditor | Blocks unsupported production/release/compliance claims. |
| External Brain Architect | Memory, claim, proof, receipt, privacy boundaries. |

## Efficiency Contract

A skill should specify:

- route file
- required read list
- allowed paths
- forbidden paths
- gates
- validation tier
- report format

## No Parallel Role Sprawl

If two skills overlap, preserve both histories but add a routing note to this file or the route file instead of creating a third duplicate skill.
