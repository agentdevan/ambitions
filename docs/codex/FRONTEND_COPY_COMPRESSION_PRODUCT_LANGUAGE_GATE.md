# Frontend Copy Compression Product Language Gate

<!-- markdownlint-disable MD013 -->

Status: Active FET gate
Date: 2026-05-09
Batch: FET07

## Purpose

Root UI copy must help the user understand value and next action. It must not narrate architecture, compliance posture, source systems, governance, or model behavior.

## Flag Phrases

Flag top-level UI copy that sounds like architecture or compliance:

- local-first trust visible
- memory is inspectable
- source-backed
- confirmation
- coherent backbone
- controls privacy visible
- keeps direction connected
- time shapes the week
- no silent changes
- implementation, infrastructure, governance, diagnostic, runtime, model, AI confidence, or architecture language

## Preferred Copy

- short human labels
- one reason line
- proof hidden in drawer unless immediately useful
- trust detail available but not shouted
- user-value-first copy

## Red

Root UI explains implementation instead of user value, exceeds first-viewport copy budget, uses AI theater, uses shame/fake precision, or claims quality/readiness without evidence.
