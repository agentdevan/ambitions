# Ambitions Failure Forensics Protocol

Status: AmbitionsOS future Codex OS protocol

## Required Fields

- owner
- source docs
- affected kernel/primitive/surface
- allowed files
- forbidden files
- evidence required
- privacy/accessibility/performance/compatibility/release impact
- rollback or repair path
- Green/Yellow/Red gates
- what this does not prove

## Boundary

This protocol does not implement app behavior and does not create release claims.

Failure classes: product behavior regression, stale test expectation, fixture drift, simulator/environment failure, copy contract regression, accessibility identifier regression, privacy projection regression, routing/deep-link regression, compatibility seam regression, performance timeout, architecture boundary violation, prompt scope failure, dependency/tooling failure.
