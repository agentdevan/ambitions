## Gate

- Green: average >= 4.5, no category below 4, preview evidence,
  accessibility evidence, and performance risk reviewed.
- Yellow: average >= 4.0, no category below 3, missing human/device proof only
  or existing repo advisory only.
- Red: average < 4.0, any category below 3, no preview evidence, no Reduce
  Motion path, no accessibility evidence, dashboard/card-stack drift, gimmicks
  without state meaning, readability harm, or unmanaged performance risk.

## Claim Boundary

This is an aspirational internal rubric. Do not claim Apple award status,
production readiness, App Store readiness, or public accessibility conformance.
