## Purpose

This scorecard preserves the legacy object baseline, target state, priority, implementation risk, and exact acceptance gate for every major Ambitions flagship object. Codex may use it as a drift-prevention contract for historical FCP batches, but `docs/truth/*` and the current frontend visual encyclopedia root win over any legacy alias here.

## Scoring Rule

- Current score is an implementation/product-object readiness estimate, not a compliment.
- Target score for every object is 10/10.
- A named object with generic card/grid/list/settings expression cannot exceed 7/10.
- An object that lacks trust/source/privacy/reduced-motion/accessibility proof cannot exceed 8/10.
- An object that depends on unsupported AI/runtime/persistence claims is Red, regardless of visual quality.

## Object Acceptance Gates

### 1. Start Here Surface (historical alias: Hero Step Panel)

Pass only if StartHereSurface exists as the primary Today decision object and includes ContextEdge, TimeFitProof, GoalThread, source-quality because line, receipt drawer seam, primary action, secondary action, privacy behavior, stale-source behavior, and reduced-motion/VoiceOver equivalents. The object fails if it remains a rounded task/recommendation card.

### 2. Reality Rail (historical alias: DayTimelineRail)

Pass only if Now / Next / Later, Start Here, closure, proof, and pressure form one continuous rail object. The object fails if Today becomes an agenda, task list, equal-card stack, or calendar timeline.

### 3. Ambition Meridian Shell

Pass only if shell remains familiar/native while adding restrained proprietary meridian chrome, compact contextual header, receipt overlay zone, safe-area behavior, accessible navigation titles, and fixed five-tab topology. The object fails if navigation becomes hidden, weird, sci-fi, or dashboard-like.

### 4. LifePath View

Pass only if LifePath becomes a thread with proof beads, risk pinch, alternate route branch fold, source fold, privacy redaction, and accessible path order. It fails if it is a card row, roadmap board, or generic progress timeline.

### 5. MissionControlTimeSpine / Mission Control Lanes

Pass only if MissionControlTimeSpine replaces grid/card Mission Control as the primary goal-detail execution object. It must preserve Completed / Now / Friction / Next / Horizon order. It fails if it is a metrics surface, card grid, kanban, or PM board.

### 6. Capture Atmosphere Composer

Pass only if Capture remains text-first and bottom-composer driven while adding Placement Shelf, local source fold, route consequence, privacy, correction, and receipt seam. It fails if it becomes an inbox, feed, command palette, or notes app.

### 7. Placement Resolver / Capture Correction

Pass only if every placement has a Resolver Fold with destination, consequence, source, correction, and receipt. It fails if it silently routes, claims hidden learning, or exposes confidence percentages.

### 8. LifeShape Map

Pass only if LifeShape is a contour/pocket/field object showing capacity, pressure, recovery, protected time, and milestones without calendar-grid or bar-chart posture. It fails if Plan becomes a calendar clone, analytics chart, or dense event grid.

### 9. Reflow Decision

Pass only if reflow uses a Decision Fold with before/after shape, what changed, why, impacted steps, capacity impact, protected-time impact, accept/edit/decline, and receipt. It fails on silent rearrangement or calendar writes without explicit scope.

### 10. Pressure / Recovery Review

Pass only if shared RecoveryLoop and PressureField are used to reduce shame, shrink overloaded next steps, protect time, and record receipts. It fails on needs closure guilt, failure language, productivity scores, or proof thread rescue.

### 11. Trust Receipt Layer / EvidenceLabel / ProofPulse

Pass only if ReceiptDrawer becomes the system-wide trust layer, not merely toast/inline components. It must answer what happened, why, source, freshness, privacy, change, undo/correction/review. It fails on generic saved snackbars or source-less AI explanation.

### 12. Evidence Ledger / Proof Spine

Pass only if proof appears as a shared ProofSpine with source/freshness/privacy/correction/stale behavior across Today, Goals, Time, and You as allowed. It fails as activity feed, trophy shelf, or analytics ledger.

### 13. Action Closure Diamond

Pass only if closure resolves through a diamond with Completed, Still Counts, Moved/Rescheduled, Blocked/Waiting, plus a secondary fold. It fails as a plain list, binary done/needs review model, or shame state.

### 14. Personal System Center

Pass only if You root becomes one primary PersonalSystemCenter object with identity/setup/trust posture, Planning Setup, Trust/Data/Memory controls, and receipts history. It fails as generic settings dump or diagnostics console.

### 15. Appearance Studio

Pass only if Appearance Studio previews real Ambitions objects and supports accent/material/reduced-motion/contrast review. It fails as theme shop, skin picker, or AI personality control.

### 16. Loading / Empty / Degraded States

Pass only if state expression becomes object-specific across Today, Goals, Capture, Time, You, Trust, and Memory. It fails on generic error cards, skeleton spam, or fake progress.

### 17. Iconography / Status Grammar

Pass only if every status has symbol, shape/pattern, text label, VoiceOver meaning, reduced-motion equivalent, and allowed placement. It fails on color-only meaning or arbitrary SF Symbol drift.

### 18. Motion / Haptics System

Pass only if object motion maps to state-settle, receipt-confirm, proof-attach, rail-advance, drawer-open, fold-reveal, or closure-resolve with reduced-motion equivalents. It fails on decorative animation or motion-only meaning.

### 19. Dynamic Adaptive Visual Primitives

Pass only if living state changes object anatomy, not just tint/glow. It fails if ambience/wallpaper becomes the product.

### 20. Memory Lens / External Brain Visual Layer

Pass only if Memory Lens exposes remembered context, source age, why remembered, correction/rejection controls where implemented, and privacy shutter without creepy or unsupported claims. It fails on omniscient copy or hidden inference.

### 21. Step Detail

Pass only if Step Detail becomes a Step Decision Fold explaining why this step, goal thread, duration source, what counts, closure/proof path, and Step Session launch. It fails as generic task-detail modal.

### 22. Step Session

Pass only if Step Session becomes an Execution Pocket with optional timer, goal thread, proof slot, pause/stop no-mutation behavior, and closure handoff. It fails as Pomodoro clone or focus gamification.

### 23. Grow into Goal

Pass only if Grow Into Goal becomes Goal Seed Incubator with why-this-goal, starting position, first milestone, first step, source/proof seed, and explicit promotion. It fails on auto-goal creation or project wizard posture.

### 24. Cross-surface proof/review integration

Pass only if ContinuityReceiptMesh connects receipts/proof/review across Capture, Today, Goals, Time, and You without becoming an activity feed. It fails on duplicated receipt islands or generic history log.

### 25. Schedule / Availability / Defaults depth

Pass only if AvailabilityCenter treats work, school, protected time, sleep, commute/buffers, and vacation/away as hard context; open time is not automatically filled; Guided automation is default; duration source is explicit. It fails as calendar clone, preferences dump, or auto-scheduler black box.
