# Found Life Layer Gate Matrix

Status: Active-scope planning truth for FL01-FL06.
Date: 2026-05-05

## Purpose

This gate matrix prevents the Found Life Layer from becoming generic memory, a dashboard, surveillance, or life-admin sprawl. It defines the strict checks that must pass before Found Life concepts can influence FCP, AOS, LDI, PFC, onboarding, search, memory, recommendation, or external surfaces.

## Hard Red Gates

| Gate | Red condition |
|---|---|
| Top-Level Tab Gate | Found Life creates a sixth top-level tab or parallel app mode. |
| Dashboard Drift Gate | Life Inventory, Weekly Sweep, or Searchable Recall becomes an all-at-once dashboard/database. |
| Surveillance Gate | The system feels like it monitors the user instead of helping the user review/correct their own life context. |
| Shame Gate | Open loops, abandoned ideas, missed commitments, or parked goals are framed as failure. |
| Memory Truth Gate | Inferred memory is presented as fact without review/source/freshness. |
| Privacy Gate | Sensitive relationship/family/work/career/health-adjacent/money content can surface in public/external surfaces by default. |
| Source Gate | Career, education, requirement, or path recommendations omit source/freshness/uncertainty. |
| Legal Boundary Gate | Found Life implies professional, legal, financial, medical, education, or career certainty beyond source truth and legal review. |
| Product Drift Gate | Found Life becomes notes app, task dump, habit tracker, diary, CRM, family admin SaaS, LMS, career website, or AI memory chatbot. |
| Runtime Claim Gate | Docs claim searchable life recall, memory runtime, sync, LDI, AOS, or legal compliance is implemented without evidence. |

## Required Found Life Gates

### Product Soul Gate

Must prove:

- Canon includes the line: `Find your life. Keep your promises. Build your future. Enjoy today.`
- Product purpose is life visibility and continuity, not only goal execution.
- Found Life is a layer under the five locked tabs, not a new tab.
- The sports-car-with-no-GPS user archetype is represented without overfitting the app to one person.

### Life Inventory Gate

Must prove:

- Life threads have type, state, source, freshness, privacy class, owner surface, and review path.
- Life Inventory maps into Today, Goals, Capture, Plan, You, Memory Lens, AOS, and LDI.
- No all-at-once life database is created as the default UX.

### Commitment Memory Gate

Must prove:

- User-confirmed commitments are separate from inferred possible commitments.
- Imported/sourced/private/stale/completed/parked/dropped/waiting/blocked commitments have distinct state.
- Commitment Memory is correctable and receipt-backed.

### Open Loop Registry Gate

Must prove:

- Open loops can close as completed, parked, waiting, blocked, needs review, needs recovery, intentionally dropped, ready to revive, converted to goal, or converted to one-off step.
- No binary failure state is introduced.
- Abandoned work can still count when evidence/source supports option value.

### Searchable Life Recall Gate

Must prove:

- Recall answers cite source/freshness/privacy and offer review/correction path.
- Recall does not hallucinate life facts.
- Sensitive recall is redacted or private by default.
- External surfaces cannot expose sensitive recall by default.

### Option Value Gate

Must prove:

- Prior proof can transfer across paths when requirements/source overlap.
- Adjacent path recommendations expose uncertainty and source requirements.
- Pivot preservation does not make career/education claims as certainty.

### Weekly Life Sweep Gate

Must prove:

- Sweep is short, calm, and non-shaming.
- Sweep asks what was forgotten, promised, still matters, can be dropped, is becoming real, is noise, needs family/relationship attention, work risk, career/income move, and future path evidence.
- Sweep feeds Start Here, Reality Rail, Life Inventory, Memory Lens, and Option Value without becoming a dashboard.

### ADHD / Cognitive Load Gate

Must prove:

- Defaults reduce working-memory burden.
- User sees one clear next step by default.
- More life context is searchable/reviewable, not forced into the morning surface.
- Recovery and parking are normal outcomes.

### Trust / Privacy Gate

Must prove:

- Found Life memory is user-owned, reviewable, correctable, rejectable, and privacy-safe.
- Local-only/sync boundaries are honest.
- Source and freshness are visible anywhere Found Life affects recommendations.

- Runtime memory/search implementation deferred to later AOS/LDI/FCP batches.
- No visual screenshots because FL is docs/product-contract only.

## Hard Red Examples

- Adds a new Found Life tab.
- Turns Weekly Life Sweep into a scorecard or shame ritual.
- Treats inferred promise as fact.
- Exposes relationship/family/work detail in widget/Live Activity by default.
- Claims career path certainty or education eligibility without source and legal boundary.
- Implements production behavior during docs-only FL source-truth batch.
