# AMB-CODEX-OS-LAUNCH-BELIEVABILITY-GATE

Supporting note: This gate supports current Ambitions Codex work but does not override `docs/truth/`.

## Purpose

Judge whether the result feels like a flagship local-first iPhone product instead of a v1 seam-filled prototype.

## Check

1. Ask whether the surface feels native, calm, and believable.
2. Ask whether it communicates ownership, proof, and trust.
3. Ask whether it avoids generic productivity, chatbot, and dashboard patterns.
4. Ask whether the copy sounds like a premium personal operating system.
5. Ask whether the claim set is smaller than the implementation evidence.

## Routes to existing support

- `ios-native-believability-reviewer`
- `release-claim-safety-auditor`
- `app-store-truth-packet-reviewer`
- `non-sycophantic-product-reviewer`

## Non-claims

This gate is a skeptical review lens, not a release stamp.
