# AMB-CODEX-OS-AUTHORITY-RESOLVER

Supporting note: This gate supports current Ambitions Codex work but does not override `docs/truth/`.

## Purpose

Force the next question to be explicit:

- What active truth did I inspect?
- Which source outranks which?
- Am I about to create duplicate authority?
- Is this material active, supporting, historical, obsolete, archive-candidate, or delete-candidate?
- Where should this change live?

## Check

1. Read `docs/truth/README.md`.
2. Identify the highest authority relevant to the task.
3. Refuse to promote old canon or prompt text over live source or current proof.
4. Classify every touched file before editing.
5. Stop if a new file would duplicate an existing active authority path.

## Routes to existing support

- `repo-truth-enforcer`
- `source-truth-librarian`
- `active-canon-linker`
- `evidence-hierarchy-enforcer`

## Non-claims

This gate does not prove implementation, validation, or release readiness.
