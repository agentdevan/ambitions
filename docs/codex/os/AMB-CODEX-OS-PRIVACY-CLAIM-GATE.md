# AMB-CODEX-OS-PRIVACY-CLAIM-GATE

Supporting note: This gate supports current Ambitions Codex work but does not override `docs/truth/`.

## Purpose

Keep privacy and local-first claims tied to current source and current copy.

## Check

1. Map every privacy or local-first claim to source code, entitlements, or privacy manifest evidence.
2. Verify user-facing copy does not outrun code.
3. Check export/delete/correction claims against current implementation and proof.
4. Reject hidden backend or hosted-account assumptions.
5. Treat iCloud/sync claims as separate and explicit.

## Routes to existing support

- `privacy-manifest-reviewer`
- `app-store-privacy-label-reviewer`
- `privacy-legal-app-store-reviewer`
- `privacy-copy-writer`

## Non-claims

This gate does not authorize legal approval or release approval.
