# AMB-CODEX-OS-APPLE-CONTINUITY-GATE

Supporting note: This gate supports current Ambitions Codex work but does not override `docs/truth/`.

## Purpose

Keep Apple continuity, sync, and multi-device claims honest and explicit.

## Check

1. State what syncs and what remains local.
2. State offline behavior and disabled-iCloud behavior.
3. State conflict handling and recovery behavior.
4. Check app-group and extension implications.
5. Avoid implying custom hosted sync or account infrastructure.

## Routes to existing support

- `continuity-sync-archive-reviewer`
- `app-group-entitlement-reviewer`
- `external-surface-safety-tester`

## Non-claims

This gate does not prove sync correctness or device behavior.
