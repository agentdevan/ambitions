## Purpose

Run HPS08 to define the Living Dream Compiler upgrade contract before LDI01.
The contract covers dream-to-domain classification, seriousness ladder,
feasibility spectrum, North Star extraction, safe symbolic translation,
requirement graph bridge, source trust bridge, capacity bridge, mutation
permissions, recompiler blast radius, next evidence recommendation, and safe
refusal/redirect.

HPS08 is docs-only. It does not implement LDI runtime, production Swift,
source packs, requirement extraction, path generation, recommendation behavior,
schema, persistence, sync, cloud, AI runtime, UI, crisis support service, legal
or professional advice, or release claims.

## Locked HPS08 Decisions

- Dreams become safe handling paths, not motivational text.
- Unsupported dreams become scaffolds or exploration paths.
- Impossible or symbolic dreams become North Star review, not literal
  validation.
- Regulated and professional-boundary dreams require source/human review.
- Unsafe dreams are blocked and redirected safely.
- Crisis-coded inputs do not enter normal productivity routing.
- Commitments, plans, paths, proof, requirements, privacy state, and external
  surfaces never mutate silently.
