## Purpose

Define commitment memory and searchable life recall architecture for Found
Life, You, AOS, LDI, proof, source, recommendations, and external-surface work.

HPS05 is docs-domain architecture only. It does not implement durable memory
storage, search index, embeddings, model memory, sync, account, cloud,
background indexing, notifications, export/delete behavior, AI runtime, or UI.

## Allowed Files

- HPS05 canon/prompt/report docs
- HPS train status
- global-order, registry, context, dependency, and run-state docs

## Forbidden Files

- Production Swift
- Persistence/schema/migration files
- Runtime memory store or recall index
- Embeddings, model memory, hosted AI, or local model adapter implementation
- Sync/cloud/account/backend
- Notifications, widgets, Live Activities, App Intents, or external recall
  implementation
- Export/delete implementation
- Top-level navigation or visible all-life memory surface
- School/workforce/family admin, diary, notes, generic search, or monitoring
  product behavior
- Release/App Store/TestFlight/device/accessibility/acquisition claims

## Required Acceptance

- Memory object families exist.
- Memory state fields exist.
- Confirmation, recall permission, and sensitivity states exist.
- Searchable recall contract exists.
- API contract families exist for read, proposal, recall query, and projection.
- Silent memory creation, promotion, recall, or externalization is forbidden.
- Correction, rejection, hide, forget, and delete boundaries exist.
- Sensitive memories are private/review-only by default.
- No durable memory/search/export/delete/runtime claim is made.
