# AFI12 Accessibility And State Proof

<!-- markdownlint-disable MD013 -->

Status: Completed / Accepted Yellow
Date: 2026-05-08

## Goal

Create AFI-specific accessibility and state proof for the active flagship
surfaces without making public accessibility, release, device, or compliance
claims.

## Scope

- Lock accessibility proof rows to the active AFI surfaces: Today, Goals,
  Capture, Time, You.
- Preserve Trust Seam, Quiet Reflow, and Receipt Surface as support objects.
- Record VoiceOver summary, Dynamic Type fallback, Reduce Motion fallback,
  non-color state support, and trust/receipt path for every active surface.
- Keep manual proof requirements explicit.

## Forbidden

- No Plan top-level proof row.
- No ACUI downgrade.
- No public accessibility conformance claim.
- No production/release/readiness/device/legal/privacy claim.
- No route/raw-value, persistence/schema, sync/cloud, account, permission, or
  calendar behavior change.

## Closeout

Type screenshots, toggled Reduce Motion walkthrough, contrast review, motor
