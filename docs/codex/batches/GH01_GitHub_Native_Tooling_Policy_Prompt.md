# GH01 GitHub Native Tooling Policy Prompt

Create or maintain the GitHub Native Tooling Policy.

Rules:

- Keep GitHub MCP read-only first.
- Do not create or store broad tokens.
- Do not add write-capable GitHub tools without separate approval.
- Do not add hosted CI workflows without cost, runner, trigger, retention, security, and claim-boundary approval.
- Do not add signing, App Store, TestFlight, or release workflows.
- Keep workflow examples under docs until explicitly approved.
