## Locked HPS07 Decisions

- Prior work is never failure by default.
- Proof transfers only when requirement, source, and evidence overlap support
  the transfer.
- Unsupported value remains reviewable context, not a claim.
- North Star continuity must be user-reviewed and non-deterministic.
- Dream parking preserves option value without execution pressure.
- Still Counts receipts preserve evidence without fake completion.
- Option Value cannot silently mutate goals, commitments, plans, paths, proof,
  requirements, source claims, privacy states, or exports.
- Career, education, legal, financial, health, and professional claims remain
  source-bound and review-bound.
