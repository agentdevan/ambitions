# PXEQ Minimalism With Utility Rules

<!-- markdownlint-disable MD013 -->

Status: Active PXEQ minimalism rules.
Date: 2026-05-03

Minimalism means fewer visible choices with stronger utility. It is Red when a
surface becomes empty, underpowered, vague, or dependent on hidden automation.
Every top-level surface needs one primary visual object, one clear next action,
visible recovery, accessible alternatives, and a path to inspect proof, source,
receipt, or control when trust is affected.
