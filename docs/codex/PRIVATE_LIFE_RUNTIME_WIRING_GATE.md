# Private Life Runtime Wiring Gate

Status: Active Codex gate.

Any intelligence-affecting change must prove:

- source input
- output object
- SourceRecord
- Receipt
- ReplayTrace
- user control
- You / What Ambitions knows inspection path
- reset/delete path
- deterministic test
- proof artifact
- no cloud LLM
- no silent sensitive use
- no silent schedule mutation

If any required wire is absent, status cannot be Green.

This full wiring gate applies to runtime-affecting changes. Pure visual, token, docs, proof-only, or audit-only changes still need canonical ownership and duplicate-concept checks, but they do not need SourceRecord/Receipt/ReplayTrace unless they affect runtime behavior.
