# Privacy Security Trust Gate Matrix

Status: Active Codex OS protocol; not implementation evidence.
Date: 2026-05-03

This document defines: local-first claims, data collection boundaries, sensitive memory, private mode, export/delete, undo/correction, audit trails, recommendation evidence, inference labeling, App Store privacy disclosure readiness, and OWASP mobile security testing alignment.

Green requires source truth, allowed/forbidden files, evidence, validation, and conservative claim boundaries. Yellow requires owner and safe deferral. Red stops or enters the Red repair decision tree.
