Status: Active Codex OS evidence ledger template.

## Purpose

Batch completion is not the same as product maturity. The Evidence Maturity Ledger tracks each major Ambitions object by proof maturity, not just implementation status.

## Maturity Columns

Each object must eventually be scored:

| Object | Canon | Implementation | Behavior | Visual | Accessibility | Privacy | Performance | Tests | Release | Handoff | Overall |
|---|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|---:|

Scoring:

- 0 = no evidence
- 1 = docs-only
- 2 = structural implementation
- 3 = focused tests
- 4 = durable rendered/proof evidence
- 5 = release/handoff-ready evidence with no Hard Red

## Use

Every major closeout must update or reference the ledger.

Final handoff cannot claim 10/10 unless ledger shows evidence maturity appropriate to the claim.

## No-Claim Boundary

This file is a tracking template. It does not itself claim any object has achieved maturity.
