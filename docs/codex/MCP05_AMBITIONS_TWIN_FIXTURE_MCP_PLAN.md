# MCP05 Ambitions Twin Fixture MCP Plan

Status: Scaffold only.
Scope: synthetic local fixture library for EFC07 proof.

MCP05 creates a fixture substrate for whole-life Ambitions proof without using telemetry, analytics, hosted AI, or user-data servers.

Initial fixture stubs:

- `busy-new-job`
- `creative-builder`
- `overloaded-mover`
- `manual-privacy-user`
- `long-term-drifter`
- `source-heavy-career-switcher`
- `travel-week-user`

Each fixture includes goals, captures, time context, proof/receipts, recovery state, privacy mode, source/freshness state, accessibility variant, and expected surface states.

The fixtures are not wired into production runtime.
