# Source Atlas Projection QA Fixture Families
<!-- markdownlint-disable MD013 -->

Status: Active fixture-family source truth for SAP04, SA10C, AOS, and LDI projection validation.
Date: 2026-05-06

## Purpose

These fixture families define the minimum Source Atlas projection scenarios
needed before pack schema, Pack Factory, AOS path compilation, or LDI
requirement-runtime work can claim projection coverage.

They are not source packs, official requirements, current legal/career/
education/certification data, production runtime fixtures, or Research Seeds v1
imports.

## Fixture Rules

Every fixture family must eventually prove:

- composable graph pieces are reused
- goals become GoalProjection objects
- user context shapes PersonalPathInstance output
- source-needed fallback appears when official/current proof is missing
- high-risk claims stay review-bound
- final scheduled steps are generated by AOS/LDI/Plan, not stored in packs
- projection receipts explain source use, source exclusion, uncertainty, and fit

## Required Families

### Pickleball Skill Slice

Goal examples:

- improve pickleball serve
- improve pickleball dink

Required proof:

- Uses `sports.pickleball` capability graph.
- Selects only relevant serve or dink capability nodes.
- Does not load the entire pro path for narrow skill work.
- Produces StepCandidateSeeds rather than scheduled steps.

### Pickleball Starter / Pro Path

Goal examples:

- learn pickleball
- become pickleball pro

Required proof:

- Starter path reuses beginner rules, equipment, and level ladder graph pieces.
- Pro path reuses lower-level capability nodes and adds competition/pro overlays.
- RequirementOverlay carries source/freshness/review state.
- AlternativePathSet includes coaching, local competitive play, or adjacent sport/community options when appropriate.

### Football Varsity / NFL

Goal examples:

- make varsity football
- make it to the NFL

Required proof:

- Varsity path uses school/team/season overlays and does not guarantee selection.
- NFL path reuses lower-level football capability nodes instead of duplicating them.
- PersonalPathInstance varies by age, grade, location, position, proof, time, and safety constraints.
- Source-needed fallback appears for school-specific eligibility and deadline claims.

### Football Skill / Commentator Path

Goal examples:

- improve football catching
- become football commentator

Required proof:

- Catching skill slice loads catching, route, hand-eye, and proof-drill nodes only.
- Commentator path uses football knowledge plus communication/media alternative path overlays.
- OptionValueMap transfers football IQ, film study, and communication proof where supported.

### U.S. President Strict Source Overlay

Goal example:

- become U.S. president

Required proof:

- Legal/civic eligibility is strict-review and source-needed unless official/current source proof exists.
- The fixture must not provide legal advice or eligibility certification.
- Projection receipt must state what is source-backed, what is excluded, and what requires human review.

### Job Posting Example-Only

Goal examples:

- become product manager
- qualify for this job posting

Required proof:

- A job posting is example market evidence, not universal career truth.
- Employer-specific requirements are source-scoped and freshness-labeled.
- Projection distinguishes transferable capabilities from employer-specific criteria.

### School Program Strict Review

Goal examples:

- apply to a school program
- plan prerequisites for a degree

Required proof:

- Admissions, deadlines, costs, residency, accreditation, and prerequisite claims require strict source/freshness review.
- The fixture must not imply admission certainty.
- Source-needed fallback provides general starter planning without current requirement claims.

### Certification Strict Review

Goal examples:

- get certified as X
- prepare for certification renewal

Required proof:

- Eligibility, fees, renewal, deadlines, exams, and jurisdiction claims are strict-review.
- Certification handbook data cannot certify user eligibility.
- ProjectionProfile must carry location, deadline, current credential state, and source freshness where relevant.

### Option Value / Still Counts

Goal examples:

- I might stop pursuing this path
- what still counts if I pivot?

Required proof:

- OptionValueMap identifies transferable proof only when requirement/source/evidence overlap supports it.
- AlternativePathSet preserves adjacent paths and explicit no-known-alternative reasons where needed.
- User-facing receipt language may use `Still Counts` without shame or fake certainty.
