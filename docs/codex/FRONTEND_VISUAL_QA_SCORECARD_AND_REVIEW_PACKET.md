## Scorecard

Score 1-100:

- first-glance clarity
- native iPhone believability
- visual hierarchy
- surface originality
- restraint
- emotional tone
- accessibility resilience
- motion/interaction believability
- product-language quality
- system coherence
- maintainability
- screenshot evidence quality

## Status Rules

Green:

- average >= 90
- no category below 85
- no hard Red

Yellow:

- average 80-89
- no hard Red
- named owner and safe continuation reason

Red:

- average below 80
- missing visual evidence
- any hard Red

## Review Packet Required Fields

- touched surfaces
- owner files
- evidence paths
- first-viewport budget table
- bottom chrome owner
- primitive density role
- copy compression result
- accessibility evidence
- motion/Reduce Motion evidence
- scorecard
- Yellow/Red owners
- release/platform non-claims
- rollback path
