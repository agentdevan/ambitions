# Transformative Motion Implementation Protocol

Status: Active

## Start

- Read Signature Experience Layer.
- Read Transformative Motion System.
- Confirm the motion primitive and owner surface.
- Confirm Reduce Motion, VoiceOver, Dynamic Type, preview, and performance
  evidence plan before code.

## Implementation Rules

- Use native SwiftUI and existing Ambitions design system.
- Keep motion scoped to the named primitive.
- Prefer short, interruptible, state-linked transitions.
- Do not add dependencies.
- Do not use motion to imply automation or hidden intelligence.

## Stop On Red

Stop if motion has no state meaning, no Reduce Motion equivalent, harms
readability, touches forbidden files, or creates release/accessibility claims.
