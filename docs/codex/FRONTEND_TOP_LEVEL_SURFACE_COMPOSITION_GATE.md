## One Thesis Per Surface

- Today: Start Here / Reality Meridian. The user should know what to do now.
- Goals: Constellation Atlas / equal-weight goal map. The user should see life direction without ranking.
- Capture: Atmosphere Composer / safe intake. The user should know where to put an unplaced thought.
- Time: LifeShape Field / pressure and available room. The user should see what the week can hold without a calendar clone.
- You: User System Profile / grouped settings control. The user should see how Ambitions works for them.

## Forbid

- surface stacks
- same panel grammar on every tab
- KPI posture on Goals
- calendar clone on Time top-level
- scrollable explainer page on Capture
- AI settings console posture on You
- Mission Control as a top-level Goals identity
- product architecture exposed as root copy

## Evidence

Each touched top-level surface needs screenshot or preview evidence, primary-object declaration, first-viewport budget, surface-distinction note, accessibility note, and scorecard.
