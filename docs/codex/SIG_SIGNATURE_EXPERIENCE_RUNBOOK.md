Status: Active Codex runbook for Signature Experience batches

## Purpose

Use this runbook when a batch touches premium interaction, visual polish,
stateful modules, transformative motion, haptics, or photo-matched experience
evidence.

SIG extends DAV/PXEQ/photo-matched targets. It must not compete with them.

## Required Start

1. Verify clean `main`.
2. Confirm DAV06 or later required prerequisite status.
3. Inspect `docs/reference/visual-targets/ambitionsos-photo-matched/README.md`.
4. Inspect `docs/canon/Ambitions_4_0_Signature_Experience_Layer.md`.
5. Inspect Transformative Motion docs when motion is touched.
6. Name allowed files, forbidden files, validation pack, and stop conditions.

## Execution Rules

- Keep visual work inside named owner surfaces or shared non-persistent
  SwiftUI primitives.
- Prefer native SwiftUI, current design system, and existing dependencies.
- Record preview, accessibility, Reduce Motion, and performance evidence.
- Treat missing evidence as Yellow or Red depending on user impact.

## Green / Yellow / Red

- Green: photo target cited, scorecards pass, preview/accessibility/motion
  evidence exists, no forbidden file touch, no identity split.
- Yellow: later-batch evidence remains deferred with named owner and no current
  blocker.
- Red: generic surface drift, visual gimmick, no Reduce Motion path, app
  behavior overclaim, route/schema/dependency drift, or unsupported release
  claim.
