# AMB-FE-BE Contracts

Status: Installed docs-only contract note

## Shared contract set

- Active top-level IA remains `Today / Goals / Capture / Time / You`.
- `Plan` stays an internal compatibility seam or contextual noun only where current truth allows it.
- No prompt in this train may create a new top-level destination, duplicate canon, or duplicate repo OS.
- No prompt may claim release, device, accessibility, privacy/legal, CI, or integrated proof without current evidence.
- No prompt may widen into `.codex/runs/` staging, branch creation, or unrelated cleanup.
- Every prompt must include the runner header, active truth inspection list, allowed scope, forbidden scope, validation expectations, hard Red stops, rollback expectations, runner command, and final report format.

## FE contract emphasis

FE prompts must require visual and accessibility proof expectations wherever the batch touches UI.

## BE contract emphasis

BE prompts must require explicit source/runtime/persistence seam naming and must not assume cloud, hosted AI, or hosted sync.

## Non-claims

This file is a contract index, not implementation proof.
