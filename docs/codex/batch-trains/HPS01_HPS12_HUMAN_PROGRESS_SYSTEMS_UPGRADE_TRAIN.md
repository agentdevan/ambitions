## Placement

Preferred placement is after PFC30 Performance Budget And Instruments Plan and before FCP22 Personal System Center Refactor.

Reason:

- PFC26-PFC30 should define legal, safety, security, observability, and performance boundaries first.
- HPS must shape remaining FCP surface maturity, AOS, and LDI before they harden.
- HPS should not replay already completed FCP/PFC/FL/FVQ/CQS work.

If the live run has already advanced, insert HPS at the earliest safe remaining point and document the mismatch as accepted Yellow.

HPS strengthens the operating system. It must not widen the app.
