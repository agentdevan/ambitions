# Ambitions Prompt Quality Gate

Status: AmbitionsOS future Codex OS protocol

## Required Fields

- owner
- source docs
- affected kernel/primitive/surface
- allowed files
- forbidden files
- evidence required
- privacy/accessibility/performance/compatibility/release impact
- rollback or repair path
- Green/Yellow/Red gates
- what this does not prove

## Boundary

This protocol does not implement app behavior and does not create release claims.

Reject prompts that mix broad refactor with product behavior, mix release claims with implementation, touch too many primitives, lack validation, lack file boundaries, lack stop conditions, ask to polish everything, silently choose product direction, or imply release readiness without evidence.
