# SIG Premium Interaction Principles

Status: Active

## Principles

- Interaction should feel native, direct, and inevitable.
- A tap should clarify ownership, not surprise the user.
- Gestures require visible alternatives.
- Press, reveal, settle, and receipt states should be quiet and legible.
- Haptic intent must be sparse, native, and meaningful.
- No interaction may delay task completion for spectacle.
- Every meaningful transition needs a Reduce Motion equivalent.

## Required Checks

- Does the interaction reveal state or merely decorate?
- Does the user keep control?
- Does Dynamic Type preserve the primary action?
- Does VoiceOver describe the same state?
- Does Reduce Motion preserve meaning without movement?
