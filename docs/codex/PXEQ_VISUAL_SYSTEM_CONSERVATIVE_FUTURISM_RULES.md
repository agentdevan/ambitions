# PXEQ Visual System Conservative Futurism Rules

<!-- markdownlint-disable MD013 -->

Status: Active PXEQ visual rules.
Date: 2026-05-03

Conservative futurism means the interface feels quietly advanced because it is
alive with useful state, not because it is loud. Use restrained material,
legible depth, native spacing, precise hierarchy, and one primary object per
surface. Avoid generic cards, dashboard grids, CRM/admin language, decorative
starfields, unreadable glass, heavy blur, noisy gradients, fake AI glow, and
beauty that reduces clarity.

Glass, blur, translucency, gradients, atmospheric material, and visual effects
are allowed only when text remains readable, contrast remains inspectable, and
meaning does not depend on color alone.
