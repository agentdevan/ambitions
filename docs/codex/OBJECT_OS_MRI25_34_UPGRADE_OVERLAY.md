## Purpose

This overlay upgrades MRI25-MRI34 so the Native Signature Interface phase implements Ambitions as a living premium Object OS, not a set of generic SwiftUI screens.

Future Codex runs for MRI25-MRI34 must inspect this file before implementing runtime visual work.

## MRI25 — Shell / Continuity Dock Runtime

Upgrade scope:

- Continuity Dock
- Action Slip Tray
- Receipt Peek
- Trust Seam
- Object Inspector
- active object handoff
- quiet object chrome
- debug-only Founder QA entry point

- The shell carries the current object, not just the selected tab.
- The dock can show pending Action Slip, Active Commitment, Recovery Thread, Source Review, or Proof Opportunity.

- Motion preserves object continuity across surfaces.

- sixth top-level tab
- generic floating card dock
- chatbot shell
- surface chrome
- sticky task bar

## Object OS visual grammar summary

Use this grammar unless a future runtime batch supersedes it with explicit proof:

- Ambition = constellation / gravitational body
- Goal Thread = path / orbit
- Commitment = tether / active line
- Step = action bead / node
- Proof = trace / glint / anchor
- Source = foundation anchor
- Constraint = boundary / weight
- Recovery = return path
- Reflection = echo / afterimage
- Pressure = density field
- Protected time = quiet boundary
- Receipt = discrete stamped evidence
- Learning Signal = inspectable local trace
