# AMB-CHATGPT-FLAGSHIP-BAR

Status: supporting quality bar

This bar defines the minimum quality for ChatGPT-generated Ambitions handoffs.

## Required qualities

- Active truth first.
- Narrow scope.
- Runner header preserved.
- Exact validation listed.
- Claims bounded to evidence.
- No duplicate authority root.
- No generic productivity framing.
- No false release or implementation claims.

## Hard stop language

Do not use this layer to imply:

- release proof without logs
- accessibility proof without checks
- privacy proof without review
- local-first proof without source and validation
- visual quality without rendered evidence
