Status: supporting decision log

This document captures launch-scope decisions for ChatGPT handoffs. It is
supporting material only.

## Current reconciled decisions

- Ambitions should be framed as a flagship local-first Personal Life Operating
  System, not a rushed v1.
- Time is active top-level IA.
- Plan remains an internal compatibility seam or contextual action noun where
  active truth allows it.
- A custom production server should not be promoted as launch-required.
- A custom account system should not be promoted as launch-required.
- A full custom encrypted sync/key hierarchy is post-v1 unless active truth
  changes that scope.
- A full chaos suite is post-v1, but minimum durability tests are required
  before launch claims.
- Apple-native continuity is preferred where active truth allows it.
- Pre-launch continuity target is Apple-native iCloud/CloudKit across the
  user's Apple devices, not a custom Ambitions server.
- Local store remains primary.
- iCloud continuity is replication and continuity only; it is not intelligence
  authority.
- Pre-launch requires minimal day-state maintenance.
- Pre-launch requires basic search and retrieval, not a full FTS sidecar.
- Pre-launch requires basic diagnostics and trust proof, not a full SLO
  platform.
- Pre-launch requires migration safety.
- Pre-launch requires durable operation and receipt handling, not full
  replay-from-genesis.
- Trust is the launch gate.
- No weak moat.
- No v1-feeling App Store release.
- Claims about launch readiness require current evidence.

## Conflict handling

If a future ChatGPT prompt conflicts with active truth, the prompt must be
reconciled downward or marked as unresolved rather than promoted.
