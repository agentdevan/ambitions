# PXOS Codex OS Upgrade Protocol

Status: Future Codex OS protocol; PXOS implementation not started
Date: 2026-05-02

## Upgrade Goal

Make future PXOS batches safer, more deterministic, more FAANG-caliber, less
vague, less prone to visual/product drift, and more executable.

## Durable Controls

- Product Decision Ledger prevents Codex invention.
- Batch Prompt Standard prevents vague prompts.
- Definition of Ready/Done blocks under-specified implementation.
- Gate Matrix adds product, visual, accessibility, trust, release, ME, CS, and
  AOS gates.
- Drift Detection catches product-language and product-shape regressions.
- Reorder Protocol evaluates global implementation sequencing before product
  depth or user-facing intelligence work.

## Skill Strategy

Do not create one-off PXOS skills that duplicate existing skills. Use existing
product-depth, deep-not-wide, product-language, privacy, accessibility,
performance, release-claim, compatibility, maintainability, and evidence skills
with PXOS source docs loaded first. Create a new skill later only when a future
PX batch proves repeated review cannot be handled by existing skills.
