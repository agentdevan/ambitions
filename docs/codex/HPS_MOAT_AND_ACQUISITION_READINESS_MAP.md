A strategic buyer or diligence reviewer should be able to inspect:

- clean repo architecture
- schema and migration posture
- privacy/legal claim boundaries
- Human Progress Graph contracts
- Proof Ledger contracts
- Source Truth / Requirement Graph contracts
- recommendation evaluation fixtures
- AI governance risk register
- no-sprawl UX gates
- rendered visual proof
- performance budgets
- security threat model
- export/delete/correction posture
- future vertical expansion boundaries
- API/platform architecture map
- final no-claim packet

## Diligence blockers to avoid

- app looks like AI-generated card stack
- unowned architecture
- hidden mutation
- no source/proof model
- weak privacy/memory controls
- unsupported legal/career/education claims
- analytics/logging of sensitive life data
- no evaluation suite
- no rendered visual proof

- overbuilt vertical products before consumer wedge proves value
