# Dependency Risk Ledger

Status: Active Codex OS protocol; not implementation evidence.
Date: 2026-05-03

This document defines: No new runtime package dependencies are approved by this Codex OS upgrade. Future dependency proposals require package, purpose, owner, alternatives, security/privacy risk, maintenance risk, license risk, platform impact, build impact, rollback, and Red/Yellow/Green decision.

Green requires source truth, allowed/forbidden files, evidence, validation, and conservative claim boundaries. Yellow requires owner and safe deferral. Red stops or enters the Red repair decision tree.
