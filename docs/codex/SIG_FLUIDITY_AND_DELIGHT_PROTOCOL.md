# SIG Fluidity And Delight Protocol

Status: Active

## Purpose

Define delight as comprehension, confidence, and desire to return. Delight is
not confetti, novelty, or animation volume.

## Required Delight Pattern

1. A state becomes clearer.
2. The next action becomes easier.
3. The user keeps control.
4. The surface feels calmer after the interaction.
5. Accessibility equivalents preserve the same meaning.

## Forbidden

- infinite decorative motion;
- fake AI glow;
- reward loops that turn proof into gamification;
- motion that hides content or blocks action;
- product-still visuals that reduce readability.
