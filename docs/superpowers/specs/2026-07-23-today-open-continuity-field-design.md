# Today Open Continuity Field — Design Specification

**Identity:** `AVF-TODAY-S10-B02-R00`

**Status:** implementation approved by owner; visual acceptance pending

**Boundary:** `AmbitionsNativeVisualFoundry` and its fixture host only

## 1. Thesis

Today is an open semantic plane that organizes immediate lived reality through
one restrained Continuity Spine. Canonical objects receive local relief only
when state, consequence, or interaction requires it. Geometry, alignment,
scale, temporal relationship, native material, and motion communicate meaning;
copy confirms it.

The result must feel like a calm native Personal Life OS, not a task manager,
agenda, dashboard, Settings form, web card stack, or AI assistant.

## 2. Protected semantics and boundaries

The fixture, stable identities, truth-state transitions, Still Counts review,
saving, settlement, History disclosure, explicit return, de-duplicated revealed
Start Here, and recovery commands remain unchanged. Today, Goals, Time, and You
remain the roots; Search and Capture remain separate global dock actions.

No production entry, runtime adapter, legacy UI, other root, temporal mutation,
dependency, final design token, global component API, production localization,
Figma artifact, Code Connect artifact, or production screenshot baseline enters
the branch. `APPROVED FOR SWIFTUI` remains false.

## 3. Spatial model

### Open plane

The root and focused depths use one natural `ScrollView` on a matte mineral or
deep-graphite canvas. Headings, temporal anchors, relationships, and ordinary
timeline objects remain open to the plane. No nested scrolling exists inside a
content object.

### Articulated object relief

Only Start Here, current truth, proposed truth, settlement, interruption, and
meaningful dense-state groupings receive localized opaque relief. Relief uses
tonal elevation, a partial edge, purposeful overlap, and spacing. It does not
use identical full-perimeter cards.

### Continuity Spine

A narrow neutral structural spine links the object’s semantic moments. It is
not a progress meter and never fills by percentage.

- Current: open circular node plus text label.
- Proposed: paired offset node plus explicit proposed label.
- Saving: the connector becomes active beside native progress; current remains
  open and proposed remains paired.
- Settled: resolved inset node plus explicit settled wording.
- Interrupted: retained gap or notched seam plus interruption wording.
- Protected: a square node containing the `shield` SF Symbol, joined to a short
  boundary bracket.
- Fixed: a rotated square (diamond) node with a centered anchor point.
- External: an open square node.
- Open lane: two short parallel marks separated by open canvas.

Color reinforces but never owns these distinctions. Under Differentiate
Without Color and Increased Contrast, shape, stroke, text, and spacing become
more explicit.

## 4. Brand and crown

The root-only crown presents a restrained `Ambitions` wordmark using system
typography and one concise present-context phrase. `Today` remains the
accessibility screen heading but is not repeated as a large visible shell
title. The crown condenses through native scroll geometry without sticky hero
behavior, blur spectacle, or an animation required for meaning.

Focused depth uses native Back navigation and the Step identity in content. It
does not repeat the wordmark or use a centered `Start Here` navigation title.

## 5. Provisional local visual grammar

### Palette roles

Journey-local dynamic roles are `canvas`, `canvasElevated`, `objectRelief`,
`objectInset`, `labelPrimary`, `labelSecondary`, `labelTertiary`, `separator`,
`ambitionsAccent`, `ambitionsAccentMuted`, `currentTruth`, `proposedTruth`,
`settledTruth`, `interruptedTruth`, `protectedState`, `fixedState`, and
`externalState`.

Dark is deep graphite with low-brightness separation, never featureless black.
Light is mineral-neutral, never a pure-white dashboard. Violet-indigo is
restricted to primary action, selected shell state, and proposed articulation.
Settled and interrupted use restrained moss/mineral and amber seams, never
broad green or brown cards. Protected, fixed, and external states use minimal
structural distinctions.

### Materials

Primary content is matte and opaque. Liquid Glass may appear only on functional
dock/transient action chrome through current native APIs. Reduce Transparency
replaces it with an authored opaque surface and visible boundary. No content
card uses glass or custom blur.

### Shape

Corners communicate grouping. Start Here uses one inset opaque relief plane with
20-point top-leading and bottom-trailing corners, 4-point opposite corners, no
perimeter stroke, and a leading Continuity Spine that enters the plane and ends
at the action shelf. RTL mirrors leading/trailing. Truth regions use smaller
12/4-point asymmetric grouping. Timeline rows stay open. Pills are reserved for
native compact controls that platform semantics require.

### Typography

System semantic styles define five roles:

1. Object identity — decisive title/title2 depending width and Dynamic Type.
2. State — headline/body with full legibility.
3. Relationship — subheadline/body.
4. Metadata — footnote/caption only when genuinely secondary.
5. Action — semibold body/headline.

One compact object uses at most three sizes and two weights. Uppercase
micro-labels are removed except where the locale’s platform convention makes a
short label appropriate. Time values may use monospaced digits. Essential text
never uses a fixed screenshot-tuned point size.

### Actions

- Primary continuation: one centered, 44-point minimum native prominent action.
- Primary commitment: one safe-area-anchored `Record Progress` control.
- Secondary cancellation: native secondary treatment, equal target, no fill
  competition.
- Navigation: row/disclosure/toolbar semantics for Full Day, History, and Return.
- Still Counts remains the only displayed executable outcome.

All controls have a visible pressed state, distinct Voice Control names, native
focus, and a non-color disabled state. Chevrons appear only for navigation.

### Iconography

SF Symbols provide familiar navigation, time, protection, history, search, and
capture glyphs. Each relationship row uses at most one leading symbol. Symbols
scale with text, mirror only when semantically directional, and carry explicit
accessibility labels when not accompanied by text. No sparkle, AI, decorative
plus, or custom font symbol is used.

## 6. Shell

### Dock Peek

The right-edge Peek is a single tap-first control with a 44-by-64-point
interaction envelope and a visible 14-by-52-point edge seam. The seam contains
one 11-point `sun.max.fill` Today glyph above a short inset root mark; pressed
state expands the opaque/material field within the envelope. It remains
subordinate, stable during scrolling, and visually connected to the plane. It
does not resemble a scrollbar, drag handle, Back control, or detached button.

### Expanded dock

The Peek morphs into an edge-attached navigation passage. Roots appear in exact
order Today, Goals, Time, You, then a clear separation, then Search and Capture.
The generic `Navigate` label is removed. Selected Today uses icon, geometry,
label, and material, not hue alone. Native dismissal and safe areas remain.

At accessibility pressure, the existing Adaptive Navigation Passage replaces
ordinary Peek. It remains scrollable, opaque, labelled, and grouped without
competing with another oversized control block.

## 7. Today root

The default first viewport contains:

1. Ambitions crown and present context.
2. One Start Here object.
3. One current-truth line.
4. One synthesized why-now/protection line.
5. One temporal relationship.
6. One primary continuation action.
7. A three- or four-anchor overview timeline.
8. Dock Peek.

### Start Here anatomy

The object is attached to the open plane and Continuity Spine. It has one small
Start Here indicator, decisive Step identity, parent pursuit, concise current
truth, one combined fit/protection relationship, time relationship, and an
anchored `Continue Nursery Setup` action. Full rationale remains in focused
depth. It is one accessibility group with separately actionable continuation.

### Overview timeline

The root shows no more than four anchors: Now, next fixed, protected, and an
open lane or later meaningful object. An aligned time column, continuous rail,
compact identity, one subordinate relationship/state line, and non-color node
form make it scannable. Start Here is not repeated. `View Full Day` is a native
navigation action.

The Start Here object is the root's explicit Now anchor. The overview never
duplicates it. Overview selection is deterministic: remove the visible Start
Here identity, then choose the earliest fixed object, the first protected
object, the first open-lane or later object, and the earliest remaining distinct
ordinary object, de-duplicating in that order and stopping at four. Quiet uses
Start Here plus one protected object and one explicit open-lane snapshot. Dense
uses the same four-slot rule over six objects. Very dense uses it over ten
objects. The complete unchanged sequence remains in Full Day. Variants never
manufacture urgency or move fixed reality.

## 8. Full Day

Full Day is a read-oriented Today depth backed by the same immutable timeline
snapshot. It provides complete fixture chronology, a visible Now position,
protected/fixed/external/open relationships, dense transformation, and object
selection only where the source-backed Step route exists. It contains no time
editing, calendar grid, drag behavior, or fabricated `Open in Time` route.

It uses native navigation Back, natural scrolling, `ScrollViewReader` for a
source-backed Scroll to Now control, and the same timeline/spine anatomy. It
does not replace Today or claim Time ownership.

The state contract is exact:

```swift
public enum TodayFlagshipFullDayOrigin: String, Hashable, Sendable {
    case todayInitial
    case todayReturned
}

public enum TodayFlagshipRoute: Hashable, Sendable {
    case fullDay(origin: TodayFlagshipFullDayOrigin)
    case step(id: String)
}

public mutating func openFullDay() -> Bool
public mutating func openStepFromFullDay(id: String) -> Bool
public mutating func reconcileNavigationPath(_ path: [TodayFlagshipRoute])
```

`openFullDay()` is valid only from `.todayInitial` or `.todayReturned`, appends
`.fullDay(origin:)`, and does not change phase, accepted truth, proposal,
commitment, or receipt. Full Day resolves its explicit Now row from the route
origin: `.todayInitial` uses the nursery Start Here Step, while
`.todayReturned` uses the newly revealed `step.send-launch-brief` Start Here.
Both are projections of existing fixture snapshots, not new fixture truth.

`openStepFromFullDay(id:)` is valid only from `.todayInitial`, only for the
source-backed primary Step, and only when the path is
`[.fullDay(origin: .todayInitial)]`. It appends `.step(id:)` and changes depth to
focused-current without changing truth. Popping the Step restores
`.todayInitial`, Full Day, and focus to the explicit Now Step row. Popping Full
Day restores the exact origin phase and focus to `View Full Day`.

After truthful return, Full Day uses `.fullDay(origin: .todayReturned)`. The
settled nursery Step and revealed Start Here are read-only there because no
focused journey for the revealed Step is fixture-backed and the settled Step
must not regain Still Counts. `openStepFromFullDay` returns false and cannot
regress `.todayReturned`. Direct initial Start Here continues to use a single
`.step` route. Unknown rows always remain read-only.

The immutable content adapter therefore exposes
`nowAnchorObjectID(for origin: TodayFlagshipFullDayOrigin) -> String`. It
returns the primary nursery Step ID for `.todayInitial` and the revealed Start
Here ID for `.todayReturned`. Scroll to Now and the visible Now node consume
this resolver; neither caches a pre-settlement ID nor parses localized copy.
Returned-origin tests assert that the revealed Start Here owns Now while the
nursery Step remains present as settled, subordinate, and read-only.

## 9. Focused Step

One natural scroll contains:

1. native Back;
2. compact object-type/continuity indicator;
3. large stable Step identity;
4. parent pursuit;
5. formed neutral current truth;
6. compact Why Now relationship;
7. compact Protected Consequence relationship;
8. temporal anchor;
9. optional context/history disclosure when source-backed;
10. anchored Still Counts action.

Identity, current truth, fit, protection, and time are recognizable before all
copy is read. No internal canon terminology, passive outcome list, Form,
Settings anatomy, nested scroll, or giant universal card is present.

## 10. Consequential review

The existing native full-screen presentation remains. The Step identity anchors
an aligned spatial comparison:

- Current region: neutral relief, open current node, accepted present reality.
- Proposed region: restrained proposed relief, paired node, Still Counts result.
- Between: a static transition seam that does not imply automatic mutation.

Below, `What Changes`, `Also Updates`, one quiet on-device History cue, and a
collapsed native Details disclosure retain exact consequence without a
developer diff. Standard Dynamic Type shows identity, current, proposed,
consequence, relationship, `Not Now`, and `Record Progress` without scrolling.
Accessibility Dynamic Type may scroll naturally; both actions remain reachable.

## 11. Saving

Saving keeps the same object and current/proposed comparison visible. Current
truth remains identifiable. Duplicate commitment is disabled. Native progress
appears beside the commitment region and the connector becomes active without
success color or whole-screen dimming. VoiceOver announces the operational
state once. Synthetic timing remains evaluation-only.

## 12. Settlement and History

Settlement keeps the stable Step identity and resolves the Continuity Spine.
The changed accepted truth is the dominant region, parent-pursuit continuity is
visible, and on-device evidence is a compact subordinate row. `View History`
opens and closes the existing secondary disclosure without mutation. `Return
to Today` remains explicit and anchored. No green card, checkmark ceremony,
score, streak, confetti, or automatic dismissal appears.

## 13. Returned Today

The nursery Step moves from Start Here into a compact settled timeline/state
row identified by the return anchor. `step.send-launch-brief` appears once as
the new Start Here with its time relationship. Focus initially targets the
settled nursery Step; the new priority does not steal focus. The overview is
reselected to show changed reality without duplicating identity, stale geometry,
reward language, or feed anatomy.

## 14. Recovery and resilience

The native recovery sheet remains object-scoped. It shows stable Step identity,
an interrupted seam, last saved progress, concise explanation, `Continue Where
You Left Off`, `Leave for Later`, and native dismissal. The underlying focused
object remains perceptible where the platform allows. Deferral and dismissal
mutate nothing.

The immutable content adapter gains two explicit evaluation-only types:

```swift
public enum TodayFlagshipTimelineRole: String, Sendable {
    case now, ordinary, fixed, protected, external, openLane
}

public enum TodayFlagshipContextCondition: String, Sendable {
    case offlineLocalTruth, staleExternalContext, conflictTransfer
}
```

`TodayFlagshipTimelineObject` gains `role`, defaulting from its existing
protected/fixed booleans for source compatibility. Content also resolves the
explicit Now identity with
`nowAnchorObjectID(for: TodayFlagshipFullDayOrigin)`: the initial origin maps to
the primary nursery Step and the returned origin maps to the newly revealed
Start Here. Full Day's Now projection and Scroll to Now both use this resolver.
No view parses a localized time or label to discover Now. A new optional
`TodayFlagshipContextSeamSnapshot` carries `condition`, `title`, `body`,
`affectedObjectID`, `ownerTitle`, and a complete `accessibilityLabel`.

- Offline local truth is attached to the nursery Step and says the saved local
  truth remains available. It has no retry or network control.
- Stale external context is attached to the existing work commitment and says
  its external timing has not refreshed. It has no false refresh control.
- Conflict transfer names the affected nursery/time relationship and says
  placement review belongs in Time. Because no source-backed route exists, it
  is read-only and exposes no `Open in Time` control.

Quiet, dense, and very-dense content variants construct explicit timeline
snapshots with these roles. Unsupported Undo and unsupported outcome controls
remain absent. View helpers never infer a condition from copy or color.

Focus anchors add `fullDayAction`, `fullDayNow`, and `fullDayStep`. Native path
reconciliation uses them to restore the exact initial or returned origin rather
than treating every pop as a return to initial Today.

## 15. Motion and haptics

Normal motion is short, causal, and identity-preserving. The Continuity Spine
and object identity persist through root-to-focus, proposal, saving, settlement,
return, dock expansion, timeline updates, and recovery. Native presentation
transitions own depth. No ambient loop or spectacle exists.

SwiftUI environment-driven Reduce Motion replaces matched travel, zoom, spring,
blur, and large morphs with static state seams, native focus, and short opacity
changes. Haptics are restrained: selection for outcome/dock selection,
commitment for Record Progress, subtle success for settlement, and no feedback
for mere dismissal. Haptics never carry sole meaning and remain direct-device
obligations.

## 16. Accessibility and adaptivity

Dynamic Type recomposes horizontal clusters into vertical layout; it never
shrinks essential text. VoiceOver exposes one dominant Start Here group, stable
object identity, concise state values, distinct actions, modal focus, saving
announcement, and truthful return focus. Increased Contrast strengthens strokes
and control boundaries. Differentiate Without Color adds node geometry and
text. Reduce Transparency makes dock chrome opaque. Bold Text and Button Shapes
remain native.

The layout uses leading/trailing alignment, safe areas, flexible stacks,
container width, and native scrolling. It is rendered on compact iPhone,
standard Pro, Pro Max, narrow/wide mirroring or resizable widths, RTL, long
localization, status-bar pressure, and keyboard-present state when input exists.
No fixed screenshot coordinates are allowed.

## 17. Performance

State and fixture snapshots remain small value types. Views receive only the
fields they render. Timeline identity remains stable; longer chronology uses
lazy containers where appropriate. Geometry readers, independent glass effects,
and broad animation invalidation are minimized. The package preview loop must
remain the default inner loop without clean builds.

ETTrace is used only if observed scroll/animation symptoms warrant it. Memgraph
is used only if repeated journey execution shows suspicious growth.

## 18. Testing and evidence

Behavior and accessibility identifiers are specified with failing package/UI
tests before implementation. Tests cover the 35 required B02 contracts,
including root-only wordmark, Today accessibility heading, Full Day reachability,
dock grouping/targets, truth preservation, commitment, settlement, return,
recovery, RTL, contrast, transparency, motion, and prohibited shell patterns.

Native rendered inspection remains mandatory at full, half, and contact-sheet
scale. Evidence contains the 16 retained TFCS frames, eight additional stress
frames, four contact sheets, five continuous recordings, warm-loop measurements,
metadata, reviewer findings, performance audit, and validation results. All
artifacts set `production_baseline = false`.

## 19. Design-spec self-review

- No placeholder or unresolved alternate direction remains.
- Full Day is bounded as read-only Today context; Time ownership is intact.
- Review/recovery presentation architecture is unchanged.
- Fixture truth and canonical identities are unchanged.
- Every custom visual behavior expresses Ambitions-specific semantics.
- Native controls remain native.
- Accessibility may recompose geometry but cannot remove meaning or action.
- No prohibited production, dependency, IA, localization, or authority change
  is implied.
