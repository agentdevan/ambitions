# Today Open Vitality Field — R13 Design Specification

**Identity:** `AVF-TODAY-S10-B04-D09-R13`

**Status:** owner-selected provisional visual direction; implementation and
final visual acceptance pending

**Boundary:** `AmbitionsNativeVisualFoundry` and its fixture host only

## 1. Thesis

One canonical object and the remaining day occupy a continuous native field.
The interface becomes visually alive only when accepted reality changes.
Identity, geometry, alignment, temporal relationship, node shape, restrained
material, and native motion establish meaning; copy confirms it.

The result is calm, precise, personal, and operational. It must not resemble a
task list, agenda-first root, dashboard, Settings form, generic card stack,
assistant, web surface, or screenshot reproduction.

## 2. Authority and proof ceiling

Canon owns product meaning. The owner-selected standalone R13 renderings own
visual caliber after canon. B02 supplies the semantic state machine, fixture,
native presentations, accessibility scaffold, and test harness.

The work remains fixture-driven. No production entry, runtime adapter,
production mutation logic, legacy frontend, other-root reconstruction,
dependency, final token, global component API, production localization,
production screenshot baseline, Figma artifact, or Code Connect artifact is
allowed. `APPROVED FOR SWIFTUI` remains false. Simulator evidence does not close
direct-device proof.

Primary product UI and owner journey evidence are English. A genuine RTL
fixture is retained only as an isolated accessibility stress proof.

## 4. Spatial model

### Open plane

Every depth uses one matte mineral or graphite canvas and one natural scroll
container. Titles, relationships, temporal rows, evidence, and navigation
remain open. No primary content uses glass or a nested scroll view.

### Open relief

Current, proposed, settled, and interrupted truth receive a localized tonal
lift and one meaningful seam. Relief does not create a complete generic card
per label or state. No shadow halo or glow is permitted.

### Continuity rail

One structural rail connects object truth and day position. It never fills by
percentage and never implies task progress. Its node shapes remain distinct
without color:

- current: open ring with stable center;
- fixed/next: anchored diamond or ring with anchor mark;
- protected: bounded node with shield form;
- open: broken or dashed ring;
- proposed: paired or offset current node;
- saving: active connector plus native progress, with current unchanged;
- settled: resolved double ring or inset center;
- interrupted: broken retained ring.

Increased Contrast strengthens outline and seam. Differentiate Without Color
adds explicit labels and preserves distinct geometry.

## 5. Brand, crown, and shell

The root-only crown uses system typography for a restrained `Ambitions`
wordmark and one present-context phrase. `Today` remains the accessibility
heading. The wordmark recedes with native scrolling and never appears in
focused depth.

The right-edge Dock Peek is a tap-first root control with at least a 44-point
interaction envelope, a recognizable Today glyph/state, and a visually narrow
edge-attached seam. It must not resemble a scrollbar, Back control, or drag
handle. It uses functional Liquid Glass only where available and appropriate;
Reduce Transparency renders an authored opaque equivalent.

Expanded dock order is Today, Goals, Time, You, then a separate Search/Capture
group. Selected Today uses icon, geometry, label, and material, not hue alone.
The expanded dock becomes vertically scrollable or adaptive when compact
height would otherwise trap commands. Accessibility pressure replaces Peek
with the existing Adaptive Navigation Passage.

The dock is root-owned and absent from native focused and consequential depths,
despite its presence in generated references. Native Back and presentation
ownership outrank the rendering artifact.

## 6. Local visual grammar

### Color and material

Dark is deep graphite rather than pure black; Light is mineral-neutral rather
than pure white or beige. Violet-indigo marks primary interaction, selection,
and proposal. Settled uses a restrained mineral/moss seam; interruption uses a
restrained amber seam. Fixed, protected, external, and open states use minimal
semantic distinctions. Hue never owns meaning.

Primary content remains matte and opaque. Native glass is reserved for dock,
sheet/action chrome, and transient controls. No gradient CTA, scenic field,
decorative texture, or broad saturated state panel is allowed.

### Typography

System typography provides five roles: object identity, state truth,
relationship, metadata, and action. A compact object shows no more than three
sizes and two weights. Object identity is decisive but does not consume the
viewport; current truth is the second landmark. Metadata remains readable.
Times use monospaced digits when alignment benefits. Dynamic Type recomposes;
nothing shrinks to preserve screenshot geometry.

### Actions

- Continue enters or resumes an object and uses one 48–52-point centered native
  control attached to object anatomy.
- Still counts is the only displayed outcome and remains distinct from commit.
- Record Progress is the strongest safe-area-anchored commitment control.
- Not Now and Leave for Later are neutral, equal-height secondary actions.
- Return to Today, View Full Day, View History, Details, and Scroll to Now use
  native navigation/disclosure treatment, not mutation styling.

All targets are at least 44 points, expose distinct Voice Control names, have
native pressed/disabled state, and use chevrons only for navigation.

### Iconography

Use SF Symbols for familiar platform concepts. One leading symbol per compact
relationship row is the maximum. Symbols scale with text, mirror only when
directional, and have explicit accessibility labels. No sparkle/AI imagery,
decorative plus, or custom symbol font is allowed.

## 7. Today Root

The first viewport contains crown/context, one Start Here, current truth, one
combined why/protection sentence, one time posture, Continue, three Later Today
anchors, View Full Day, and Dock Peek.

Start Here is an open object attached to the continuity rail. It contains the
Step title, parent pursuit, current node, present truth, consequence, time, and
one action. It is not a bordered card. It is one dominant accessibility group
with the action separately reachable.

Later Today is an overview, not the full chronology. It uses a leading aligned
time column, one rail, object identity, and one subordinate line. Initial root
shows 2:00 PM fixed handoff, 5:30 PM protected family time, and open after
6:30 PM. Returned Today replaces Start Here with the revealed Step once and
integrates the settled nursery Step as a compact rail entry. No fake Continue
route is shown for the revealed Step.

## 8. Focused Step

Native Back returns to Today. Stable node/title alignment preserves identity.
The depth presents Step identity, parent pursuit, current truth, concise
why/protection synthesis, time posture, and Still counts. It does not use a
Form, generic detail card, document labels, or persistent root dock. The action
opens review without mutation.

## 9. Consequential review and saving

Review is a native full-screen presentation. One vertical comparison field
shows current truth, a static transformation seam, and the Still counts
proposal. Current and proposed remain explicit and non-color distinguishable.
The screen includes the exact consequence, affected pursuit, local-History cue,
collapsed Details, Not Now, and Record Progress. Standard Dynamic Type exposes
the complete commitment boundary without scrolling; accessibility sizes may
scroll naturally.

Saving is the same review field in transaction posture. Current and proposed
remain visible, duplicate commitment and cancellation are disabled, native
progress appears inside the disabled commitment region, and one VoiceOver
announcement states Recording progress. A failed synthetic commit returns to
an explicit failed-settlement posture with accepted truth intact and a truthful
retry/dismissal route; it must never remain trapped in saving.

## 10. Settlement, History, and return

Settlement retains Step identity and resolves the rail into one settled node.
The changed truth is dominant. Goal lineage and `Recorded in your local
history` remain subordinate. View History is non-mutating. Return to Today is
explicit neutral navigation rather than a success or mutation CTA. There is no
Back path that can regress the committed state and no automatic dismissal.

History Entry exposes exact recorded truth, timestamp, Step, Goal, and local
device cue. Filters use native selection for All, Today, Last 7 Days, current
Goal, and current Step. They do not create an activity dashboard.

On return, the nursery Step becomes one settled rail entry and receives focus.
`step.send-launch-brief` becomes the unique read-only Start Here. Family time
and open time remain stable. The new priority does not steal focus.

## 11. Full Day and supporting drill-downs

Full Day is native read-only Today depth. Read-only forbids temporal mutation
but preserves B02's source-backed, non-mutating canonical Step inspection,
native Back, and origin-specific focus restoration. It uses one leading monospaced time
column and rail for 9:00 AM deep work, Now/10:30 nursery Step, 2:00 PM launch
brief, 3:30 PM open lane, 5:30 PM protected family time, and open after 6:30 PM.
It has Scroll to Now, no calendar grid, editing, drag, false duration scale, or
fabricated Time route.

Goal Detail provides concise context for `Welcome our baby home` without Goals
root reconstruction. Time Transfer explains that exact changes belong in Time.
Because the current Foundry has no source-backed route, Time Transfer exists
only as a directly launched fixture-host evaluation state, absent from the
product journey UI. It renders a truthful unavailable posture and cancellation,
not a fake navigation.
Consequence Details contains source-backed impact, visibility, Goal, local
History, protected boundary, and inverse eligibility.

## 12. Recovery and resilience

Interruption adds one narrow seam to the stable focused object while preserving
accepted truth. A native medium/large sheet shows identity, saved progress,
Continue Where You Left Off, and Leave for Later. Continue restores saved
posture; deferral and dismissal mutate nothing. The sheet scrolls at large type
and restores meaningful focus.

Offline retains local truth, permits the fixture-supported local Still counts
closure, and separately labels unavailable external context. Stale
context preserves the Step, labels outside facts as outdated, and permits only
source-supported Review Changes. Failed settlement preserves accepted truth.
Blocked consequence and conflict transfer remain distinct, narrow owning-scope
states; conflict transfer delegates exact chronology without silently moving
Today truth. Undo appears only in
a dedicated exact-receipt fixture whose current revision and dependencies meet
the canonical inverse contract; Keep is always safe and History is retained.

## 13. Quiet, dense, and adaptive states

Quiet, typical, dense, and very dense fixtures reuse the same semantic anatomy.
Root still shows at most three Later Today anchors; Full Day owns complete
chronology. Dense fixtures never manufacture urgency or move protected/fixed
reality.

Compact iPhone, Pro, Pro Max, narrow mirrored/resizable width, expanded status
area, long English, and keyboard-present states use safe areas, adaptive stacks,
container-relative layout, natural scrolling, and flexible line wrapping. No
fixed screenshot coordinates are permitted.

## 14. Accessibility

Accessibility Dynamic Type stacks compact comparisons, keeps current truth in
the first meaningful region, preserves all actions, and replaces Dock Peek with
the Adaptive Navigation Passage. VoiceOver orders identity, lineage, truth,
consequence, time, then action; review orders current, proposed, consequence,
Details, cancel, commit; settlement orders changed truth before evidence and
return.

Focus targets are actual semantic controls or truth elements, not container
proxies. Return targets the settled nursery entry. Increased Contrast strengthens
geometry; Differentiate Without Color preserves labels and node shape; Reduce
Transparency uses opaque chrome; Reduce Motion uses stable placement and
crossfade. Bold Text, Button Shapes, grayscale, Smart Invert, Voice Control,
Switch Control, Full Keyboard Access, 44-point targets, and RTL logical order
are tested where Simulator permits. Physical spoken order, haptics, reach, edge
competition, and low-brightness behavior remain direct-device obligations.

## 15. Motion and haptics

Motion is low-amplitude and continuity-preserving: root identity opens through
native navigation; proposal appears without replacing current truth; saving
activates one transaction seam; settlement resolves nodes; return restores the
settled object in the rail; dock Peek expands through native material; recovery
uses the native sheet. No loop, particles, glow, bounce, autonomous timeline,
or motion implying silent scheduling is allowed.

Haptic intent is selection, commitment, settlement, and newly surfaced
interruption only. Simulator evidence documents the contract, not physical
haptic proof.

## 16. Architecture and performance

The public immutable snapshot/fixture/view boundary remains stable. New
journey-local views are small composition units within the Foundry target. The
state model uses explicit enum routes and phases. No view owns durable mutation
logic. B02 files larger than 300 lines are not expanded further when a focused
R13 file can own the new anatomy.

Observation stays at the journey boundary, timeline identities are stable,
Full Day uses lazy containers, materials are limited to chrome, and animations
are scoped to semantic changes. Package preview hot reload remains the default
loop. ETTrace or memgraph is required only if rendered symptoms justify it.

## 17. Testing and evidence

Tests cover semantic state, accessibility labels/order, target geometry,
failure recovery, de-duplication, read-only Full Day, source-backed inverse
gating, locked dock ownership, and scope guards. Native screenshots and journeys
remain required because source tests do not prove visual quality.

The final evidence package contains the required primary, drill-down,
resilience, stress, device, and accessibility frames; six journeys; contact
sheets; reference comparisons; warm-loop data; performance review; independent
review findings; command log; metadata; exact SHAs; and honest limitations.
All artifacts set `production_baseline = false`.

## 18. Self-review

This specification has no placeholders or unsupported route promise. It resolves
reference/canon conflicts explicitly, preserves fixture truth, isolates RTL to
stress proof, keeps mutation outside views, retains native presentation, and
does not broaden authority. Implementation can proceed without another owner
decision unless a named stop-loss conflict appears.
