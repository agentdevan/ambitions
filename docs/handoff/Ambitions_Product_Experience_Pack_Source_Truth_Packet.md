## 3. Locked Product Identity Excerpt

Ambitions is a premium iPhone-native life operating system for execution,
goals, planning, capture, recovery, trust, and self-direction.

Visual feeling:

- 70% Apple quiet luxury.
- 20% OpenAI intelligence.
- 10% executive command surface.

Locked top-level tabs:

- Today.
- Goals.
- Capture.
- Plan.
- You.

Locked primary objects:

- Today -> Reality Rail.
- Goals -> LifePath View.
- Capture -> Text-first Capture Atmosphere Composer.
- Plan -> LifeShape Map.
- You -> Personal System Center.

MissionControlTimeSpine order:

- Completed -> Now -> Friction -> Next -> Horizon.

Core surface rules:

- Capture is text-first.
- Voice and add/attachment are secondary.
- Placement appears only after content exists.
- Plan is LifeShape-first.
- Day / Week / Month are capacity lenses, not calendar modes.
- You is trust/control-first.

Appearance Studio rules:

- Appearance Studio lives under You.
- Default accent is Gold.
- Launch accents are Gold, Platinum, Rose, Cyan, Violet.
- Accent changes emphasis only.
- Accent must not recolor semantic states.
- No full theming.
- No custom color picker at launch.

Proof, source, privacy, and receipt semantics:

- Proof is evidence, not achievement.
- Receipt is consequence and reversibility, not notification.
- Source is freshness, conflict, and review boundary, not AI verification.
- Privacy is user control, not surveillance.
- Generated visual-board copy is non-binding unless repeated in locked source
  truth.

## 6. Accessibility Requirements

- Every invented visual object requires a non-visual equivalent.
- Visual hierarchy becomes traversal hierarchy.
- Every semantic mark requires a text label.
- Meaning must not rely on color only.
- Accessibility labels must be privacy-safe by default.
- Dynamic Type collapse must preserve meaning and core actions.
- Reduced Motion static equivalents are required for motion-driven visuals.
- VoiceOver labels must not expose hidden private details.
- Touch targets, focus order, labels, and hints must remain stable through
  future implementation.

Mandatory replacements:

| failed | Blocked / Still counts / Needs recovery |
| productivity loss | Reduce the ask / Create breathing room |
| sensitive data detected | Details hidden from previews / Private detail hidden |

| monitored | You control what Ambitions remembers |
| trophy / achievement | Proof / Evidence |
| notification feed | Receipts / History |
| activity feed | Evidence Ledger / Receipt History by meaning |
| AI optimized / AI decided | Review before changing / Ambitions asks before consequential changes |

Internal compatibility rule:

Internal compatibility cases may remain when they preserve history, migration,
routing compatibility, raw-value compatibility, technical state, or legacy data
interpretation. Internal naming does not automatically equal user-facing copy.

User-facing copy boundary:

Future implementation must keep internal compatibility words out of visible
labels, VoiceOver labels, receipts, headers, buttons, tab labels, empty states,
onboarding copy, external snapshot copy, and screenshots unless active source
truth explicitly permits the wording.
