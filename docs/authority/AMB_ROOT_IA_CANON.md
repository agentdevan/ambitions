# AMB_ROOT_IA_CANON

Ambitions is a Personal Life OS. This canon locks the active root set for the product surface and keeps compatibility names in their seam-only role.

## Active IA root (hard requirement)

`Today / Goals / Capture / Time / You`

## Locked labels

- `Start here`
- `Recommended step`
- `step`
- `Start now`
- `Open step`

## Compatibility seam

- `Plan` appears in internal routing, compatibility docs, and legacy migration notes only.
- `Plan` must not be promoted back to active top-level IA in this installer phase.

## Prohibited claims

- Do not claim `Tasks`, `Habits`, `Insights`, or `Profile` as active roots in user-facing copy.
- Do not add a sixth root tab in this installer phase.
- Do not describe the root shell as a generic productivity app, task manager, calendar clone, or chatbot surface.
