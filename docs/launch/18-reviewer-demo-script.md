# Ambitions Reviewer Demo Script

Status: Draft
Purpose: App Review walkthrough guidance and reviewer clarity

## Reviewer objective

Help reviewers quickly understand:

- what Ambitions is
- how goals become daily steps
- how recommendations work
- what permissions are used for
- why the app differs from generic productivity tools

## Recommended review flow

### Step 1 — Onboarding

Complete onboarding and create a meaningful goal.

Recommended example goals:

- Prepare for a certification
- Build a healthier weekly routine
- Finish a personal project
- Prepare for a move or trip

## Step 2 — Add schedule context

Allow calendar, reminders, or availability setup if desired.

Purpose:

To help Ambitions shape recommendations around real-life time constraints.

## Step 3 — Open Today

Navigate to Today and review Reality Meridian and Start Here.

Reviewer should observe:

- grounded daily orientation
- recommendation context
- calm execution structure
- premium native iPhone composition

## Step 4 — Open Start Here

Open the recommended step.

Reviewer should observe:

- believable recommendation structure
- understandable context
- connection between goal and action
- non-chatbot interaction design

## Step 5 — Complete or close a step

Review closure and recovery behavior.

Reviewer should observe:

- non-shaming execution model
- continuity preservation
- recovery-aware structure

## Step 6 — Review trust settings

Open You → User System Profile.

Reviewer should observe:

- trust and privacy explanations
- understandable controls
- calm privacy language

## Important reviewer clarification

Ambitions is:

- a personal planning and execution system
- focused on grounded daily organization
- designed around goals and real-life adaptation

Ambitions is not:

- therapy
- mental health treatment
- financial advice
- a chatbot companion
- a habit streak system

## Permissions clarification

### Calendar

Used to help shape recommendations around real schedule commitments.

### Notifications

Used to support grounded daily continuity.

### Reminders

Used to help integrate existing commitments into the Ambitions system.

## Review preparation checklist

Before submission verify:

- screenshots reflect real UI
- onboarding matches functionality
- App Privacy disclosures match implementation
- reviewer notes are current
- no unsupported claims exist
- recommendation behavior is understandable
