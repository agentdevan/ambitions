# Ambitions App Store Screenshot Shotlist

Status: Draft
Purpose: Production capture planning for App Store screenshots

## Screenshot production principles

All screenshots must:

- use real production-faithful UI
- preserve canonical naming
- avoid placeholder content
- reflect believable life scenarios
- maintain premium native iPhone realism
- preserve one-primary-object discipline

Avoid:

- dashboard density
- fake productivity metrics
- chatbot framing
- web-app aesthetics
- streaks or gamification
