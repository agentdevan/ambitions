# Ambitions App Store Metadata Matrix

Status: Draft
Purpose: Centralized App Store metadata planning

| Area | Primary Direction | Notes |
|---|---|---|
| App Name | Ambitions | Keep clean and premium |
| Category | Productivity initially | Public framing remains Personal Life Operating System |
| Primary Tagline | Finally know how to accomplish your goals. | Canonical promise |
| Subtitle | Turn ambitions into daily progress | Current preferred subtitle |
| Promotional Text | Make your goals feel achievable again. | Calm and emotional |
| Core Positioning | Goals into grounded daily steps | Avoid productivity framing |
| Emotional Promise | Goals feel achievable | Must stay grounded |
| Primary Differentiator | Goal-to-step continuity | Strongest launch proof |
| Trust Framing | Private by design | Calm, non-performative |
| Screenshot Tone | Premium native iPhone realism | Avoid dashboards |
| Visual Style | Graphite/OLED quiet luxury | Apple-native restraint |
| Onboarding Priority | Goals first | Teach through action |
| First User Outcome | Understand what to do today | Core comprehension metric |
| Reviewer Framing | Personal planning and execution app | Avoid category confusion |
| Major Risk | Sounding generic or AI-coded | Protect aggressively |
| Forbidden Framing | habit tracker, chatbot, AI productivity | Never lead with these |
| Beta Priority | Trust and comprehension | More important than feature count |
| Core Retention Driver | Believable daily guidance | Recommendations must feel grounded |
| Accessibility Priority | Calm readable structure | Avoid overload |
| Launch Bar | Premium, understandable, trustworthy | No rushed v1 feel |

## Metadata validation checklist

Before submission verify:

- copy matches implementation
- screenshots match actual UI
- App Privacy disclosures align with behavior
- reviewer notes match functionality
- no unsupported AI/privacy claims exist
- keywords remain policy-safe
- onboarding terminology is canonical
