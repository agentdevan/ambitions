# Ambitions Onboarding Narrative

Status: Draft
Purpose: Launch onboarding copy, flow, and evaluation foundation

## Onboarding promise

Build a life system that adapts with you.

## Onboarding outcome

Within the first session, a user should understand that Ambitions helps them turn meaningful goals into grounded daily steps that fit real life.

The user should not feel like they are setting up a generic productivity app, habit tracker, calendar clone, or chatbot.

## Onboarding feel

The onboarding experience should feel:

- calm
- guided
- Apple-native
- premium
- action-oriented
- emotionally safe
- practical

It should teach through action immediately.

## First setup priority

Goals come first.

Ambitions should begin with what the user wants to accomplish, then shape the rest of setup around making those goals executable.

## Recommended onboarding sequence

1. Welcome
2. Goal setup
3. Goal-to-step explanation
4. Time reality setup
5. Start Here preview
6. Privacy/trust explanation
7. First recommended step

## Screen 1: Welcome

### Headline

Finally know how to accomplish your goals.

### Body

Ambitions helps turn what matters into grounded daily steps that fit real life.

### Primary action

### Headline

Start with what matters.

### Body

Choose one goal Ambitions can help you make real through daily progress.

Add goal

The first goal should be meaningful, concrete, and personally relevant. The flow should not require perfect phrasing.

### Body

Ambitions helps connect your goals to what you can actually do today.

### Primary action

Continue

## Screen 4: Add time reality

### Headline

Built around real life.

### Body

Your schedule, commitments, protected time, and available capacity help Ambitions recommend steps that fit.

### Primary action

Set availability

## Screen 5: Start Here preview

### Headline

Know where to begin.

### Headline

Private by design.

## Onboarding copy rules

Use:

- goal
- step
- Start Here
- real life
- grounded
- progress
- adapt
- private

Avoid:

- habits
- streaks
- productivity system
- optimize
- AI assistant
- task dump
- hustle
- performance pressure

## Skip and later behavior

Onboarding should allow users to defer non-critical setup, but must preserve enough context to make the first experience understandable.

Allowed deferrals:

- detailed schedule setup
- advanced profile settings
- notification preferences
- deeper privacy controls

Not recommended to defer:

- first goal
- basic goal-to-step explanation
- first Start Here preview

## Success criteria

A first-time user should be able to answer:

- What is Ambitions for?
- How does it help me accomplish goals?
- What should I do today?
- Why is this different from a task list?
- Can I trust it with personal life information?

## TestFlight onboarding questions

Ask beta users:

1. Did you understand what Ambitions helps you do?
2. Did your first goal feel easy to enter?
3. Did the first recommended step feel believable?
4. Did the experience feel different from a productivity app?
5. Did you trust the system enough to continue?
