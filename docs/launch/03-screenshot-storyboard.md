# Ambitions Screenshot Storyboard

Status: Draft
Purpose: App Store screenshot narrative system

## Screenshot philosophy

Ambitions screenshots should communicate:

- grounded execution
- goal continuity
- real-life adaptation
- calm intelligence
- premium native iPhone quality
- trust

Do not present the product as:

- a productivity dashboard
- a calendar clone
- a chatbot
- a task manager
- an AI wrapper

The screenshots should feel cohesive, restrained, believable, and native to iPhone.

# Visual rules

## Required

- native iPhone realism
- graphite/OLED visual system
- restrained typography
- premium spacing
- believable SwiftUI composition
- one-primary-object discipline
- minimal noise
- no marketing gradients

## Forbidden

- giant dashboard grids
- excessive charts
- generic cards everywhere
- floating chatbot UI
- neon AI aesthetics
- web-app styling
- habit streak visuals
- gamification

---

# Screenshot production checklist

Before final export:

- Dynamic Type checked
- Safe areas verified
- Tab hierarchy accurate
- Canonical naming verified
- No placeholder content
- Visual hierarchy reviewed
- Device framing consistent
- Reduce Motion fallbacks reviewed
- Accessibility labels audited
- Product language consistent
