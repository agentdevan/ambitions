# Ambitions Release Notes Template

Status: Draft
Purpose: Standardized release communication

## Release philosophy

Release notes should:

- communicate meaningful improvements
- reinforce trust
- stay grounded and honest
- avoid filler language
- avoid hype

## Tone

Preferred:

- calm
- direct
- premium
- human

Avoid:

- exaggerated excitement
- meaningless patch filler
- productivity hype
- fake urgency

## Release template

# Ambitions X.X

## Focus of this release

Short summary of the primary improvement theme.

## Improvements

- improvement one
- improvement two
- improvement three

## Refinements

- onboarding refinement
- accessibility refinement
- visual polish
- recommendation quality updates

## Stability

- bug fixes
- crash reductions
- consistency improvements

## Trust and privacy

Include only if meaningful.

## Avoid in release notes

- fake roadmap promises
- exaggerated AI claims
- vague filler
- productivity clichés
- feature quantity framing
