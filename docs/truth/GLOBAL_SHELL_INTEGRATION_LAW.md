# Global Shell Integration Law

Status: Active global product and implementation law.
Scope: all Ambitions shell and surface chrome.

The Ambitions shell is a product layer, not a border around the product. The Context Crown, search, Capture access, route controls, continuity dock, overlays, and surface actions must be functional, modern, and seamlessly integrated into the active surface.

Full-bleed means atmosphere bleeds, content remains safe, chrome integrates, and object hierarchy stays clear.
