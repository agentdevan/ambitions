# Design — Owner Taste Design Governance

The durable source is `docs/canon/design/OWNER_TASTE_DESIGN_DECISION_SYSTEM.md`
with its JSON peer. The VC input contract remains sole active visual authority
and carries the explicit concept/disposition matrix. Its machine peer points
to the source record and compiler validation rejects missing source links,
wrong device scope, missing evidence-governed categories, or undeclared
dispositions.

Frontend impact: affected — this changes decision routing for future material
iPhone-native work, but creates no product UI. Visual gate: not required for
this documentation/governance change. A future candidate uses the 12-dimension
0–2 gate before expensive proof; the score cannot approve a design or certify
behavior, accessibility, runtime, device, or release proof. Physical-iPhone
validation is required for physical feel and haptics remain evidence governed.
