# Scope — Owner Taste Design Governance

Install the calibration as a reference source, machine peer, reconciliation
matrix, compiler guardrail, and normal canon route. In scope: provenance,
human/machine parity, explicit dispositions, evidence-governed exclusions,
iPhone-only scope, a pre-proof taste gate, and physical-iPhone proof routing.

Out of scope: production surface redesign, broad frontend authorization, a
second visual authority, iPad/Watch work, Figma control, accessibility by
taste, haptics by taste, or process-only merge gates. Precedence is product
truth; safety/privacy/correctness/accessibility; current platform evidence;
canon semantics; reconciled visual contract; owner taste; local preference;
novelty.
