# AFRI-018 Deterministic Experience Compiler Proof

Issue: AMB-370 / AFRI-018

Status: source and focused-test proof pending final validation in this run.

## Scope

AFRI-018 installs a deterministic Experience Compiler in the existing
`AmbitionsOSExperienceModels` domain owner. The compiler maps runtime semantics
into product-critical visual state without accepting decorative randomness as an
authority input.

## Semantic Inputs

- capacity
- protected pressure
- closure residue
- SourceRecord freshness
- proof strength
- goal pull
- recovery need
- privacy mode

## Product-Critical Output

- `LivingVisualState`
- bounded visual intensity
- sorted semantic cause identifiers
- accessibility label
- stable golden snapshot key
- critical signature

## Proof Boundary

This proof covers deterministic model behavior and focused unit tests. It does
not prove rendered screenshot fidelity, device behavior, accessibility audit
completion, release readiness, ReplayTrace capture integration, Receipt storage,
or runtime integration into every visual surface.

## Rollback

If semantic causality regresses, disable compiler-driven visuals and return
surfaces to their previous explicit local visual-state mappings until the
compiler tests are Green again.
