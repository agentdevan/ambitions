## AFI Green / Yellow / Red Rules

Green:
- batch objective complete
- no Hard Red
- required proof exists for touched scope
- no false claim

Yellow:
- safe partial completion
- implementation or proof gap remains
- screenshots/accessibility/device validation pending
- compatibility code names remain but are clearly migrated and non-user-facing

Red:
- top-level IA conflict
- compatibility names reintroduced as active/user-facing language
- broad unsafe refactor required
- screenshot/QA proof absent but Green claimed
- automation/trust/receipt requirement violated
- visual-only/motion-only/color-only meaning
- generic task/calendar/dashboard/chat/habit drift
