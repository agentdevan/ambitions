## Canon Status

Ambitions is 10/10 pre-repo/pre-Codex at the canon level only.

That means:

- product direction is locked
- architecture rules are locked
- top-level IA is locked
- Signature Objects are locked
- Continuity Layer behavior is locked
- implementation gates are explicit
- drift is blocked

It does not mean:

- the app is implemented
- the app is visually validated
- exact token values are final
- accessibility is proven in code
- performance is proven on device
- tests or previews pass
- release readiness exists

## Token Caveat

Semantic token names are locked. Exact numeric values remain candidate until visual QA validates them against real app screenshots, especially Today, Capture, and You.
