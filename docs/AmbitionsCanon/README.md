Existing repo material may reference Ambitions 3.0, Ambitions 4.0, PXOS, Signature Interface, ACUI, handoff packets, audits, and Codex trains. Those files are supporting or historical context only unless explicitly compatible with active truth and current evidence.

Do not use this folder to revive:

- `Plan` as a top-level destination
- `Profile` as a top-level destination
- `Captures` as a top-level destination
- `DayTimelineRail` as active product language
- `Hero Step Panel` as user-facing language
- `Start Focus` or `Begin Focus`
- `Your best next move` or `next best move`
- chatbot or assistant as primary UI
- external/cloud LLM as core product architecture

## Non-proof boundary

This package does not implement app behavior. It does not prove visual QA, accessibility, performance, tests, release readiness, App Store readiness, TestFlight readiness, or production readiness.

Docs-only maturity means direction may be useful. It does not mean the app is implemented or validated.
