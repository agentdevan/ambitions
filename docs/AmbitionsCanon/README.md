## Active IA Update

The flagship IA is now:

```text
Today
Goals
Capture
Time
You
```

`Plan` is no longer a top-level destination in active flagship canon. `Plan` remains valid only as an action or contextual noun, such as Adjust plan, Shape week, or Review pressure. Time is the capacity surface and is represented by Shape Time / LifeShape Field.

The product hierarchy is:

```text
Goals → Time → Today
Capture feeds all three.
You governs trust, privacy, defaults, and automation.
```

- product direction is locked

- canonical vocabulary is locked

- screen composition constitution is locked

- Continuity Layer behavior is locked

It does not mean:

- the app is implemented

- exact token values are final
- accessibility is proven in code
- performance is proven on device
- tests or previews pass
- release readiness exists

Semantic token names are locked. Exact numeric values remain candidate until visual QA validates them against real app screenshots, especially Today, Capture, Time, and You.
