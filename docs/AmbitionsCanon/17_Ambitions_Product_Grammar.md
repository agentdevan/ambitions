# 17 — Ambitions Product Grammar

Status: active canon, docs-only.

Purpose:

- define how Ambitions turns raw intention into grounded action
- clarify hierarchy across Goals, Time, Today, Capture, and You
- prevent Goals/Time/Today confusion
- make the product lifecycle human, memorable, and implementation-ready

## Flagship Product Grammar

```text
Capture → Clarify → Shape → Start → Close → Remember
```

Ambitions does not simply manage tasks. Ambitions carries intention through a lifecycle:

1. Capture what appears.
2. Clarify where it belongs.
3. Shape time around what matters.
4. Start the step that fits now.
5. Close the loop without shame.
6. Remember what changed with trust and control.

## Product Spine

```text
Direction → Time → Today → Closure → Memory
```

Expanded:

```text
Goals define direction.
Time shapes capacity.
Today starts what fits now.
Closure resolves reality without shame.
Memory preserves proof, trust, and learning.
```

Capture feeds the system at any point. You governs trust, privacy, defaults, and automation.

## Conceptual Hierarchy

```text
Goals → Time → Today
Capture feeds all three.
You governs the system.
```

Goals are higher than Time. Time exists to make goals realistic. Today executes the slice of Goals + Time that fits now.

Daily navigation may start with Today because Today is the daily home. This does not mean Today is conceptually higher than Goals.

## Surface Ownership

| Surface | Owns | Does not own |
| --- | --- | --- |
| Goals | direction, life areas, goal threads | time capacity, daily task list, system score |
| Time | capacity, pressure, protected time, shaping | life meaning, calendar identity, hidden automation |
| Today | current execution, Start Here, closure | full planning, goal portfolio, calendar management |
| Capture | raw input, safe holding, route reveal | notes archive, inbox management, forced organization |
| You | trust, privacy, defaults, automation, receipts/history | social identity, admin console, primary planning |

## Ambitions Promise Ladder

```text
Capture anything.
Give it a place.
Shape your time around what matters.
Start where reality allows.
Close the loop without shame.
Trust what changed.
```

This ladder must be visible in UI behavior, not just marketing copy.

## Cross-Surface Handoffs

| From | To | Handoff |
| --- | --- | --- |
| Capture | Goals | Grow into Goal / place into life area |
| Capture | Time | captured commitment influences capacity after user confirms |
| Capture | Today | quick step can become Start Here candidate after placement |
| Goals | Time | goal thread asks for capacity |
| Goals | Today | thread feeds Recommended step |
| Time | Today | capacity informs what fits now |
| Today | Time | pressure/reflow sends user to Shape Time |
| Today | Goals | completed/closed step updates goal thread proof |
| Any | You | Trust Seam routes to Trust & Automation / Privacy / Receipts & History |

## Surface-Specific Product Grammar

### Today

Grammar:

```text
Now → Recommended step → Start / Adjust / Close → Receipt
```

Today must narrow choices.

### Goals

Grammar:

```text
Life area → Goal thread → Next possible step → Thread to Today
```

Goals must orient without ranking.

### Capture

Grammar:

```text
Input → Safe hold → Route reveal → Place / Grow / Leave for later
```

Capture must avoid premature structure.

### Time

Grammar:

```text
Capacity truth → Pressure/protected/open time → Shape → Preview → Receipt
```

Time must show reality without becoming a calendar.

### You

Grammar:

```text
Defaults → Trust level → Permissions → Receipts/history → Control
```

You must make system behavior inspectable.

## Product Grammar Hard Reds

Stop and repair if:

1. Goals becomes lower than Time conceptually.
2. Time becomes calendar/schedule identity.
3. Today owns full planning instead of current execution.
4. Capture becomes notes/inbox/archive instead of intake.
5. You becomes social/account/admin instead of trust/control.
6. Plan returns as a top-level destination.
7. Goal thread cannot feed Today.
8. Time cannot inform Today.
9. Capture cannot remain safely unplaced.
10. Closure becomes overdue/failure/shame.
11. Memory/receipts become surveillance or activity feed.
12. Automation acts without trust/source/receipt.
