# 16 — Surface Identity And Signature Moments

Status: active canon, docs-only.

Purpose:

- make every top-level surface emotionally and visually distinct
- define the memorable moments that make Ambitions tell-worthy
- align surface title, primary object, user question, emotional role, and anti-drift rules

## Surface Identity Table

| Tab | Screen title | User question | Primary object | Emotional role | Signature moment |
| --- | --- | --- | --- | --- | --- |

## Today — Start Here

Functional job:

- choose the next action that fits now
- show Now / Next / Later through Reality Meridian
- close loops without shame
- provide Why this? when recommendations appear

Emotional job:

- reduce overwhelm
- make the day feel navigable
- validate partial progress

Signature moment:

```text
Start Here emerges from the Reality Meridian.
```

Required copy:

- Start Here
- Recommended step
- Fits now
- Why this?
- Start now
- Open step
- Still counts
- Reality changed
- Make today lighter
- Needs closure

Hard Red:

- task list
- detached card hero
- overdue/failed/shame copy
- focus mode as primary identity
- dashboard status pile

## Cross-Surface Signature Flow

The ideal user journey:

```text
Capture anything.
Give it a place.
Shape your time around what matters.
Start where reality allows.
Close the loop without shame.
Trust what changed.
```

Surface mapping:

| Promise | Surface |
| --- | --- |
| Capture anything | Capture |
| Give it a place | Capture / Goals |
| Shape your time around what matters | Time |
| Start where reality allows | Today |
| Close the loop without shame | Today / Receipt Surface |
| Trust what changed | Trust Seam / You / Receipts & History |

## Friend-Tell Standard

A user should be able to describe at least one signature moment naturally:

- “It shows me where to start without making a task list.”
- “It shows what my week can actually hold.”
- “I can save a thought without organizing it right away.”
- “It explains why it suggested something.”
- “It lets partial progress still count.”

If no surface creates a tell-worthy moment, the UI is functional but not flagship.

## Surface Identity Hard Reds

Stop and repair if:

1. Today does not clearly produce relief/clarity.
2. Goals does not clearly produce orientation.
3. Capture does not clearly produce safety.
4. Time does not clearly produce realism.
5. You does not clearly produce trust/control.
6. screen titles do not match surface roles.
7. a surface’s primary object is not visually dominant.
8. a surface can be mistaken for a generic category app.
9. signature moments are documented but not implemented/proven.
