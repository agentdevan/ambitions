# Crowned Edge Dock viability gate

Status: `PROVISIONAL_HIGH_RISK_HYPOTHESIS`

The dock is neither rejected nor production-approved.

## Current evidence establishes

- a recognizable Peek;
- Today, Goals, Time, You ordering;
- Search and Capture separation;
- an accessibility passage concept;
- functional shell ownership; and
- Simulator-safe geometry in reviewed fixtures.

## Unproven

- left- and right-hand reach and one-handed use
- Back-edge and scroll-indicator coexistence during continuous use
- accidental activation, discoverability, expansion speed, and dismissal
- VoiceOver, Voice Control, Switch Control, and Full Keyboard Access
- Reduce Motion and Reduce Transparency on device
- haptics, Dynamic Island and safe-area pressure
- fatigue after repeated use

## Pass criteria

The dock may approach shell freeze only when direct-device testing proves:

1. root switching is no slower than a viable native alternative;
2. Back-edge navigation remains reliable;
3. accidental activation is rare and recoverable;
4. Peek is discoverable without tutorial copy;
5. one-handed reach succeeds for both hands;
6. Search and Capture remain clear;
7. assistive technologies expose equivalent navigation;
8. scrolling never makes Peek feel like a scrollbar;
9. dismissal is predictable; and
10. prolonged use causes no irritation or obstruction.

## Failure criteria

The shell must branch or fall back if edge gestures become unreliable, Peek is
routinely mistaken for scrolling, reach is poor, persistent obstruction is
reported, assistive navigation is inferior, expansion is only a slower generic
menu, or the interaction has no measurable usability advantage.

## Current decision

- The dock does not block the next root's content calibration.
- The dock blocks final cross-root shell freeze.
- No alternative dock is designed by this gate.
- Simulator evidence is not device validation.

## Direct-device protocol

On an authorized physical iPhone, run separate one-handed left-hand and
right-hand trials while seated and walking. Exercise root switching, Back
gestures, long scrolling, Search, Capture, sheet presentation, keyboard use,
VoiceOver, Reduce Motion, and Reduce Transparency. Repeat ordinary use for at
least 15 minutes.
