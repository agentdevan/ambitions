# Provisional cross-root grammar

This is a transfer contract for calibration, not a component API or final
design system.

## Object identity core

A persistent canonical object presents, in semantic order:

1. stable object identity;
2. canonical owner or lineage;
3. current accepted truth;
4. applicable state;
5. material consequence;
6. available native action;
7. truthful return or owner transfer.

## State layers

Identity, accepted truth, proposed truth, external truth, temporal relationship,
consequence, action, evidence/history, and recovery remain distinguishable.
Evidence and metadata never become object identity.

## Geometry law

- Identity appears before decoration.
- The open plane is default; local relief appears only when meaning changes.
- No generic perimeter surrounds every group and no card stack propagates.
- Layouts use no screen-specific fixed coordinates.
- Natural scrolling completes depth.
- Accessibility may recompose geometry without removing meaning.

## Node law

Nodes are provisional semantic markers, not decorative bullets:

- **Current:** the accepted truth in effect now.
- **Proposed:** a not-yet-accepted consequence under review.
- **Fixed:** a relationship whose placement is accepted and not silently moved.
- **Protected:** a boundary the experience must preserve.
- **Open:** available capacity without manufactured urgency.
- **Settled:** newly accepted truth after a successful commitment.
- **Interrupted:** accepted truth retained across a disrupted operation.
- **Saving:** an operation in flight while prior accepted truth remains valid.

Exact shape, dimensions, color, animation, and reusable SwiftUI APIs remain
unresolved.

## Action law

Continuation, selection, consequential commitment, cancellation or deferral,
navigation or disclosure, and recovery remain distinct roles. One accent-filled
treatment must not represent every action.

## Cross-root adaptation law

Another root inherits this grammar, not Today's composition. Goals, Time, and
You derive spatial structure from their own canonical objects and ownership.
