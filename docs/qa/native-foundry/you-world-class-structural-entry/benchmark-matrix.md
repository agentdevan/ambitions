## Cross-corpus findings

- Native comprehension comes from consistent row anatomy, disclosure, and return—not decorative settings cards.
- Local ownership is strongest when a product names the storage/source boundary in plain language.
- Permission trust improves when the purpose and consequence appear before technical detail.
- History is understandable when current state remains visibly authoritative.
- Appearance remains calm when choices are finite and a specimen demonstrates consequence.
- Account products naturally pull hierarchy toward identity heroes, vaults, plans, and devices; those patterns are invalid for flagship You.
- Privacy dashboards, recommendations, scores, and expansive option inventories repeatedly turn control into monitoring or optimization.
