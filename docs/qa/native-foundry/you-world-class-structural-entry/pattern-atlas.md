# Pattern Atlas

## Stable domain passage

A scrollable root with consistent domain rows preserves native comprehension. Identity comes from meaningful order, summaries, spacing, and continuity into depth—not bespoke containers around every row.

Use in You: preserve all nine domains in canonical order and let the first viewport reach Notifications & Attention naturally.

## Ownership statement before controls

Local-first products build trust by stating where data lives and who can access it before presenting technical controls.

Use in You: Identity & Local Data names “On this iPhone” and “No Ambitions account” without an account hero.

## One state summary per domain

The strongest settings roots answer “what is true now?” without duplicating the full drilldown.

Use in You: one concise summary, disclosure, and material state only where consequence warrants it.

## Purpose-bound permission

Apple Health and 1Password connect each sensitive permission to its exact use. System Settings remains the authority for system-owned decisions.

Use in You: Calendar, Reminders, and Notifications state the purpose and route outward only when iOS owns the change.

## Current truth over history

Proton Pass and Standard Notes show that historical or deleted states become legible when current truth remains dominant and older truth is explicitly dated or segregated.

Use in You: personalization history never looks current; superseded and removed states do not silently reappear as active knowledge.

## Finite appearance with live consequence

Signal and Things use a small choice set with direct preview. This makes appearance operational rather than collectible.

Use in You: System, Light, Dark, approved accents, and one controlled specimen.

## Consequence-first sensitive depth

Clear products state the practical effect of a privacy or destructive action before implementation details.

Use in You: “Calendar lets Time observe external events” precedes adapter or authorization metadata.

## Progressive disclosure for personal truth

Sensitive, uncertain, and historical information is easier to trust when the root exposes category and state while depth exposes source, date, and consequence.

Use in You: Personalization is a control passage, not a visible dossier.

## Structural accessibility transformation

Dense horizontal controls do not merely enlarge. They become ordered vertical choices, wrap summaries, and preserve semantic order.

Use in You: `VC11-YOU-D06` is a complete equivalent, not an enlarged root screenshot.

## Exact return

Native control surfaces feel dependable when Back restores scroll position, selected domain, state, and focus.

Use in You: every bounded depth returns to the same root context without parallel navigation.
