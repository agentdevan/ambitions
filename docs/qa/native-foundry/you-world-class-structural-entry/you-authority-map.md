# You Authority Map

## Installed direction

- Parent: `AVF-YOU-D07-R02 — Local Personal Control Index`
- Selected closure: `VC11-YOU-D02 — Personal Control Passage`
- Native substrate: `VC11-YOU-D01 — Native Grouped Control List`
- Accessibility transformation: `VC11-YOU-D06 — Explicit Adaptive Control Passage`

The installed direction is a settings-first personal system. It is not an account home, profile feed, dashboard, or AI memory dossier.

## Root law

The root presents these domains in this exact order:

1. Identity & Local Data
2. Personalization
3. Privacy & Data
4. Appearance
5. Notifications & Attention
6. Connections & Permissions
7. Accessibility & Interaction
8. App Behavior
9. About Ambitions

The first viewport normally reaches into Notifications & Attention. All nine domains must not be compressed into one viewport.

## Local and account truth

Flagship scope has no Ambitions account. Sign in, account recovery, cloud sync, device management, subscriptions, sign out, account deletion, account heroes, and avatar-led profile UI are absent.

## Domain-row law

A domain row may carry an SF Symbol, domain identity, one concise current-state summary, material state where needed, and native disclosure. It may not carry a score, grade, completion metric, recommendation, dashboard visualization, or unsupported disabled command.

## Personalization truth

Personalization distinguishes:

- person-entered;
- confirmed;
- suggested;
- inferred;
- uncertain;
- historical;
- superseded; and
- removed.

It does not summarize the person, claim personality understanding, or create a generated dossier.

## Appearance law

Appearance is a focused You depth. The bounded target includes System, Light, Dark, approved action accents, a restrained violet-indigo default, and one controlled live specimen. It excludes a theme gallery, swatch wall, marketplace, root-specific theme system, typography editor, density editor, material editor, and motion override system.

## Navigation law

Normal depth uses `NavigationStack`, native Back, interactive Back, smallest-sufficient native presentation, and exact restoration of root position, selected domain, object, and focus. Parallel settings navigation and top-level You sub-tabs are absent.

## Privacy and permission law

Privacy language must state what is local, what source is consulted, what purpose a permission serves, and what is currently supported. System-owned permission decisions remain system-owned. Unsupported permissions and controls are absent, not disabled.

## Accessibility law

At accessibility sizes, domain rows become multiline vertical units. Summaries wrap; decorative symbols disappear before meaning; controls precede specimens; appearance choices become labelled vertical choices; sensitive values may be hidden without leaving an empty focus target; and color always has a non-color equivalent.

## Reconciled precedence

Broader or older visual-system inventories for account, sync, export, reset, and data management are target context only. The current You specification, migration blueprint, Wave 2 closure, Wave 3 accessibility closure, and live capability audit control this packet.
