## Structural thesis

Native navigation defines where the person is. One persistent Goal object defines what the person is building.

Every depth uses a different resolution of one canonical pursuit continuum:

1. compact Goal identity anchor;
2. accepted-truth seam;
3. recorded support physically attached to that seam;
4. one current movement extending from the accepted boundary;
5. open possibility with decreasing definition;
6. relationship consequence modifying or protecting the same field.

The continuum is qualitative. It cannot imply time, percentage, distance, completion, rank, or a prescribed project sequence.
