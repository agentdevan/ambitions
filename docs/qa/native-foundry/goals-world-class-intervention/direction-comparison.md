## D01 — Native Pursuit Ledger

- **What it proves:** Whether exceptionally disciplined native hierarchy, a stable Goal-specific identity margin, semantic chapters, and exact restoration are enough to make Goals feel coherent without custom spatial behavior.
- **What it sacrifices:** Visual distinctiveness, embodied continuity, and a strong ownable interaction signature.
- **Research support:** Things, Bear, iA Writer, Apple Health, Reminders, Primary, and Apple’s hierarchy/accessibility guidance.
- **What would invalidate it:** If the identity margin reads as a colored rule, if a contact sheet still reads as a formatted document/list, if the Linked Goal Lens remains an inset disclosure, or if Goal identity depends on repeated headings.

## D02 — Open Horizon Passage

- **What it proves:** Whether qualitative distance and a present horizon can replace the stepper while making uncertainty intuitive.
- **What it sacrifices:** Straightforward density, easiest Dynamic Type transformation, and the safety of familiar native hierarchy.
- **Research support:** Tide Guide, Apple Weather, Gentler Streak, Flighty, and Calendar.
- **What would invalidate it:** If people interpret position as percentage/time, if the horizon becomes a static infographic, or if the accessible equivalent loses information.

## D03 — Consequence Weave

- **What it proves:** Whether a qualitative Path can remain independently legible while material relationships alter only the exact region they affect.
- **What it sacrifices:** Simple Path clarity and scalability when several relationships are simultaneously material.
- **Research support:** Photos collections, Craft/Bear contextual links, Journal grouping, and Flighty cause/impact.
- **What would invalidate it:** If crossings read as a graph/Sankey diagram, if position or width implies quantity/dependency/flow, if object ownership becomes ambiguous, or if dense states require a dashboard legend.

## D04 — Pursuit Aperture

- **What it proves:** Whether one persistent visual object can generate root, Lens, focused Goal, Path, Proof, relationship, and recovery without changing anatomy.
- **What it sacrifices:** Implementation simplicity and immediate familiarity.
- **Research support:** iA Writer focus, Journal moment capture, Photos identity, Moonlitt object coherence, and Apple’s material/layer guidance.
- **What would invalidate it:** If the aperture looks like a fancy card, carousel, sci-fi panel, or if large type destroys the layer relationship.

## D05 — Evolving Passage

- **What it proves:** Whether qualitative eras can make progression emotionally legible without project stages or a chronological activity log.
- **What it sacrifices:** First-viewport compactness and protection against journal/timeline resemblance.
- **Research support:** Day One, Photos Memories, Gentler Streak, Flighty, and Calendar density transformation.
- **What would invalidate it:** If eras are merely renamed phases, if the UI invents narrative labels, or if the Goal becomes a retrospective journal rather than a present pursuit.

## D06 — Living Fold

- **What it proves:** Whether opening the same pursuit from its Life Area can become an ownable, native-feeling Ambitions interaction signature.
- **What it sacrifices:** The absolute simplicity of a standard list and certainty that its directional metaphor will feel necessary rather than authored.
- **Research support:** Freeform scenes, Craft attached depth, Photos grouping, Play direct manipulation, and Apple adaptive hierarchy.
- **What would invalidate it:** If it reads as an accordion/card peel, requires tutorial copy, breaks accessibility or exact restoration, or makes content transition more important than system navigation and object truth.

## Neutral selection considerations

- Select D01 if the next question is whether native-default restraint can meet the flagship bar with minimal interaction risk.
- Select D02 if the priority is replacing the Path with a decisive qualitative continuity model.
- Select D03 if the consequential relationship is the hardest and most differentiating Goals problem.
- Select D04 if persistent canonical-object identity across every depth is the primary design challenge.
- Select D05 if long-horizon evolution, Proof, recovery, and closure need to read as one lived passage.
- Select D06 if the owner wants to test a restrained but more ownable Ambitions interaction grammar.

These are decision criteria, not recommendations. Rendering more than one direction is appropriate when the owner wants to compare competing structural hypotheses.
