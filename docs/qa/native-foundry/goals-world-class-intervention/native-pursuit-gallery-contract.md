## Core principle

Navigation remains fully native through NavigationStack, NavigationLink semantics, system Back and edge gestures, native navigation bars and toolbars, natural scrolling, native focus restoration, Dynamic Type, VoiceOver, and standard disclosure behavior.

Visible composition is authored, rich, premium, modern, calm, and distinctly Ambitions. Native behavior does not imply default List appearance.

## Hierarchy

```text
Goals root
→ Life Area
→ Goal
→ Path / Relationship / Proof / History
```

This hierarchy is binding. The three rendering-gate screens prove three distinct native depths:

1. Goals root is the Life Area index.
2. Home is a separate Life Area drilldown containing Home-owned Goal identities.
3. `Welcome our baby home` is a separate focused Goal detail.

The Linked Goal Lens belongs to selected Goal context. It may not expand a Goal into the Goals root or collapse root, Life Area, and Goal ownership into one editorial surface. Framework NavigationStack behavior, native Back and interactive Back, root-local path preservation, and truthful focus restoration remain mandatory for a later native prototype.
