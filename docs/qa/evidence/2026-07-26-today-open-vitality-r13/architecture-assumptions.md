# Architecture-Sensitive Assumptions

- Views consume immutable fixture snapshots; fixtures do not become runtime or
  product authority.
- The Step is the bounded calibration vehicle, not a universal Start Here law.
- Today initiates the journey, but durable mutation remains owned outside the
  Foundry view. Synthetic host timing is evaluation behavior only.
- Native full-screen review and native recovery sheet remain the presentation
  owners. The dock is root-owned and omitted at depth.
- Focus restoration uses stable semantic identity and actual focused elements,
  not visual offsets or proxy containers.
- Returned-Today de-duplication is this fixture's projection behavior, not a
  global runtime law.
- The revealed Start Here is read-only because the fixture has no executable
  focused journey for it.
- Time Transfer is an unavailable fixture posture until a source-backed Time
  route exists; it is not a fake control.
- Review Details and History destinations do not define final production
  Receipt architecture.
- Undo appears only when an exact current Receipt, current revision, dependency
  state, and fixture command satisfy the source-backed inverse contract.
- RTL content is evaluation-only accessibility stress, not production
  localization authority. Primary owner UI remains English.
- Simulator timing, focus, motion, and haptics do not imply production runtime
  guarantees or physical-device proof.
- Package preview hot reload remains the inner loop; no clean build or injection
  dependency is required for ordinary visual iteration.
