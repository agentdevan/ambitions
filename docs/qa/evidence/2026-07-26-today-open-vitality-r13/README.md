This package is still-image evaluation evidence for the bounded, fixture-driven
Today calibration slice. It contains 37 native Simulator frames, four contact
sheets, immutable hashes for the eight owner references, focused validation,
and explicit proof ceilings. It is not a production screenshot baseline.

dedicated `AmbitionsNativeFoundryHost`. It does not connect the runtime, alter
the production app entry, import legacy frontend code, or authorize broad
reconstruction.
