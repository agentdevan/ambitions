# Implementation evidence

## Architecture

R13 preserves the immutable fixture-snapshot boundary and enum-driven Foundry
journey state. The host owns evaluation-only timing and presentation. Views do
not own persistence, production mutation, scheduling, or runtime policy.

The R13 composition is divided into focused journey-local views for root,
timeline, focused Step, review/saving, settlement/return, recovery, Full Day,
supporting depth, and resilience. This is not a final component library or
global token system.

## Visual grammar

- Continuous mineral/graphite matte plane with localized open relief.
- A single continuity rail connects current, proposed, settled, protected,
  fixed, open, and interrupted states through shape as well as color.
- System typography uses five local roles: object identity, state truth,
  relationship, metadata, and action.
- Violet-indigo is reserved for selection, proposal, and primary interaction.
  Settled and interruption use restrained mineral/moss and amber seams.
- Functional material is restricted to the edge dock and transient chrome;
  Reduce Transparency has an opaque equivalent.

## Journey

The implemented path preserves stable Step identity from Today through focused
depth, Still counts review, saving, settlement, explicit return, settled-object
continuity, newly eligible Start Here, Full Day, and object-scoped recovery.
Accepted truth remains distinct from proposed truth until settlement.

Supporting evaluation depths cover the parent pursuit, consequence details,
local History, History filters, a truthful Time transfer posture, offline local
truth, stale external context, exact inverse availability, failed settlement,
and cancellation without mutation.

## Accessibility and adaptivity

The package includes Accessibility Dynamic Type, Increased Contrast,
Differentiate Without Color, Reduce Transparency, Reduce Motion, long English,
quiet/dense/very-dense Today, compact iPhone 17e, and Pro Max frames. Controls
retain semantic labels and 44-point envelopes. The ordinary dock transforms to
the scrollable Adaptive Navigation Passage under accessibility pressure.

R13 is intentionally English-only by owner direction. Physical VoiceOver,
Switch Control, Full Keyboard Access, reach, haptics, low-brightness, edge
gesture, and direct-device verification remain open.

## Motion and haptics

Source uses low-amplitude native transitions and state-preserving focus. Reduce
Motion replaces spatial continuity with static seams and fades. Haptic intent is
specified and source-wired where supported, but physical tactility is not proven
without a device.

## Performance

The Foundry package keeps stable IDs, bounded observation, lazy scrolling for
the complete day, localized material, and scoped animation invalidation. No
ETTrace or Memgraph escalation was warranted by observed Simulator behavior.
