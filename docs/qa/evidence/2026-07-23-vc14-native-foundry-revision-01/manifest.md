## Architecture-sensitive assumptions

- Dynamic Type is the only input used to choose ordinary Peek versus the
  Adaptive Navigation Passage; no runtime capability or navigation destination
  is invented.
- Empty fixture-host callbacks continue to prove control rendering only.
- The Material Seam uses Liquid Glass only as functional dock chrome on iOS 26
  and retains the existing authored opaque fallback for Reduce Transparency and
  earlier OS versions.
- Ordinary trailing reserve is deliberately larger than the 44-point hit
  envelope so timeline and hero text cannot enter the dock-owned region.

## Validation

Exact command outcomes are recorded in `validation.md`. Visual inspection of
all four revised native frames confirms that resting text is unobscured. The
ordinary dock has dedicated trailing space; the accessibility passage is in
normal flow and has no overlay dock. In the continuation frame, upstream text
exits through the normal top scroll boundary while every remaining timeline
entry is reachable and unobscured.

Warm package-preview reloads were 14 seconds and 11 seconds after the initial
host warm-up. Both are **excellent** under the VC-14 latency rubric. The
existing package-backed preview workflow remains the provisional default inner
loop; no hot-reload workflow or module boundary changed.
