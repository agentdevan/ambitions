# B02 visual grammar

Status: `PROVISIONAL FOUNDRY GRAMMAR`

The Open Continuity Field is a continuous matte semantic plane. Canonical
objects receive local relief only when state, consequence, comparison, or
interaction requires it. It is journey-local calibration—not a final component
library, token system, or production design-system authority.

## Continuity Spine

The Continuity Spine carries stable identity across the Today journey without
acting as progress, completion, or score. Its nodes have structural as well as
color distinctions:

| Meaning | Structural expression |
| --- | --- |
| Current | Open circle |
| Proposed | Paired offset circles |
| Saving | Active connector |
| Settled | Resolved inset circle |
| Interrupted | Retained broken seam |
| Protected | Shielded square with boundary bracket |
| Fixed | Anchored diamond |
| External | Open square |
| Open lane | Parallel open-lane marks |

The same grammar appears in Start Here, the timeline, focused depth, review,
saving, settlement, return, and recovery. Differentiate Without Color keeps
the shapes and seams explicit; meaning never depends on hue alone.

## Surface classes

- Open plane: headings, navigation depth, relationships, and supporting
  timeline content remain on the continuous canvas.
- Articulated object relief: Start Here, truth comparison, settlement, and
  interruption use asymmetric geometry, tonal lift, spacing, and seams.
- Transient chrome: native material is confined to the functional dock and
  presentation chrome. Reduce Transparency substitutes an authored opaque
  equivalent.

## Shape and density

- Asymmetric `UnevenRoundedRectangle` geometry signifies primary grouping; it
  is not repeated as a generic card treatment.
- Rows remain open or partially articulated along the temporal rail.
- Separators and shadows are restrained and subordinate to spacing and type.
- The root presents one Start Here plus at most four overview anchors; Full Day
  owns the complete read-only chronology.
- Accessibility sizes recompose vertically rather than shrinking meaning.

## Deliberate exclusions

No bottom tabs, dashboard grid, progress meter, glow, glass content cards,
rainbow category system, decorative success ceremony, AI-assistant treatment,
or fixed screenshot-coordinate layout was introduced.

## Proof ceiling

This record describes the package-backed Foundry implementation. It does not
establish final visual tokens or authorize reuse outside this bounded journey.
