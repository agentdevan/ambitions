# Architecture-sensitive assumptions

- Foundry views consume immutable snapshots; fixtures do not become authority
  owners or a production runtime.
- The stable Step is the calibration vehicle, not universal Start Here law.
- Today may initiate Still Counts, but durable mutation remains owned outside
  the view. B02 contains no production mutation logic.
- Full Day is a read-only Today projection of existing fixture chronology and
  does not move temporal editing out of Time.
- Synthetic saving latency exists only to make the transitional posture
  inspectable. It implies no production persistence or network guarantee.
- History disclosure is not final Receipt architecture.
- Returned-Today de-duplication is fixture projection behavior, not a universal
  runtime rule.
- No generic Undo appears because the exact inverse contract is not proven for
  this fixture.
- Haptic code or contract in the fixture host cannot close physical-device
  tactility proof.
- Genuine Arabic evaluation copy does not authorize production localization.
- Simulator focus metadata does not close physical VoiceOver, Switch Control,
  Voice Control, Full Keyboard Access, reach, edge gesture, or low-brightness
  obligations.
