# B02 provisional iconography system

Status: `PROPOSED`

B02 uses SF Symbols for familiar platform actions and compact relationship
cues. No custom font, icon package, decorative sparkle, or generic AI symbol
was added.

## Rules

- One leading symbol at most in a compact relationship row.
- Symbols remain subordinate to object identity and text.
- Weight follows the surrounding hierarchy and scales with Dynamic Type.
- Directional disclosure and Back behavior remain native. RTL behavior is not
  part of the final English-only proof package and remains open.
- Symbols that repeat visible text are accessibility-hidden; controls retain
  explicit labels and input labels.
- Continuity states use drawn node geometry because the shapes are
  Ambitions-specific semantics, not replacements for ordinary Apple controls.

## Shell mapping

Today, Goals, Time, You, Search, and Capture retain stable command identities
and SF Symbol presentation. Selected-root meaning combines label, glyph,
geometry, and material rather than color alone. Search and Capture remain in a
visually separate global-actions group.

## Proof ceiling

This mapping is journey-local calibration. It does not establish a final
product icon library or production symbol authority.
