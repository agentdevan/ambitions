# Reviewer findings

## Phase 0

The first specification and quality reviews each returned six blockers. The
issues were planning precision, Phase ownership, unresolved geometry, explicit
stress-state/copy contracts, Full Day Back semantics, accessibility proof
classification, immutable reference durability, and complete media/benchmark
inputs. All were repaired before implementation. Re-review status is pending.

The first re-review found incomplete localized navigation/Time-owner fields,
unsafe post-return Full Day Step depth, no stable Now anchor, and shallow media
metadata validation. Repairs added the complete copy map, origin-bearing Full
Day routes with post-return read-only behavior, stable Now/focus identities, and
exact per-artifact validation commands. A second fresh re-review is required.

The quality final review additionally required an exhaustive inherited product/
accessibility-copy inventory and exact render-source binding. Those contracts
now forbid literal product/AX strings in journey views, scan the complete Arabic
label tree, enforce unique artifact paths and the approved fixture family, and
prove that evidence-only commits do not change Swift source after capture.

A later quality gate found masked-failure risk in metadata shell loops. They now
use strict shell mode and explicit failure exits for every artifact property. A
later specification gate found a stale post-settlement Now identity. The
contract now resolves Now from Full Day origin and requires the returned Start
Here to own Now while retaining the nursery Step as settled/read-only context.

The next gate caught the superseded fixed-Now wording in the evidence fixture
contract and an ambiguous phase/task commit split. The fixture record now uses
the origin-specific resolver. Task 01 explicitly includes the anatomy refactor;
Phase 2 explicitly integrates the two separate shell and root commits.

The final boundary gate found unresolved shorthand for motion, adaptivity, and
capture ownership. Tasks 09 and 10 now enumerate exact paths, Task 12 is
evidence-only, and Phase 8 explicitly integrates—rather than replaces—the
three ordered task commits.

The next gate found Task 11 could edit unspecified source and metadata paths
could escape the evidence root. Task 11 now owns three exact test files and
routes source defects back to implementation. The final validator uses a full
ID/path allowlist and rejects absolute or escaping paths.

Final Phase 0 specification review: `PASS`.

Final Phase 0 quality review: `PASS`. Tasks 01–12 have exact ordered ownership;
Task 11 is test-only; Task 12 is evidence-only; and the 26/5/4 media inventories
are bound to exact contained paths, hashes, measurements, fixture identity, and
one immutable render-source SHA.

Later phase findings and their dispositions will be appended without rewriting
this history.
