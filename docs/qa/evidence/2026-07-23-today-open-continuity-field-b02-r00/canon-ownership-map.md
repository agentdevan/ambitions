## Resolution of the Full Day seam

Canon requires a `See Full Day` affordance while keeping Today object-led and
Time-owned chronology changes outside Today. B01 lacks the route. B02 therefore
adds one fixture-driven, read-oriented destination backed only by the existing
timeline snapshot. It has no edit commands and no fabricated handoff to Time.
