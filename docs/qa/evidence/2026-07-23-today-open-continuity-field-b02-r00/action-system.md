# B02 provisional action system

Status: `PROPOSED`

All actions use native `Button`, disclosure, navigation, or presentation
behavior. The Foundry does not imitate ordinary Apple controls.

## Roles

| Role | Examples | Treatment |
| --- | --- | --- |
| Primary continuation | Continue nursery setup | One centered, semibold action; minimum 44-point height; restrained violet-indigo relief |
| Primary commitment | Record progress | Strongest review action in the native safe-area region; disabled during saving |
| Secondary cancellation | Not now; Leave this for later | Equal interaction height without competing filled emphasis |
| Navigation | View Full Day; View history; Return to Today | Disclosure or secondary/navigation treatment matching the destination |
| Consequential outcome | Still counts | Only displayed executable outcome in this fixture |

The primary style uses an asymmetric continuous shape with a native pressed
state. Reduce Motion removes scale motion while retaining opacity feedback.
Haptics are placed at existing semantic command boundaries: selection,
commitment, dock command, and saving-to-settled transition.

## Truthfulness safeguards

- Passive outcome names and unsupported alternative controls are absent.
- No `Open in Time` action is shown because the fixture has no source-backed
  route.
- No generic Undo is shown because the exact inverse-command prerequisites are
  absent.
- Offline, stale, and conflict seams remain read-only where no command exists.
- Saving prevents duplicate commitment and never implies success prematurely.

## Accessibility

The final English evidence uses distinct visible labels and input labels,
minimum 44-by-44 targets, native focus behavior, and vertical recomposition at
Accessibility sizes. Localization proof remains open.

## Proof ceiling

Simulator tests cover geometry and semantics. Physical touch comfort, haptic
quality, Voice Control recognition, Switch Control, and keyboard traversal are
not closed.
