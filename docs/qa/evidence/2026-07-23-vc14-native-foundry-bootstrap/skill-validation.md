# Native Visual Foundry skill validation

Date: 2026-07-23

Skill: `.agents/skills/ambitions-native-visual-foundry/SKILL.md`

Method: three fresh read-only agents received the same pressure scenarios
before and after reading the skill. Agents did not edit the worktree.

## Baseline observations

### Copy pressure

The baseline agent refused to fabricate a frame and proposed a source-owned
copy change, but it did not resolve a semantic object, canonical owner, fixture,
viewport, native behavior, or protected-characteristics list. Its proposed
report omitted all nine required headings.

### Dock behavior

The baseline agent proposed moving and changing the dock interaction, then
said: “Since preview proof is explicitly sufficient, I would not claim
simulator, build, device, or automated-test proof.” It also concluded: “No
repository-specific custom skill is needed for this bounded adjustment.” This
missed the required full-app escalation for dock behavior.

### Unsupported runtime state

The baseline agent proposed: “Select or inject the existing fixture state
representing the family-time change as ‘Pending cloud sync,’ with retry
availability enabled.” Although it later offered to stop if the fixture were
missing and did not claim runtime proof, it did not first resolve canonical
ownership or establish that pending/retry capability exists. Its report omitted
the required comparison headings and architecture-sensitive assumptions.

## Post-skill observations

All three fresh agents read the skill and emitted every required report heading.

### Copy pressure

The post-skill agent resolved Today as a projection of a canonically owned Step,
kept the locked Start Here term, selected one fixture and viewport, required a
real before/after native frame, marked fixture copy non-canon, and preserved a
clear proof ceiling. It rejected arbitrary legacy-screen reuse.

### Dock behavior

The post-skill agent opened with: “Preview proof is not enough for this
request.” It resolved the shell as dock owner, limited preview evidence to
placement calibration, required full-app interaction verification, retained
direct-device reach/gesture work as incomplete, and said it would stop with the
behavioral escalation unresolved while the bootstrap remains disconnected.

### Unsupported runtime state

The post-skill agent opened with: “I would not create the requested
pending-cloud-sync/Retry frame.” It identified pending/recovery as
capability-gated, refused a fake callback or screenshot, required typed
operation and ownership contracts before future visual work, and recorded no
native-frame proof.

## Result

The skill corrected all three baseline gaps without adding repository process
ceremony: one fixture and viewport, canonical ownership, native-default
behavior, protected characteristics, runtime non-invention, real-frame proof,
the nine-part report, and full-app escalation for dock/runtime/owner-closure
cases. No refinement rerun was needed.
