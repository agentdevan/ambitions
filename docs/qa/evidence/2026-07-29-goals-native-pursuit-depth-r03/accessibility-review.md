# Accessibility review

## Dynamic Type

At Accessibility Dynamic Type, Goal Path becomes a vertically ordered semantic list. Before that list, an authored semantic foundation presents accepted truth, current Path position, supporting Proof, next movement, possible future, and conditional future in the required meaning order. All eight node identities, state labels, selected detail, and the Start/Now/Next/Finish Menu remain reachable through natural scrolling. Relationship content remains consequence-first and complete. Dedicated Accessibility Dynamic Type fixtures verify that recovery and closure actions remain reachable.

## Meaning beyond effects

- Reduce Motion uses native pushes and immediate/crossfade local changes; a dedicated Path fixture and UI assertion prove that no Path travel or autonomous motion carries meaning.
- Reduce Transparency uses authored opaque semantic planes and controls.
- Increased Contrast strengthens seams and secondary contrast.
- Differentiate Without Color retains explicit labels and distinct marker shapes for current, selected, protected, interrupted, conditional, and closed states.

## Assistive proof ceiling

Identifiers, grouping, semantic order, minimum interaction envelopes, and typed focus anchors are covered by package and Simulator UI tests. Physical VoiceOver, Voice Control, Switch Control, Full Keyboard Access, haptics, and repeated-use behavior remain direct-device obligations.
