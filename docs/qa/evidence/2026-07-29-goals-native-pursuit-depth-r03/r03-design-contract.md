# R03 design contract

Direction: `AVF-GOALS-S08-INT-D09-NATIVE-R03 — Pursuit Depth Completion`

## Thesis

The accepted D09 pursuit object gains Goal-owned depth without changing identity. Path, relationship, recovery, and closure are different resolutions of the same Goal, not detached utilities, project-management screens, or generic status pages.

## Spatial contract

- The matte semantic plane remains the default.
- Goal identity and Home ownership precede progression or metadata.
- Accepted truth remains authoritative through Path selection, relationship inspection, and recovery.
- Path uses qualitative compression and material certainty rather than equal milestones or measured distance.
- Proof is visibly attached to the exact accepted truth or Path node it substantiates.
- Relationship consequence changes the usable future boundary; it is not a graph.
- Recovery breaks the current seam but retains Goal, accepted truth, Proof, and Path.
- Closure resolves the pursuit while retaining history and explicit open work.

## Native behavior

NavigationStack, framework Back, interactive Back, native Menu, tap-first selection, natural scrolling, semantic focus, and accessibility reflow remain system-owned. No custom navigation or gesture-only behavior is introduced.

## Accessibility contract

At Accessibility Dynamic Type, the horizontal Path becomes a complete ordered semantic list. Identity, accepted truth, Proof, current movement, uncertainty, relationship consequence, recovery, closure, actions, and return remain present. Reduce Motion uses immediate or crossfade state changes. Reduce Transparency uses opaque authored planes. Increased Contrast and Differentiate Without Color strengthen boundaries, symbols, and explicit labels.

## Proof ceiling

This packet proves only fixture-driven native calibration in the Foundry host. It does not prove production routes, mutation, persistence, replay, Receipts, runtime integration, physical-device haptics, physical dock viability, or release accessibility. `APPROVED_FOR_SWIFTUI` remains false.
