# Architecture-sensitive assumptions

- Immutable Foundry snapshots remain synthetic proving inputs, not product authority or runtime state.
- The accepted `Goals → Home → Goal` `NavigationStack` hierarchy can own Path, relationship, recovery, and closure inspection without production routing changes.
- Path selection, jumps, and evidence inspection change only local fixture presentation state.
- Proof identity is distinct from Path state, History, Receipt, and completion.
- Recovery can preserve accepted truth and the exact Path while exposing an unaccepted alternative.
- Closure can express achieved outcome, closed Goal, retained Proof and History, and remaining open work without a production closure command.
- Horizontal Path geometry is a standard-size expression only; the ordered semantic list is the complete large-type equivalent.
- Focus anchors prove deterministic fixture-host intent. Physical assistive-technology behavior still requires direct-device validation.
- The Crowned Edge Dock remains provisional and is not evaluated or frozen by this packet.
- No R03 view, token, node, seam, or action is a final shared component API.
