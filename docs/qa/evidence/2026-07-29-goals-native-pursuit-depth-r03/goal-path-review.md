# Goal Path review

The standard-size Path is a horizontally inspectable qualitative field, not a timeline, roadmap, progress bar, or equal-node stepper. The selected region aligns to the leading edge so accepted truth or a future movement reads cleanly without cropped neighboring copy.

## Anatomy

- Recorded support compresses completed and settled positions while preserving exact Proof.
- `Paint the nursery wall` is the accepted-now seam and initial selection.
- `Assemble the crib` is a concrete near movement, not an accepted commitment.
- Planned and conditional content lose material presence with uncertainty.
- `Nursery ready for the crib` is a closure posture, not a percentage.
- Selected detail remains attached beneath the Path field and exposes scoped Proof/history inspection.
- A native Menu provides Start, Now, Next, and Finish jumps without four equal controls.

No continuous connector asserts a fixed sequence. Node spacing and width do not encode duration, quantity, rank, or percent.
