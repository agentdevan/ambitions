# Known limitations

- The packet is fixture-driven and does not prove a production Goal Path, relationship, recovery, closure, History, Receipt, persistence, replay, or mutation implementation.
- The horizontal Path is qualitative evaluation anatomy, not a temporal, duration, quantity, or completion axis.
- Simulator proof cannot close physical VoiceOver, Voice Control, Switch Control, Full Keyboard Access, haptic, edge-gesture, reach, or repeated-use obligations.
- Framework Back and semantic focus restoration are automated; the interactive edge gesture is deliberately not claimed because XCUI gesture synthesis was unreliable in this Simulator environment.
- Selection haptics can be specified and invoked, but cannot be claimed from Simulator evidence.
- The Crowned Edge Dock remains `PROVISIONAL_HIGH_RISK_HYPOTHESIS`; R03 does not test physical reach or Back-edge coexistence.
- Light and Dark, reduced effects, Increased Contrast, Differentiate Without Color, and Accessibility Dynamic Type are evaluation transformations, not release accessibility certification.
- Goal Path recovery, relationship expansion, and closure are non-mutating inspections. No production command or adapter is implied.
- Exact Path geometry, future material, relationship placement, motion, haptics, tokens, and component APIs remain open for cross-root synthesis.
- In the future-node evaluation frame, the selected unresolved position occupies the available Path viewport while accepted truth remains semantically available through Back/jump behavior; a later owner review may prefer simultaneous spatial context.
- `R03-F01` and `R03-F02` are intentionally identical because the default Path anchor is the current node. `R03-A03` is pixel-identical to the standard Dark Path because the baseline already uses the required opaque plane.
- The two H.264 clips are semantic-state recordings assembled from ordered native `XCUIScreen` frames captured by passing XCUI journeys. They prove state sequence and return targets, but not real-time transition cadence.
- `APPROVED_FOR_SWIFTUI` remains false and owner review remains required.
