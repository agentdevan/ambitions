# Closure review

Closure is a separate synthetic evaluation fixture for the same stable Goal. It distinguishes:

- outcome achieved;
- Goal closed;
- accepted truth: `The nursery is ready for the crib.`;
- retained Proof and settled Path continuity;
- protected result: `The first weeks together remain protected.`;
- remaining work: `Arrange final furniture after delivery`;
- retained local closure history.

The remaining item does not invalidate the achieved outcome. History is inspectable and retained. Closure never auto-dismisses and does not use green success material, a large check, confetti, score, percentage, reward copy, or deleted history.
