# Goals Native Calibration R01

`AVF-GOALS-S08-NATIVE-CALIBRATION-R01 — Singular Living Pursuit Passage`

Status: `REJECTED_STRUCTURAL_SPIKE — PRESERVE_SEMANTICS / REPLACE_VISUAL_MODEL`

This package preserves the first bounded, fixture-driven Goals structural spike after owner rejection. Its fixture identities, state semantics, typed routes, tests, and screenshots remain useful research inputs, but its visual model is not approved for refinement or propagation.

The fixture family is `goals-flagship/home/welcome-baby-home/v1`. All screenshots are native Simulator evaluation references with `production_baseline = false`. No recording requirement applies to this calibration.

## Preserve exactly

- Four roots: Today, Goals, Time, You.
- Search and Capture remain global dock-owned actions.
- Matte opaque content planes, system typography, object identity before state, natural scrolling, and accessibility recomposition.
- R14 and transfer-gate authority remain unchanged.

## Changed

- Added a Goals-specific spatial grammar for Life Area expansion, selected Goal identity, an attached lens, focused pursuit depth, relationship inspection, and a native Goal Path.
- The existing fixture-host selector can launch eight deterministic Goals evidence states.

## Removed

- No existing product or Foundry behavior was removed.
- Today-specific Start Here, Later Today, Full Day, Still Counts, settlement placement, and return-focus composition were deliberately excluded.

## Added

- Immutable Goals fixture snapshots and typed non-mutating navigation state.
- Local Goals composition units, previews, package tests, UI interaction tests, capture tests, eight screenshots, and two contact sheets.

## Unresolved

- Production Goals data, routing, restoration, persistence, mutation, and Goal Path generation.
- Cross-root synthesis of final node geometry, motion, color distribution, tokens, and component APIs.
