# Architecture-sensitive assumptions

- Foundry fixtures remain immutable synthetic snapshots and are not runtime adapters.
- The local state model proves selection, inspection, disclosure, navigation, Path selection, and restoration only.
- No production Life Area persistence, Goal activation, Proof mutation, Path mutation, schedule mutation, Receipt, or Undo exists in this slice.
- A future runtime adapter must construct equivalent semantic snapshots without changing view contracts.
- Goal Path order and states are source-local fixture truth; generation remains unimplemented.
- Time context is explanatory only. Exact chronology and mutation remain Time-owned.
- The Crowned Edge Dock remains provisional pending direct-device proof.
- Path haptics, final motion, focus restoration, and final node geometry remain provisional.
- Final cross-root tokens and component APIs require later synthesis across Goals and Time.
- R14 evidence and transfer-gate authority remain unchanged.
