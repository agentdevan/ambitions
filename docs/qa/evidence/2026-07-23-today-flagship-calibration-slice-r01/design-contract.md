# Today calibration design contract

The slice preserves the closed AVF direction set and VC-14 bootstrap boundary.
It is a Personal Life OS journey, not a task manager, agenda, dashboard, feed,
or assistant.

## Stable anatomy

- Today remains the active root and owns immediate lived execution.
- The compact semantic crown states `Today` and the present relationship.
- One dominant Start Here presents identity, accepted truth, fit, consequence,
  and one object-specific action before timeline detail.
- The supporting timeline is object-first; exact time is secondary.
- Search and Capture remain dock-owned and separate from the four roots.
- Matte mineral-neutral Light and deep-graphite Dark share identical anatomy.
- Violet-indigo is restricted to action/proposal articulation.
- Natural native scrolling, system type, native controls, and minimum 44-point
  targets remain default behavior.

## Truth grammar

- **Current:** accepted canonical truth remains authoritative before commit.
- **Proposed:** `Still counts` is labelled not yet accepted and cannot replace
  current truth.
- **Operational:** saving and interruption retain identity and accepted truth.
- **Settled:** new accepted truth appears only after settlement and remains in
  the focused object until explicit return.

The distinctions use labels, semantic order, symbols, and structure in addition
to tone. Hue is never the only signal.

## Rejected anatomy

No bottom tabs, card grid, dashboard section system, agenda table, completion
circle, score, streak, status-pill collection, glass content card, glow,
decorative category color, fake control, generic success ceremony, or AI
assistant presentation is present.

## Outcome and return

`Still counts` is the one consequential outcome. Settlement creates fixture
Receipt/History evidence because this exact source-backed Step contract supports
it; no generic Undo is exposed. Return retains the settled Step in truthful
Today continuity, removes it from Start Here eligibility for this fixture, and
reveals `Send the launch brief` without presenting it as a reward.
