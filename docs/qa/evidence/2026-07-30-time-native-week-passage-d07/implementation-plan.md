# Implementation plan

The prototype is isolated to `AmbitionsNativeVisualFoundry`, its fixture host,
and focused tests. It does not enter the production app target.

## Native proving seams

1. An immutable fixture supplies exact identity, minute ranges, truth posture,
   source, consequence, and relationship context.
2. A typed journey state owns selected day, framework navigation path, compact
   presentation, and restoration focus without mutation.
3. A proportional scale maps fixture minutes to native points for duration,
   Now, overlap, and open-capacity boundaries.
4. `NavigationStack`, native Back, a compact sheet, and native Buttons provide
   the proving interaction model.
5. Accessibility Dynamic Type switches the spatial Week passage to an ordered
   semantic chronology.

The seam deliberately omits production repositories, adapters, routes,
persistence, mutation, external writes, receipts, undo, recurrence, drag, and
resize.
