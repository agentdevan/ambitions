# Visual reference assets

The restored directories in this tree preserve the Figma exports, selected VSP
packages, accessibility matrices, visual explorations, and Revision 1 reference
renders that explain Ambitions' design direction.

These assets are not repository authorization or mandatory proof packs. No
ordinary change must generate a receipt, ledger, owner approval, screenshot
bundle, or status label. The dated names and historical manifests remain only
so links from the design-provenance library resolve and prior visual decisions
can be inspected.

Current UI work is validated against the applicable design reference using
real compilation, focused behavioral/UI tests, accessibility checks, and
rendered inspection. A historical image does not prove current parity.
