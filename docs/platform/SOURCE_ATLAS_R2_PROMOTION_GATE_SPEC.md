# Source Atlas R2 Promotion Gate Spec

Status: active local contract for M04 validation
Scope: Source Atlas public/reference bundle manifests, R2 object layout, freshness, revocation, last-known-good, and dry-run promotion validation
Owner posture: platform implementation support, not R2 production readiness, privacy/legal approval, app runtime proof, or release proof

Source Atlas R2 promotion is a hard validation gate. The gate exists to prove whether a candidate public/reference bundle and R2 staging plan are promotion-shaped. It does not upload to R2, promote a stable channel, validate app runtime fetch/cache, validate entitlement gating, or prove release readiness.

## Required Inputs

- Foundry bundle root with `manifest.json`
- R2 staging plan generated by `source-atlas-foundry.py r2-plan`
- optional revocation manifest generated by `source-atlas-foundry.py revocation-manifest`
- target channel, currently `staging` or `stable`

## Required Checks

The local dry-run gate must fail on:

- private egress or private-looking payloads
- unsafe R2 object key shape
- missing local object
- missing or mismatched checksum
- missing byte count
- missing provenance receipt
- source-backed claim without source/provenance IDs
- invalid or incomplete source registry certification
- stale critical claim use
- revoked artifact use
- blocked source promotion
- source-of-sources metadata used as claim truth
- unsupported channel

## Output Contract

The gate output is deterministic JSON:

```text
kind: ambitions.sourceAtlas.promotionGateDryRun
dryRunOnly: true
wouldUpload: false
validForPromotion: true/false
checks: per-check pass/fail records
issues: blocking issue list
nonClaims: explicit non-claim ledger
```

## Commands

```bash
python3 tools/source-atlas/source-atlas-foundry.py compile \
  --output-root /tmp/source-atlas-foundry \
  --version-id source-atlas-m04-smoke \
  --channel staging

python3 tools/source-atlas/source-atlas-foundry.py r2-plan \
  --bundle-root /tmp/source-atlas-foundry/source-atlas-m04-smoke \
  --bucket ambitions-source-atlas-staging \
  --prefix source-atlas/v1 \
  --channel staging \
  --output /tmp/source-atlas-foundry/source-atlas-m04-smoke/r2-plan.json

python3 tools/source-atlas/source-atlas-foundry.py promotion-gate \
  --bundle-root /tmp/source-atlas-foundry/source-atlas-m04-smoke \
  --r2-plan /tmp/source-atlas-foundry/source-atlas-m04-smoke/r2-plan.json \
  --channel staging
```

## Non-Claims

This spec and the local dry-run gate do not prove remote R2 staging, R2 production freshness, stable-channel promotion, deployed Worker promotion, app runtime fetch/cache, offline fallback, account or entitlement gating, privacy/legal approval, release readiness, or App Store/TestFlight readiness.
