# Excluded for cost/scope reasons

The following are explicitly excluded in this batch to preserve no-cost, local-only control plane:

- Codex GitHub Action
- GitHub Actions workflows
- OpenAI API SDKs
- Agents SDK
- MCP servers
- gpt-oss model runtime
- Whisper
- tiktoken
- openai-cookbook examples
- ChatKit / Apps SDK
- Figma / Canva / paid design integrations
- App Store upload/signing automation
- package managers / dependency installation
- external CI/CD
- external SaaS tools

These are excluded because each could introduce new operational cost exposure, external dependency risk, or release claims without explicit future approval.
