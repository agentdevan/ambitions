# AmbitionsOS Photo-Matched Visual Targets

Status: Active visual reference assets

## Purpose

This folder stores the uploaded photo-matched visual reference stills for Ambitions 4.0 Dynamic Adaptive Visual System, Signature Experience, and future Transformative Motion work.

These files are reference assets only. They guide visual direction, evidence reports, and batch review. They are not production app assets and must not be shipped in the native app bundle.

## Visual Qualities

- Dark premium graphite and black studio product photography feel.
- iPhone Pro Max / iPhone 17 Pro Max-class demo proportions.
- Conservative futuristic composition with cinematic but minimal atmosphere.
- Refined native iOS glass/material depth, soft edge light, and restrained translucency.
- Subtle atmospheric glow and living stateful modules without plastic gradients, neon, rainbow palettes, or cartoonish effects.
- Emotionally compelling premium polish that helps the user love the experience before understanding the intelligence underneath.

## Implementation Usage Rules

- Every DAV, SIG, or Transformative Motion visual implementation batch must inspect or cite this folder in its evidence report.
- Use these references as a visual north star, not as shipped app content.
- Prefer native SwiftUI and existing repo dependencies.
- Do not add these PNG files to `Native/Ambitions/Assets.xcassets`.
- Do not create binary files from prompts or attachments to satisfy this reference set.
- Do not create a separate SIG visual identity that competes with DAV.
- Keep implementation evidence grounded in changed repo files and validation output.

## Claim Boundaries

- These references do not prove shipped app behavior.
- These references do not prove release readiness, production readiness, App Store readiness, TestFlight readiness, device verification, full accessibility conformance, or public award status.
- Aspirational quality language may be used as a design target, but reports must not claim Apple award status or production readiness from these images.
